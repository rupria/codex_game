# 선택 제출 가산점 메모

> 이 문서는 제출 필수 조건이 아닌 선택 가산점 자료를 관리한다. 공개 웹 빌드와 플레이 링크 완성을 우선한다.

## 3분 이내 데모 영상

- 상태: 선택 제출
- 조건: 실제 플레이 포함, 3분 이내
- 권장 구성: 게임 소개 → 실제 플레이 → 핵심 기능
- 준비 원칙: 플레이 가능한 제출 후보 빌드가 확정된 뒤 제작 여부를 결정한다.

## Codex 활용 설명

- 상태: 선택 제출
- 설명 항목:
  - Codex를 사용한 영역
  - Codex와 구현한 기능
  - Codex로 해결한 문제
  - 사람이 직접 결정한 부분
- 근거 기록: `core/CODEX_COLLABORATION_LOG.md`
- 기록 형식: `문제 → Codex 활용 → 사람이 결정한 내용 → 결과`

## 우선순위 원칙

1. 브라우저에서 실행되는 웹 빌드
2. 심사 기간 접근 가능한 공개 플레이 링크
3. 무승인 접근, 조작 안내와 안정성 검증
4. 선택 데모 영상과 Codex 활용 설명

선택 자료 때문에 필수 빌드의 범위, 안정성 또는 검증 시간이 줄어들면 선택 자료 작업을 중단한다.
