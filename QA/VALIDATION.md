# 검증 계획 및 기록

## 판정 등급

- `PASS`: 완료 조건을 충족하고 재현 가능한 문제가 없다.
- `CONDITIONAL`: 플레이는 가능하지만 알려진 제한이나 우회 방법이 있다.
- `FAIL`: 완료 조건을 충족하지 못하거나 플레이 진행이 막힌다.
- `NOT TESTED`: 아직 검증하지 않았다.

## 필수 검증 체크리스트

### 재미와 이해

- [ ] 처음 보는 플레이어가 첫 30초 안에 목표를 이해한다.
- [ ] 조작법을 별도 설명 없이 찾을 수 있다.
- [ ] 플레이어의 선택에 즉시 이해 가능한 피드백이 제공된다.
- [ ] 3분 안에 긴장, 숙련, 발견 또는 웃음 중 하나가 나타난다.
- [ ] 플레이테스터가 한 번 더 플레이할 의향을 표현한다.

### 기능과 안정성

- [ ] 시작, 진행, 성공·실패, 종료와 재시작이 정상 작동한다.
- [ ] 새로고침 후에도 게임을 다시 시작할 수 있다.
- [ ] 잘못된 입력이나 빠른 반복 입력으로 진행이 막히지 않는다.
- [ ] 치명적 콘솔 오류와 무한 로딩이 없다.

### 공개 접근성

- [ ] 공개 URL이 시크릿 창에서 열린다.
- [ ] 승인, 초대, 결제와 개인 계정 로그인이 필요하지 않다.
- [ ] 지원 대상 브라우저와 화면 크기에서 조작할 수 있다.
- [ ] 외부 API 장애나 비용 한도가 기본 플레이를 막지 않는다.
- [ ] 비밀 키가 클라이언트 코드나 저장소에 포함되지 않는다.

### 권리와 제출

- [ ] 이미지, 음원, 폰트, 코드와 데이터의 출처가 기록돼 있다.
- [ ] 공개·배포가 가능한 라이선스인지 확인했다.
- [ ] Codex 활용 사례와 사람의 최종 결정이 기록돼 있다.
- [ ] 실제 플레이가 포함된 3분 이내 영상이 준비돼 있다.
- [ ] 제출 설명과 게임 화면의 조작 안내가 일치한다.
