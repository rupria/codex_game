# 포커 라운드 원형 테이블 UI 개편 0.2.2

> 2026-08-10 갱신: 승패 선택 부분은 `Textless_Currency_0_4_0` 계약이 우선한다. 기존 체크·X 메달과 `승리/패배` 문구를 사용하지 않고 플레이어·AI 초상 중 예상 승자를 선택한다. 나머지 원형 테이블 배치는 유지한다.

## 문제

- 기존 포커 화면은 플레이어 카드·커뮤니티 카드·AI 카드가 화면을 가로질러 같은 높이에 놓여 대면 게임의 공간감이 약하다.
- 승리·패배 버튼이 화면 전체 폭의 회색 직사각형이라 메인·가이드 UI와 시각적으로 지나치게 유사하다.
- HP·아이템·카드·판정 선택의 우선순위가 분리되지 않아 포커 단계 고유의 화면으로 읽히지 않는다.

## 확정 배치

- AI 개인 카드 3장: 원형 테이블 12시, 뒷면 상태
- 커뮤니티 카드 2장: 테이블 중앙
- 플레이어 개인 카드 3장: 테이블 6시, 앞면 상태
- AI HP 하트: AI 카드의 왼쪽
- AI 아이템: AI 카드의 오른쪽
- 플레이어 HP 하트: 플레이어 카드의 왼쪽
- 플레이어 아이템: 플레이어 카드의 오른쪽
- 승리·패배 선택: 플레이어 카드 아래의 원형 메달 버튼 2개

## HP 규칙 — #23 연결

- 3번째 참고 이미지의 ‘총알 3개’ 표시는 GitHub #23 확정 기준에 따라 하트 3개로 치환한다.
- 남은 HP는 filled 하트, 잃은 HP는 empty 하트로 표시한다.
- 플레이어는 청록, AI는 붉은색을 사용하지만 색상뿐 아니라 채움·외곽선·명도도 함께 다르게 한다.
- 포커 피해 확정 순간 하트 한 개를 즉시 갱신한다.
- 시안은 플레이어 3/3, AI 2/3 상태를 예시로 보여 준다.

## 승패 선택 버튼

- 기존 화면 하단의 폭 전체 회색 버튼 2개는 제거한다.
- 원형 서부 메달 버튼 2개를 플레이어 손패 아래에 배치한다.
- 승리 선택은 청록 체크, 패배 선택은 붉은 X를 사용한다.
- 한국어 `승리 / 패배`, 영어 `WIN / LOSE` 라벨은 Unity 텍스트로 버튼 아래 또는 내부에 중앙 정렬한다.
- hover 시 황동 외곽선과 내부 명도를 올리고, pressed 시 1~2px 내려간 상태를 사용한다.
- 보이는 버튼과 실제 클릭 영역의 중심이 일치해야 한다.
- 선택 후에는 두 버튼을 모두 비활성화하고 선택 결과가 확정될 때까지 중복 입력을 막는다.

## 카드 공개 규칙

- AI 개인 카드 뒷면은 상대 방향으로 180° 회전해 놓는다.
- 예측 입력 전까지 AI 카드 3장은 뒷면을 유지한다.
- 결과 공개 시 카드가 뒤집힌 후 앞면은 플레이어가 읽을 수 있는 정방향으로 고정한다.
- 커뮤니티·플레이어 카드는 항상 플레이어 정방향이다.
- 카드 아래에는 접촉 그림자만 두고 사각 슬롯 프레임을 만들지 않는다.

## 아이템 슬롯

- AI·플레이어 각각 한 개의 64×64 슬롯을 사용한다.
- 비어 있을 때는 승인된 빈 슬롯 이미지만 표시하고 `+` 문자를 표시하지 않는다.
- 아이템이 있으면 아이콘을 슬롯 중앙에 배치한다.
- 사용 불가 상태는 채도와 명도를 낮추고 입력을 차단한다.

## #21·#22 공통 UI 원칙

- 장식 버튼 위에 별도의 회색 텍스트 버튼 또는 투명 클릭 레이어를 중복 생성하지 않는다.
- 시각 버튼과 클릭 영역이 일치해야 한다.
- 한국어·영어 전환 후에도 라벨 중심과 패딩을 유지한다.
- 포커 화면에는 메인 화면의 START·GUIDE 버튼을 재사용하지 않는다.

## #24 타이머 분리

- #24의 30초 밧줄 타이머는 할리갈리 카드 펼치기 단계 전용이다.
- 포커 예측 제한시간과 같은 타이머 인스턴스·폭발 판정을 공유하지 않는다.
- 포커에도 제한시간을 둘 경우 별도 상태와 명세를 사용하며, 이번 시안에는 밧줄을 표시하지 않는다.

## Unity 구현 요청

1. 기존 포커 가로 배열과 전체 폭 승패 버튼을 비활성화한다.
2. Poker Wide 카메라 상태에서 본 문서 좌표를 기준으로 새 앵커 그룹을 구성한다.
3. 내부 HP 데이터와 하트 filled/empty 상태를 연결한다. 관련 이슈: #23.
4. AI/플레이어 아이템 데이터를 각 슬롯에 연결한다.
5. 승리·패배 버튼을 기존 예측 로직에 각각 한 번만 연결한다.
6. AI 결과 공개 시 뒷면→앞면 회전 연출을 실행한다.
7. 할리갈리 30초 타이머와 포커 UI 상태를 분리한다. 관련 이슈: #24.

## 완료 조건

- 포커 화면이 AI→커뮤니티→플레이어의 세로 대면 구조로 보인다.
- AI 개인 카드 3장은 판정 전까지 뒷면이며 플레이어 카드 3장은 읽을 수 있다.
- HP 0~3 상태가 #23의 내부 데이터와 항상 일치한다.
- 승리·패배 버튼의 보이는 영역과 클릭 영역이 일치한다.
- 한 번의 선택으로 기존 예측 로직이 정확히 한 번만 호출된다.
- 오른쪽·왼쪽 아이템 슬롯이 카드와 겹치지 않는다.
- 960×540, 1280×720, 1920×1080에서 원형 테이블 중심축과 좌우 대칭이 유지된다.
- 할리갈리 밧줄 타이머의 진행·폭발 상태가 포커 화면에 남지 않는다.
- 게임 규칙과 카드 데이터는 변경하지 않고 표시 계층과 입력 연결만 개편한다.
