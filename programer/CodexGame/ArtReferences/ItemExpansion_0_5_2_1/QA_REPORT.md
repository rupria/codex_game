## 3해상도 아트 검수

- 960×540: 기준 픽셀 크기에서 카드 좌상단 랭크·우상단 문양과 상태 마커 충돌 없음.
- 1280×720: nearest 변환에서 번짐·보간 없음.
- 1920×1080: 기준 해상도 2배 확대에서 픽셀 경계와 실루엣 유지.
- 보험 발동 배지는 중앙 판정 카드와 개인 카드 영역을 피한 결과 패널 내부에 위치.
- 용병단 AI 영역은 모든 검수본에서 카드 뒷면만 사용.

## 남은 런타임 검증

- 공유 카드 2장이 아이템 선택 화면에서 계속 앞면으로 유지되는지 Unity 실행 확인.
- 보험 실제 발동이 오답·2분 무입력에서만 0.40초 재생되는지 확인.
- 실제 정답, 충전 0, 세 번째 이후 실패, 손패 확정 120초 초과에서 발동 연출이 나오지 않는지 확인.
- 아이템 연출 중 손패 확정 타이머가 멈추지 않는지 확인.

위 항목은 아트 파일 문제가 아니라 프로그래머 이벤트 조건과 런타임 QA 범위다. 연결 상태는 2026-08-20 `dev` 감사에서 `PlayableDevSceneBuilder`의 `prediction_result_insured_success_32_0_5_2.png` 로드와 `PokerDevPanel.DrawPredictionInsuranceActivation`의 실제 소비를 함께 확인해 정정했다.
