# 프로그래머 확인용 — 게임진행플로우 0.1.2 아트

아트 연결 이슈: [#37](https://github.com/rupria/codex_game/issues/37)

이번 리비전은 상점, 할리갈리, 포커 UI와 살룬 조명 기준을 연결 가능한 상태로 정리한 것입니다. 게임 규칙 로직은 변경하지 않았습니다.

## 상점

![상점 4칸과 총알 주머니](../BarShop_0_3_4/preview/bar_shop_four_slot_pouch_layout_preview_960x540_0_3_4.png)

- 상품 슬롯 4개: X `20, 250, 480, 710`, Y `146`, 크기 `190×174`
- 총알 주머니: `(776,384)`, `180×150`, 별도 사각 프레임 없음
- 버튼 PNG에는 아이콘과 문자를 굽지 않고 TMP 텍스트를 올림
- 가격 1~2는 화면 하단에서 동전처럼 튕기고, 가격 3 이상은 주머니를 기울여 테이블에 붓는 연출
- 총알이 고정된 주머니 이미지는 잔액 표시에 사용하지 않고 `BarShop_0_3_8`의 빈 주머니·개별 총알·손 오버레이 사용
- 구매 중 손이 주머니를 덮은 사이 표시 총알 수를 현재 `BulletCount`와 동기화
- 총알 최신 비주얼은 `BarShop_0_3_9` 사용: 탄두·탄피·림·뇌관 가독성 강화, 플립·불규칙 붓기 시트 포함

## 할리갈리

![할리갈리 좌우 공유 더미](../Halli_Item_0_3_7/preview/halli_two_card_fan_application_preview_960x540_0_3_7.png)

- 독립 더미 4개가 아니라 화면 좌·우 공유 더미 2개 표시
- 왼쪽은 플레이어 1번째 → AI 2번째, 오른쪽은 AI 1번째 → 플레이어 2번째 순서
- 더미당 최대 2장, 이전 카드는 아래·왼쪽으로 밀어 두 카드 정보를 함께 표시
- 카드 뒤 불투명 검은 패널 제거
- 상세 연결값: `../Halli_Item_0_3_7/README.md`
- 밧줄 타이머는 `Halli_0_3_9`의 어두운 웨스턴 도화선, char cap, 6프레임 불꽃, 8프레임 폭발 사용
- 도화선 본체는 폭에 맞춰 늘이지 않고 UV/clip으로 잘라 꼬임 간격 유지
- 상세 연결값: `../Bullet_Rope_0_3_9/README.md`

## 포커 아이템 상자

### 닫힘

![포커 상자 닫힘](preview/poker_item_box_closed_preview_960x540_0_3_6.png)

### 열림 — 아이템 없음

![포커 빈 상자 팝업](preview/poker_item_box_open_empty_popup_preview_960x540_0_3_6.png)

### 열림 — 아이템 있음

![포커 아이템 상자 팝업](preview/poker_item_box_open_filled_popup_preview_960x540_0_3_6.png)

- 포커 본 화면에서 총알 개수 및 총알 관련 미터를 표시하지 않음
- 닫힌 상자 클릭 시 불투명 팝업을 열고 뒤쪽 입력을 차단
- 보유 아이템 `0개`면 `open_empty`, `1개 이상`이면 `open_filled + 4칸 인벤토리`
- AI는 0.1.2 기준 아이템을 사용하지 않으므로 AI 아이템 상자를 표시하지 않음

런타임 경로:

- `Assets/Art/Prototype/UI/Poker_0_3_4/` — 닫힘/열림 빈/열림 채움 상자 원본
- `Assets/Art/Prototype/UI/Poker_0_3_6/` — 팝업 프레임 및 포커 연결 리비전
- `Assets/Art/Prototype/UI/Poker_0_3_7/` — 아이템 선택·상세·대상 선택 리비전
- `Assets/Art/Prototype/UI/Gameplay_0_1_2/` — 아이템 아이콘/인벤토리 공용 리소스

## 연결 완료 체크

- [ ] 상점 상품 4개와 주머니가 겹치지 않는다.
- [ ] 할리갈리 좌우 공유 더미에 최대 2장씩 보이고 최신 카드만 판정한다.
- [ ] 할리갈리 밧줄이 밝은 진행 막대가 아니라 어두운 도화선으로 읽히고 불꽃·그을음이 함께 이동한다.
- [ ] 포커 본 화면에 총알 수가 없다.
- [ ] 포커 상자 클릭 시 빈/채움 팝업이 데이터에 따라 분기된다.
- [ ] 팝업이 열린 동안 뒤쪽 입력이 차단된다.
- [ ] 살룬 배경이 검은 실루엣이 아니라 공간으로 읽힌다.
- [ ] 960×540, 1280×720, 1920×1080에서 UI가 겹치지 않는다.
