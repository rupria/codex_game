# 서부 해골 조커 2종 아트 인계 0.07

## 카드 구성

| 파일 | 이름 | 시각 구분 |
|---|---|---|
| `card_poker_joker_brass_sheriff.png` | 황동 보안관 조커 | 아이보리 보안관 모자, 황동 별, 청록 스카프, 갈색 더스터 |
| `card_poker_joker_crimson_outlaw.png` | 진홍 무법자 조커 | 검은 챙모자, 붉은 반다나·판초, 카드 패, 리볼버 |

두 카드는 같은 인물의 색상 변경이 아니다. 모자 실루엣, 얼굴 장식, 자세, 의상, 소품과 우측 상단 상징을 각각 다르게 구성했다.

## 적용 규격

- 크기: 56×78px
- 단계: 포커 카드
- 랭크: Joker
- 문양: 없음
- 좌측 상단: `J`
- 우측 상단: 보안관 별 / 말발굽 상징
- Texture Type: Sprite (2D and UI)
- Filter Mode: Point
- Compression: None
- Mip Map: Off
- Alpha Is Transparency: On

Unity 경로: `Assets/Art/Prototype/Cards_0_07/joker_variants`

## 데이터 키 권장

- `joker_brass_sheriff`
- `joker_crimson_outlaw`

조커의 실제 게임 효과와 덱 포함 여부는 아직 아트 범위 밖이다. 프로그래머는 카드 이미지에 효과를 고정하지 말고 데이터 키로 분리한다.
