# #19 할리갈리 획득 카드 UI 정리 요청 0.2.1

## 문제

- 오른쪽 아래 `AI 획득` 영역에서 카드 뒷면과 로딩 표시가 깨진 상태로 계속 노출된다.
- AI 덱은 이미 화면 상단 중앙에 있으므로 오른쪽 아래 카드 뭉치는 같은 정보를 중복 표시한다.
- 상단의 `할리갈리 0/3` 텍스트와 하단 승수 표기가 분리되어 현재 라운드 승수를 빠르게 읽기 어렵다.

## 확정 변경

1. 상단 좌측과 우측은 플레이어·AI의 HP만 표시한다.
2. 할리갈리 라운드 승수는 하단의 원형 마커 3개로 이동한다.
3. 플레이어 마커는 청록색, AI 마커는 붉은색을 사용한다.
4. 승리할 때마다 왼쪽부터 한 칸씩 `empty → filled`로 전환한다.
5. 플레이어 획득 카드 영역은 왼쪽 아래에만 유지한다.
6. 오른쪽 아래 AI 획득 카드 패널은 컨테이너까지 완전히 제거한다.
7. AI 덱의 유일한 화면 표시는 상단 중앙의 대면형 AI 덱이다.
8. `AI 판정 중` 상태는 카드 패널과 분리된 작은 상태 박스로 유지한다.

## 제거 대상

- 오른쪽 아래 `AI 획득 0` 텍스트
- AI 획득 카드 패널의 외곽 프레임
- 로딩 원
- 카드 뒷면 이미지
- 붉은 카드 수 사각 카운터 3개
- 패널 제거 후 남는 빈 슬롯·플레이스홀더·깨진 텍스처
- 상단 좌우의 중복 `할리갈리 n/3` 텍스트

## 960×540 참고 좌표

### 플레이어 라운드 승수

- 마커 크기: 32×32
- 시작 위치: `(18, 365)`
- 다음 마커 간격: 46px
- 세 위치: `(18, 365)`, `(64, 365)`, `(110, 365)`
- 플레이어 획득 카드 영역 바로 위에 배치한다.

### AI 라운드 승수

- 마커 크기: 32×32
- 시작 위치: `(704, 390)`
- 다음 마커 간격: 46px
- 세 위치: `(704, 390)`, `(750, 390)`, `(796, 390)`
- `AI 판정 중` 상태 박스 아래에 배치한다.
- 오른쪽 아래에는 카드 컨테이너를 다시 만들지 않는다.

좌표는 기준값이며 Canvas Scaler를 사용해 화면 비율에 맞게 비례 적용한다.

## 상태 규칙

| 승수 | 표시 |
|---|---|
| 0승 | empty, empty, empty |
| 1승 | filled, empty, empty |
| 2승 | filled, filled, empty |
| 3승 | filled, filled, filled |

- 승수 감소 연출은 사용하지 않는다.
- 승리 확정 시 해당 마커를 120~180ms 동안 밝게 점등한 뒤 filled 상태로 고정한다.
- 3승 달성 이후에는 기존 단계 전환 로직을 호출하며 별도의 네 번째 마커를 만들지 않는다.

## 완료 조건

- AI가 승리하거나 카드를 획득해도 오른쪽 아래에 카드 뒷면·로딩 원·깨진 이미지가 생성되지 않는다.
- 상단 중앙 AI 덱은 정상 유지된다.
- 플레이어 획득 카드는 왼쪽 아래에서 계속 확인할 수 있다.
- 양쪽 라운드 승수는 서로 대칭적인 3개 마커로 읽힌다.
- 0승부터 3승까지 empty/filled 조합이 정확하다.
- 16:9 및 WebGL 화면에서 마커가 테이블 밖으로 잘리지 않는다.
- 게임 판정과 카드 데이터는 변경하지 않고 표시 계층만 정리한다.
