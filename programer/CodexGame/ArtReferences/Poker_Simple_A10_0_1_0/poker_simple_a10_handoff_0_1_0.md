# 포커 단순화 A–10 후보 0.1.0

## 상태

- 검토용 WIP 후보이며 현재 런타임 `Assets/Art/Prototype/Cards_0_06/poker_variants/`는 교체하지 않았다.
- 개별 카드: `cards/{suit}/card_simple_{suit}_{rank}.png`
- 전체 검수 시트: `poker_simple_a10_contact_sheet_1600x800_0_1_0.png`
- 규격: 64×90 RGBA, 투명 모서리, Point 필터 권장
- 수량: 하트·다이아·클로버·스페이드 각 10장, 총 40장

## 디자인 규칙

1. 좌측 상단에 A–10 랭크, 우측 상단에 슈트를 표시한다.
2. A는 슈트 안에 해골 문양을 사용한다.
3. 2–10은 해골을 넣지 않고 익숙한 포커 핍 배열을 사용한다.
4. 하트·다이아는 적색, 클로버·스페이드는 흑색으로 구분한다.
5. 새 단순화 J·Q·K와 맞추기 위해 얇은 슈트색 안쪽 테두리와 황동 모서리 포인트를 사용한다.

## 제작 기록

- A 방향 시안: OpenAI 내장 ImageGen으로 4개 슈트 해골 엠블럼과 큰 인덱스 방향을 생성
- 40장 최종 후보: 기존 `card_front_base.png`와 승인된 A 해골 문양을 사용해 랭크·핍·테두리를 결정적으로 합성
- 숫자와 핍 정확성을 위해 40장을 생성형 모델로 개별 생성하지 않았다.
