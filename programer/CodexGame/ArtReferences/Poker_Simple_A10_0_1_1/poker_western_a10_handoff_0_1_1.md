# 웨스턴 포커 A–10 후보 0.1.1

## 상태

- 검토용 WIP 후보이며 런타임 `Assets/Art/Prototype/Cards_0_06/poker_variants/`의 52장은 아직 교체하지 않았다.
- 개별 카드: `cards/{suit}/card_western_{suit}_{rank}.png`
- 전체 검수 시트: `poker_western_a10_contact_sheet_1600x800_0_1_1.png`
- 카드 본체 템플릿: `card_front_western_base_64x90_0_1_1.png`
- 규격: 64×90 RGBA, 투명 모서리, Point 필터 권장
- 수량: 하트·다이아·클로버·스페이드 각 10장, 총 40장

## 변경·보존 규칙

1. 카드 본체만 따뜻한 양피지, 짙은 월넛 외곽, 얇은 적갈색 키라인과 작은 황동 모서리 포인트로 갱신했다.
2. 기존 랭크, 핍 배열, 슈트 색, A의 문양 테두리와 해골 디자인은 픽셀 단위로 그대로 재사용했다.
3. A 해골은 네 슈트 모두 머리띠·이마 보석·왕관이 없는 맨머리 디자인이다.
4. 2–10은 해골 없이 익숙한 포커 핍 배열을 유지한다.
5. 생성형 모델은 고해상도 방향 시안에만 사용했다. 40장 실사용 후보는 숫자와 핍 정확성을 위해 결정적으로 합성했다.

## 원본·방향 시안

- `sources/ace_bare_skull_reference_0_1_1.png`: 머리 장식을 제거한 A 해골 기준
- `sources/ace_western_card_body_direction_0_1_1.png`: 웨스턴 카드 본체 방향

## 프로그래머 적용 메모

- 승인 전에는 기존 `poker_variants/`를 유지한다.
- 승인 후 A–10만 교체할 경우 파일 이름 매핑이 필요하다.
- J·Q·K는 이 후보에 포함되지 않으므로 기존 로열 카드와 병행하거나 같은 본체 템플릿으로 후속 합성한다.
