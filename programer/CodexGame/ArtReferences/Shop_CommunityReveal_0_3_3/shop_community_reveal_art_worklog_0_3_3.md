## 문제 → Codex 활용 → 사람이 결정한 내용 → 결과

### 상점 탄약

- 문제: 기존 탄약 표시는 단색 기호에 가까워 실제 총알의 느낌이 약했다.
- Codex 활용: 기존 200×58 패널 규격과 팔레트를 분석하고 24×40 픽셀 리볼버 탄환을 Aseprite로 제작했다.
- 사람이 결정한 내용: 상점의 총알 표시를 조금 더 실제 총알처럼 보이게 한다.
- 결과: 구리 탄두·황동 탄피·밑면 림이 분리된 idle·shine·low 3상태와 새 패널을 만들었다.

### 커뮤니티 카드 공개

- 문제: 현재 공개 카드는 일반 UI 안에서 바로 나타나 주목도와 단계 전환 감각이 약했다.
- Codex 활용: UI 없는 원형 테이블 배경, 중앙 스포트라이트, 카드 폭 축소를 이용한 뒤집기 6프레임을 구성했다.
- 사람이 결정한 내용: 오픈 단계에서 커뮤니티 카드를 단독 화면으로 펼치는 연출을 넣는다.
- 결과: 약 1.29초의 뒷면→확대→측면→앞면→고정 연출과 Aseprite 프레임 원본을 만들었다.

### 포커 아이템 상자

- 문제: 포커 화면의 아이템 영역이 흰 임시 박스로 남아 서부 콘셉트와 맞지 않았다.
- Codex 활용: 제공된 빈티지 목재 운반 상자를 3/4 시점 픽셀 아트로 단순화하고 포커 테이블에 배치했다.
- 사람이 결정한 내용: 공유한 목재 상자 사진과 같은 방향으로 아이템 박스를 만든다.
- 결과: closed·empty·filled 3상태와 실제 포커 화면 적용 시안을 만들었다.
