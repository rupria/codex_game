# 상점 탄약·커뮤니티 공개·포커 아이템 상자 인계 0.3.3

## 사용자 확정 방향

- 상점 탄약 아이콘을 납작한 기호가 아니라 실제 리볼버 탄환에 가까운 픽셀 아트로 개선한다.
- 커뮤니티 카드 공개 시 기존 UI를 잠시 가리고 카드만 집중해서 보여주는 단독 공개 화면을 사용한다.
- 포커 라운드의 플레이어·AI 아이템 박스는 서부 목재 운반 상자 형태로 바꾼다.

## 1. 상점 탄약 UI

Unity 경로: `Assets/Art/Prototype/UI/BarShop_0_3_3`

- `bar_shop_bullet_realistic_24x40_0_3_3.png`: 기본 황동 탄환
- `bar_shop_bullet_realistic_shine_24x40_0_3_3.png`: 구매·호버 강조
- `bar_shop_bullet_realistic_low_24x40_0_3_3.png`: 탄약 부족 상태
- `bar_shop_ammo_panel_200x58_0_3_3.png`: 새 탄환이 적용된 기존 규격 패널

탄두는 구리색, 탄피는 황동색, 림과 프라이머는 어두운 금속색으로 분리했다. 탄약 수치는 패널 오른쪽 빈 영역에 기존 런타임 텍스트로 표시한다.

## 2. 커뮤니티 카드 단독 공개

Unity 경로: `Assets/Art/Prototype/UI/Halli_0_3_3`

- `community_reveal_backdrop_960x540_0_3_3.png`: UI가 없는 원형 테이블+중앙 스포트라이트 배경
- `community_reveal_glow_256_0_3_3.png`: 카드 뒤에 배치하는 투명 광원·십자 플레어
- 실제 카드 뒷면과 앞면은 현재 덱의 카드 이미지를 그대로 사용한다.

연출 순서(총 약 1.29초):

1. 뒷면 작은 카드 등장: 0.18초
2. 중앙으로 확대: 0.18초
3. 폭을 줄여 측면 상태: 0.10초
4. 앞면으로 교체하며 폭 복원 시작: 0.10초
5. 앞면 전체 노출: 0.18초
6. 광원·모서리 프레임·입자와 함께 확대 고정: 0.55초

연출 중 기존 전투 UI는 표시하지 않고 입력을 잠근다. 마지막 고정 이후 공개 카드를 상단 커뮤니티 슬롯으로 축소 이동시키고 일반 할리갈리 화면을 복원한다. 예시 J♣는 스토리보드 확인용이며 런타임에서는 실제 공개 카드 데이터를 사용한다.

## 3. 포커 아이템 상자

Unity 경로: `Assets/Art/Prototype/UI/Poker_0_3_3`

- `poker_item_crate_closed_112x96_0_3_3.png`: 상대 아이템 비공개 또는 잠김
- `poker_item_crate_empty_112x96_0_3_3.png`: 아이템 없음
- `poker_item_crate_filled_112x96_0_3_3.png`: 아이템 보유

상자는 목재 판자, 어두운 틈, 모서리 보강, 화인 문양을 포함한 3/4 시점이다. 플레이어와 AI 모두 상자를 뒤집지 않고 동일한 테이블 시점으로 배치한다. AI 아이템이 비공개라면 `closed`, 플레이어가 확인 가능한 아이템이 있다면 `filled`를 사용한다.

권장 960×540 배치:

- AI 아이템 상자: `(642, 100, 112, 96)`
- 플레이어 아이템 상자: `(642, 346, 112, 96)`

## 4. 적용 규격

- Texture Type: Sprite (2D and UI)
- Filter Mode: Point
- Compression: None
- Mip Map: Off
- Alpha Is Transparency: On
- 정수 배율 우선

## 5. 완료 조건

- 상점 탄약 아이콘에서 탄두·탄피·림이 작은 화면에서도 구분된다.
- 커뮤니티 공개 중 기존 UI가 보이지 않고 뒷면→측면→앞면 전환이 읽힌다.
- 공개되는 카드가 예시 J♣에 고정되지 않고 실제 카드 데이터와 일치한다.
- 포커 아이템 박스의 closed·empty·filled 상태가 명확히 구분된다.
- AI 상자가 뒤집히거나 테이블 밖으로 튀어나오지 않는다.
