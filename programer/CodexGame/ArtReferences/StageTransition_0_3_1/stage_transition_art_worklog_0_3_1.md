# #26 스테이지 이동 연출 아트 진행 기록 0.3.1

## 상태

- 상태: 진행 중
- 기준 이슈: #26
- 기준 아트: `BarShop_0_3_0`
- 작업 브랜치: `codex/art-bar-shop-0.3.0`
- 담당 범위: 아트 에셋, 연출 시각 규격, Unity 교체 경계
- 제외 범위: 상태 머신, 씬 로딩, 입력 잠금, 실제 카메라 및 조명 코드

## 확인된 누락

현재 구현은 `NextStageTransition` 진입 후 약 1.2초 동안 입력을 잠그고 안내 상태를 보여 주는 수준이다. 가게를 나서는 동작, 이동감, 문 통과, 암전, 로딩 피드백을 보여 주는 아트와 시각 명세가 없다.

## 제작 범위

1. 상점 UI가 정리된 뒤 살룬 출구로 시선이 이동하는 960×540 장면
2. 1인칭 보행감을 보조하는 부츠 먼지·화면 비네트 오버레이
3. 좌우 살룬 스윙도어의 닫힘·열림 상태 및 애니메이션 프레임
4. 문 통과 후 사용할 페이드 마스크와 무문자 로딩 표시
5. `상점 정리 → 뒤로 물러남 → 문 접근 → 문 열림 → 암전 → 다음 스테이지` 스토리보드/GIF
6. Aseprite 원본, 좌표·프레임·타이밍·ArtSet Key 카탈로그, 프로그래머 인계서

## 연출 원칙

- 현재 게임의 1인칭 테이블 시점을 유지한다.
- 화면 속 플레이어 캐릭터를 새로 노출하지 않고 카메라 이동과 문 반응으로 퇴장을 전달한다.
- 배경은 강한 고정 조명을 굽지 않은 어두운 서부 살룬 톤으로 제작한다.
- Unity Spot Light와 카메라 이동이 주 연출을 담당하고, 2D 에셋은 교체 가능한 배경·문·FX·로딩 레이어로 분리한다.
- 이미지에 현지화 문자열을 굽지 않는다.
- 로딩이 즉시 끝나도 전환 완료 콜백은 한 번만 처리할 수 있도록 루프성 로딩 애니메이션과 완료용 페이드 상태를 분리한다.
