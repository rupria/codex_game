카드 정보 가독성 아트 0.06

GitHub Issue #10과 아트_변경요청_카드정보가독성_0.06.md를 기준으로 만든 개발 전달용 아트 세트다.
기존 Cards와 생성기는 수정하지 않고 Cards_0_06에 별도 보관한다.

[공통 규격]
- 카드 크기: 64×90 px, RGBA PNG
- 좌상단: 포커 랭크 A, 2–10, J, Q, K
- 우상단: 큰 문양 스페이드, 하트, 다이아, 클로버
- 색상: 스페이드·클로버는 검정/청록, 하트·다이아는 적색
- 카드 뒷면: 기존 확정 시안의 종·해골 문양 유지

[게임별 세트]
- 할리갈리: 문양과 같은 중앙 해골 엠블럼 1–3개. 총 156장.
- 포커 숫자 카드 2–10: 일반 플레잉 카드처럼 랭크와 같은 개수의 문양을 표준 핍 배열로 배치하며 해골을 사용하지 않는다.
- 포커 A·J·Q·K: 같은 프레임과 색상을 유지하면서 해골 에이스·잭·퀸·킹 디자인을 사용한다. 포커 전체는 총 52장이다.
- 3장 포커 손패는 좌상단 랭크와 우상단 문양이 겹친 상태에서도 보이도록 간격을 확인했다.

[개발 연결 경로]
- 카탈로그: Assets/Art/Prototype/Cards_0_06/card_art_catalog_0_06.json
- 할리갈리: Assets/Art/Prototype/Cards_0_06/halli_variants/
- 포커: Assets/Art/Prototype/Cards_0_06/poker_variants/
- 공통 뒷면: Assets/Art/Prototype/Cards_0_06/card_back.png

[포커 검수 프리뷰]
- 현재 방향: card_poker_direction_standard_pips_skull_faces_0_06.png
- 전체 52장: card_poker_full_deck_preview_0_06.png
- 3장 손패: card_poker_hand_3_preview_0_06.png
- card_poker_direction_legacy_no_skull_0_06.png는 변경 전 기록이며 현재 구현 기준으로 사용하지 않는다.

[담당 범위와 단계별 사용 구분]
- 아트 작업 완료: 할리갈리 카드와 포커 카드는 서로 다른 폴더와 카탈로그 배열로 분리되어 있다.
- 할리갈리 단계: halliCards 및 halli_variants 경로를 사용한다.
- 포커 단계: pokerCards 및 poker_variants 경로를 사용한다.
- 두 단계는 card_back.png만 공통으로 사용한다.
- 개발 연결 필요: 현재 아트 에셋 분리는 완료됐지만 게임 단계가 해당 세트를 자동 선택하도록 만드는 런타임 연결은 개발 담당 작업이다.
- 기존 Cards 경로와 기존 생성기는 보존했으므로 0.06 적용 시 반드시 Cards_0_06 경로를 명시한다.

모든 Unity 에셋에는 .meta 파일이 포함되어 있다.
카탈로그에는 게임별 카드 경로, 랭크, 문양과 할리갈리 해골 개수가 기록되어 있다.

[레퍼런스와 권리 확인]
- 기본 프레임·팔레트·뒷면: 사용자가 확정한 카드 시트
- 포커 표준 핍·해골 페이스 카드 방향 시안: OpenAI 내장 이미지 생성 도구로 제작한 내부 레퍼런스
- 외부 무료/유료 에셋 팩은 사용하지 않았다.
- 공개 배포 전 프로젝트의 최종 라이선스·권리 검토 절차를 따른다.
