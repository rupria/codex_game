- 제외 범위: 카드 목록 바인딩 코드, 렌더 순서·클리핑 코드, HP 상태 코드

## 사용자 확인 사항

1. 화면 좌측 상단에 잘려 보이는 불필요한 카드 이미지를 노출하지 않는다.
2. 플레이어·AI HP 하트를 서부 픽셀 UI에 맞는 새 디자인으로 교체한다.
3. 좌측 하단 획득 카드 트레이는 빈 카드 슬롯 3개를 상시 표시하지 않고 실제 획득 카드만 왼쪽부터 보여 준다.
4. 획득 수치와 카드 이미지 목록은 반드시 동일한 `PlayerAcquiredCards` 원본을 사용한다.
5. 좌·우 펼치기 영역의 최근 카드 2장은 숫자·문양·해골 표시를 동시에 읽을 수 있을 만큼 간격을 벌린다.

## 확인된 구현 원인 후보

- 현재 `AcquiredCardFanLayout`은 카드 1장일 때 트레이의 오른쪽 끝에 정렬한다. 사용자 수정안은 아이템/상태 원형 영역 다음부터 왼쪽 정렬이다.
- 현재 트레이 배경은 원형 영역과 빈 카드 슬롯 3개를 이미지에 굽고 있어 실제 카드 수와 별개로 4칸이 보인다.
- 수치 라벨은 `PlayerAcquiredCount`, 카드 렌더는 `PlayerAcquiredCards.Count`를 사용하므로 둘이 다른 의미라면 화면 불일치가 발생할 수 있다.
- 좌측 상단 잘린 카드는 승인된 `PublicCard`, `AiDeck`, `PlayerDeck` 영역 밖의 잔존 렌더/애니메이션 클리핑을 확인해야 한다.
- 현재 좌·우 카드 배치는 96px 카드에 28px 간격만 사용해 이전 카드가 약 29%만 보인다. 최근 2장을 계산할 수 있도록 80~84px 간격으로 확대해야 한다.

- 좌·우 판정 카드 최근 2장 가독성 배치 프리뷰
