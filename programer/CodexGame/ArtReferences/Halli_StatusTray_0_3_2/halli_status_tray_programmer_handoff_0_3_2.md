## 2. 펼친 카드 가독성

현재 `HalliBoardLayout`은 96×135px 카드에 28px 간격을 사용한다. 이를 최근 2장 전용 배치로 교체한다.

권장 960×540 좌표:

- 플레이어/좌측 더미: 첫 카드 `(190, 194, 96, 135)`, 최근 카드 `(274, 194, 96, 135)`
- AI/우측 더미: 첫 카드 `(590, 194, 96, 135)`, 최근 카드 `(674, 194, 96, 135)`
- 간격: 84px, 겹침: 12px
- 그리기 순서: 이전 카드 → 최근 카드
- 보이는 카드: 각 더미 최근 2장

카드가 2장 미만이면 첫 위치부터 사용한다. 이 간격에서는 두 카드의 숫자, 문양, 해골 수가 모두 노출된다. 비교 이미지는 `preview/halli_exposed_pair_readability_0_3_2.png`를 따른다.

## 3. 플레이어 획득 카드

- 트레이 전체: 기존 `(34, 390, 378, 130)` 유지 가능
- 배경: `player_acquired_tray_378x130_0_3_2.png`
- 카드 렌더 영역: 트레이 로컬 좌표 `(112, 29)`부터 시작
- 카드 크기: 56×78px
- 카드 간격: 52px(4px 겹침)
- 정렬: 왼쪽 정렬
- 표시: 실제 획득 후보 카드 최대 3장
- 렌더 순서: 획득 순서대로 왼쪽 → 오른쪽

중요: 획득 수치와 카드 목록 모두 `PlayerAcquiredCards.Count`를 기준으로 한다. 별도의 누적 수치가 필요하면 다른 라벨로 명시하고 획득 후보 카드 수와 혼용하지 않는다.

## 4. AI 상태 패널

- `ai_status_panel_224x130_0_3_2.png`에는 카드 뒷면이나 덱 이미지가 없다.
- 상단 중앙 AI 덱이 이미 존재하므로 우측 하단 카드뭉치 렌더는 제거한다.
- 좌측 원형 영역: AI 판단 중 스피너
- 우측 3칸: 라운드 승리 표시 또는 상태 칸
- 카드 보유 수가 필요하면 텍스트 수치로만 표시한다.

## 5. 좌측 상단 잘린 카드 제거

승인된 카드 표시 영역은 `PublicCard`, `AiDeck`, `PlayerDeck`, `LeftPile`, `RightPile`뿐이다. 화면 좌측 상단 잔존 카드는 새 아트 리소스가 아니라 렌더 위치/애니메이션 정리 문제다.

- 전환 시작 시 이전 카드 이동 렌더러를 비활성화하거나 풀로 반환한다.
- 이동 중 카드 Rect를 `PlayableViewport`로 클리핑한다.
- 화면 밖 좌표에 남은 카드 렌더 호출을 건너뛴다.
- 할리갈리 재진입 시 이전 프레임의 이동 상태를 초기화한다.

## 6. HP 하트

- 평상시: 현재 HP만 `filled`, 나머지는 `empty`
- 피격 프레임: 감소 대상 한 칸을 짧게 `damage`로 교체한 뒤 `empty`
- 권장 크기: 원본 24×24 정수 배율
- 플레이어는 청록, AI는 붉은색을 유지한다.

## 7. 적용 확인

1. HP 3/3, 2/3, 1/3, 0/3 상태를 양측 모두 확인한다.
2. 획득 카드 0·1·2·3장에서 실제 카드와 수치가 일치하는지 확인한다.
3. 좌우 펼친 카드 두 장의 숫자·문양·해골 수가 모두 읽히는지 확인한다.
4. 카드 이동 중 좌측 상단과 화면 경계에 잔존 카드가 생기지 않는지 확인한다.
5. 우측 하단에 중복 카드뭉치가 없는지 확인한다.
