# PrivateSelection 0.6.3 아트 인계

상태: `ART_HANDOFF_READY`

이 문서는 사용자 승인 화면을 최신 기준으로 고정한다. `PrivateSelection_0_6_2`의 작은 완료 버튼 배치는 폐기하며, 이후 구현은 이 문서와 `private_selection_art_catalog_0_6_3.json`만 참조한다.

승인 화면 증거: `preview/approved_private_selection_reference_1680x945_0_6_3.png`

## 화면 계약

- 좌측 상단: 커뮤니티 카드 최대 2장.
- 좌측 하단: 세로 공간을 사용하는 단일 `패 확정` 액션 패널.
- 우측: 획득 카드 풀 전용 영역. 다른 액션이나 카운트 패널을 넣지 않는다.
- 획득 후보는 최대 5장, `첫 줄 4장 + 둘째 줄 1장`으로 배치한다.
- 후보 카드 프레임은 카드 풀 외곽 프레임에 붙이지 않는다. 모든 방향 최소 안전 여백은 16px이다.

## 960×540 기준 좌표

| 요소 | 좌표/크기 |
|---|---|
| 패 확정 비주얼 | `(72, 366, 184, 120)` |
| 패 확정 클릭 영역 | `(64, 358, 200, 136)` |
| 패 확정 제목 | `(80, 388, 168, 40)` |
| 선택 진행 정보 | `(80, 438, 168, 28)` |
| 획득 카드 풀 외곽 | `(270, 124, 620, 328)` |
| 획득 카드 안전 영역 | `(286, 140, 588, 296)` |
| 카드 크기 | `112×150` |
| 첫 줄 시작 | `(326, 140)` |
| 첫 줄 간격 | `20px` |
| 둘째 줄 5번째 카드 | `(326, 286)` |

첫 줄 X 좌표는 `326, 458, 590, 722`이다. 네 장을 카드 풀 안에서 가운데 정렬하여 좌우 프레임과 각각 56px 간격을 둔다. 카드 풀 상단·하단과의 거리는 각각 16px 이상 유지한다. 다섯 번째 카드는 공유된 승인 화면처럼 둘째 줄 첫 번째 열에 둔다.

## 런타임 연결

`PrivateSelectionUiArtSet`:

- `ConfirmIdle` → `private_selection_hand_lock_idle_184x120_0_6_3.png`
- `ConfirmHover` → `private_selection_hand_lock_hover_184x120_0_6_3.png`
- `ConfirmActive` → `private_selection_hand_lock_active_184x120_0_6_3.png`
- `ConfirmDisabled` → `private_selection_hand_lock_disabled_184x120_0_6_3.png`

모달 외곽은 아래 승인본을 계속 사용한다.

- `PrivateSelection_0_6_1/private_selection_modal_panel_clean_860x456_0_6_1.png`

프로그래머 연결 시:

1. 기존 별도 선택 카운트 패널 렌더링을 제거한다.
2. 좌하단에는 `DrawConfirm` 한 개만 둔다.
3. 제목은 `패 확정`, 하위 정보는 `선택 {selected}/{required} · ENTER`로 표시한다.
4. 우측 획득 카드 풀 내부에는 버튼을 생성하지 않는다.
5. 카드 데이터 순서, 선택 로직, 사운드 연결은 변경하지 않는다.

## 검수 조건

- `패 확정` 패널이 좌측 하단에 한 개만 보인다.
- 첫 줄 후보 카드들이 카드 풀 좌우 프레임에서 각각 56px 떨어져 있다.
- 첫 줄 후보 카드들이 카드 풀 위쪽 프레임에서 16px 이상 떨어져 있다.
- 둘째 줄 카드 아래로 16px 이상 여백이 남는다.
- 획득 후보는 최대 5장, 4+1 배치다.
- 커뮤니티 카드는 최대 2장이다.
- 한국어·영어에서 제목과 진행 정보가 패널 밖으로 잘리지 않는다.
- 기존 카드 데이터, 선택 상태, 사운드 및 쇼다운 전환에는 회귀가 없다.
