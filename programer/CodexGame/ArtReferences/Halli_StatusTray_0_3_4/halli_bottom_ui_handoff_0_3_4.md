# 할리갈리 하단 UI 0.3.4 프로그래머 인계

## 확정 변경

- 플레이어 하단만 유지한다.
- 왼쪽은 아이템 소켓 1개, 오른쪽은 획득 카드가 왼쪽부터 겹쳐 쌓이는 연속 영역이다.
- 빈 카드 슬롯 구분선과 `+` 표시는 사용하지 않는다.
- 우측 하단 AI 획득 카드 패널은 통째로 제거한다. AI 덱은 상단 중앙의 기존 덱만 사용한다.
- AI 판단 상태와 붉은 라운드 승리 표식 3개는 패널 없이 독립 배치한다.

## 완료 조건

1. 좌측 하단에 4칸 빈 슬롯이 보이지 않는다.
2. 실제 획득 카드 목록과 표시 카드가 일치한다.
3. 우측 하단 AI 카드 뒷면·로딩 원·3칸 카운터가 보이지 않는다.
4. 16:9 화면에서 중앙 덱과 벨 조작부를 침범하지 않는다.
