# 상점 총알 주머니 UI 0.3.8 — 최종 정적 이미지

연결 이슈: [#36](https://github.com/rupria/codex_game/issues/36)

## 최종 확정

상점 우측 하단 총알 주머니는 아래 이미지 한 장만 사용합니다.

- 런타임 기준: `Assets/Art/Prototype/UI/BarShop_0_3_8/bar_shop_ammo_pouch_static_5_180x150_0_3_8.png`
- 호환 파일: `bar_shop_ammo_pouch_pile_5_180x150_0_3_8.png`도 같은 이미지로 갱신됨
- 표시 내용: 열린 가죽 주머니와 세워진 총알 5발
- 배경: 투명
- 표시 크기: 180×150 px

## 연결 금지

이 주머니 UI는 장식용 정적 이미지입니다. 다음 기능을 연결하지 않습니다.

- `BulletCount`에 따른 총알 추가·제거
- 개별 총알 자식 오브젝트 생성
- 손으로 주머니를 가리는 연출
- 총알 던지기·튕기기·붓기 연출
- 구매 전후 주머니 상태 전환
- 빈 주머니 상태

기존 빈 주머니, 개별 총알, 손, 던지기·붓기 스프라이트는 과거 검토 자료이며 런타임에 연결하지 않습니다.

## 원본과 제작 방식

- 승인 원본: `references/approved_static_five_round_pouch_chroma_20260815.png`
- 투명 고해상도 원본: `source/bar_shop_ammo_pouch_static_5_hires_alpha_20260815.png`
- Aseprite 원본: `source/bar_shop_ammo_pouch_static_5_0_3_8.aseprite`
- 처리: 원본 자홍색(`#ff00ff`) 배경 제거 → 알파 영역 기준 크롭 → 최근접 보간으로 180×150 캔버스 배치
- 형태·총알 수·색·픽셀 표현은 승인 이미지 그대로 유지

- [ ] 주머니가 화면에 한 장만 보인다.

- [ ] 주머니 위에 사각 프레임이나 색 배경이 없다.

- [ ] 손, 개별 총알, 던지기·붓기 애니메이션이 재생되지 않는다.
- [ ] 기존 재화 계산과 구매 기능은 아트 표시와 독립적으로 정상 동작한다.
