# ImageGen 작업 기록 0.08

## Brass Sheriff Joker

사용자 제공 J/Q/K 레퍼런스를 품질 기준으로 삼아, 크림색 카드·잘린 모서리·서부 해골 보안관·청록/검정/황동/적색 팔레트·회전 대칭 구도의 고해상도 픽셀 카드로 제작했습니다. 최초 종을 든 버전은 폐기하고, 인물과 카드 틀을 유지한 채 종을 서부식 6연발 리볼버로 교체했습니다.

## Crimson Cardsharp Joker

동일한 카드 품질과 회전 대칭을 유지하되 보안관의 색상 변형이 되지 않도록, 장미·카드·포커칩·광대 장식 모자를 사용하는 여성 해골 카드샤프 캐릭터로 분리 설계했습니다.
