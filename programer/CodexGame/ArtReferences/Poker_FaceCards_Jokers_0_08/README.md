# Poker Face Cards + Jokers 0.08

프로그래머 적용용 서부 해골 카드 패키지입니다.

## 확정 범위

- J/Q/K 4문양: 12장
- Joker: 2장
  - `card_poker_joker_brass_sheriff_revolver.png`
  - `card_poker_joker_crimson_cardsharp.png`
- 카드 뒷면과 A~10 숫자 카드는 기존 확정 디자인을 유지합니다.

## 적용 우선순위

1. `Assets/Art/Prototype/Cards_0_08/poker_face_cards_hires`
2. 성능·UI 제약이 있을 때 `poker_face_cards_112x156`
3. 기존 56×78 슬롯 강제 호환이 필요할 때만 `poker_face_cards_56x78`

고해상도본이 시각 기준입니다. 56×78은 호환용 축소본이라 확대 UI에는 사용하지 않습니다.

## 중요

- 종을 든 Sheriff Joker는 폐기되었습니다.
- 확정 Sheriff Joker는 리볼버를 든 버전입니다.
- `Jokers_0_07`의 저해상도 조커는 이 패키지로 대체합니다.
- 이 패키지는 아트 파일과 매핑 자료만 제공합니다. 덱 편입 수량·효과는 프로그래머/기획에서 연결합니다.
