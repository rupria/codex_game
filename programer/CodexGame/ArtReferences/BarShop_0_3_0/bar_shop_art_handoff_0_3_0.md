## Unity 연결 요청

1. `StageWon → BarShop → NextStageTransition` 상태 전이는 프로그래머가 연결한다.
2. `bar_shop_art_catalog_0_3_0.json`의 Key를 ArtSet 또는 카탈로그 데이터에 주입한다.
3. 파일명·Resources 경로를 UI 코드에 직접 하드코딩하지 않는다.
4. 상품 슬롯 프레임·아이콘·버튼 상태를 각각 교체 가능한 Sprite 참조로 둔다.
5. 상점 진입 시 전투 입력과 전투 타이머를 차단한다.
6. 리롤 전에는 idle/hover/pressed, 사용 후에는 disabled만 사용한다.
7. 리롤 클릭 영역과 다음 진행 클릭 영역은 보이는 버튼 크기와 일치시킨다.
8. 다음 진행은 한 번만 처리하고 중복 보상·중복 스테이지 증가를 막는다.
9. 총알 수와 HP 숫자/현지화 문자열은 런타임 텍스트로 출력한다.

## 배경 조명

- 배경에는 천장 조명 기구와 강한 고정 광원을 넣지 않았다.
- Unity 프레젠테이션 리그의 Spot Light로 상점 진입·상품 강조·다음 진행 시 광량을 조절한다.
- 상점 진입 시 카운터 와이드, 상품 선택 시 선택 슬롯만 약한 런타임 강조를 권장한다.

## 완료 검증 기준

- 초기 화면에 상품 3개가 동일 규격으로 보인다.
- 리롤 후 세 아이콘이 모두 교체되고 리롤 버튼이 disabled가 된다.
- 두 번째 리롤을 유도하는 활성 아트 상태가 남지 않는다.
- 총알과 HP 영역이 960×540 안전 영역 안에 있다.
- 상품명·가격·내부 개발 문구가 이미지에 구워져 있지 않다.
- 모든 단일 UI 에셋은 투명 모서리를 유지한다.
- 1280×720, 1920×1080에서는 기준 좌표를 Canvas Scaler로 비례 확대한다.
