## 작업 목표

스테이지 클리어 후 보상 정산을 확인하고 다음 스테이지로 이동하기 전에 방문하는 서부 살룬 바 상점 화면을 제작한다. 실제 구매·아이템 효과·총알 차감은 구현하지 않으며, 교체 가능한 더미 아트와 UI 상태만 제공한다.

## 확정 시각 규칙

- 기존 서부 살룬의 어두운 목재·황동·짙은 녹색 팔레트를 유지한다.
- 화면 중앙에 상품 3개를 같은 크기로 배치한다.
- 상품 이름·가격·설명은 이미지에 굽지 않고 Unity 현지화 텍스트로 표시한다.
- 구매 버튼은 제작하지 않으며 상품 슬롯은 보기 전용 상태로 표현한다.
- 리롤은 1회 무료 사용 전/후가 명확해야 한다.
- `다음 가게로`는 상점 종료의 유일한 진행 버튼으로 강조한다.
- HP는 #23 규격의 filled/empty 하트로 표시한다.
- 총알은 아이콘과 숫자 텍스트용 앵커를 분리한다.
