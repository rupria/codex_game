# 바 상점 버튼·탄약 구매 연출 0.3.4 프로그래머 인계

## 버튼

- 리롤/계속 버튼에서 화살표·회전 아이콘을 제거한다.
- PNG에는 글자를 굽지 않는다. 기존 현지화 문자열 `UI_BAR_REROLL_FREE`, `UI_BAR_REROLL_USED`, `UI_BAR_CONTINUE`를 버튼 중앙에 표시한다.
- 기존 슬롯 호환 크기:
  - `bar_shop_reroll_{idle|hover|pressed|disabled}_180x56_0_3_4.png`
  - `bar_shop_continue_{idle|hover|pressed}_200x56_0_3_4.png`
- 공용 원본: `bar_shop_text_button_220x56_{state}_0_3_4.png`

## 탄약 주머니

- `bar_shop_ammo_pouch_180x150_0_3_4.png`을 우측 하단 Safe Area 안에 둔다.
- 탄약 수 표시는 기존 좌측 상단 패널을 유지한다. 주머니는 구매 피드백의 발사 지점이다.

## 구매 모션

1. 구매 확정 시 주머니가 0.06초 아래로 눌린다.
2. 총알 1발이 주머니에서 분리되어 상점 주인의 손/가슴 쪽으로 포물선 이동한다.
3. 총 시간 0.50초, 회전 540도 시계 방향, 정점에서 1.15배 확대 후 접촉 시 0.8배로 축소한다.
4. 접촉 순간 0.08초 황동 스파크를 표시하고, 그 시점에 탄약 수를 차감한다.
5. 연출 중 구매 입력은 0.60초 잠근다. 잔액 부족이면 발사하지 않고 주머니를 0.12초 좌우로 흔든다.

기준 포인트(960×540): 시작 `(868,468)`, 제어점 `(735,305)`, 도착 `(494,182)`.
스핀 참고: `bar_shop_bullet_toss_spin_384x64_0_3_4.png`.
스토리보드: `preview/bar_shop_bullet_purchase_storyboard_1920x270_0_3_4.png`.

## 완료 조건

- 하단 두 버튼에 아이콘이 남지 않고 현지화 텍스트가 보인다.
- 구매 성공 때 총알이 주머니에서 상점 주인에게 날아간다.
- 탄약 차감과 아이템 획득은 접촉 프레임에 동기화된다.
