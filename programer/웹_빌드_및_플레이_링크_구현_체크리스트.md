# 웹 빌드 및 플레이 링크 구현 체크리스트

- 역할: 프로그래머
- 상태: 구현 전
- 기준일: 2026-08-05
- 적용 브랜치: `dev`
- 배포 브랜치: `pub` — 사용자 별도 요청 없이는 커밋·푸시·병합하지 않음

이 문서는 프로그래머가 필수 제출 형식과 플레이 링크 요구사항을 구현할 때 사용하는 작업 체크리스트다. 규칙 원본은 `rules` 폴더이며, 이 문서는 규칙을 복제하거나 대체하지 않는다.

## 구현 시작 조건

- [ ] 합의된 게임 기획과 핵심 플레이 루프가 전달됐다.
- [ ] 시작·진행·종료 및 성공·실패 조건이 정의됐다.
- [ ] 첫 화면에 표시할 목표, 조작법과 실행 방법이 정의됐다.
- [ ] 지원 브라우저, 화면 크기와 입력 방식이 정해졌다.
- [ ] 기술 스택과 배포 환경이 확정됐다.

## 필수 웹 빌드

- [ ] 별도 설치 없이 브라우저에서 실행된다.
- [ ] 정적 또는 서버 빌드 절차가 명령어 단위로 재현 가능하다.
- [ ] 새 환경에서 의존성 설치부터 빌드까지 재현된다.
- [ ] 빌드 결과에 비밀번호, API 키와 인증 토큰이 포함되지 않는다.
- [ ] 외부 API 장애, 인증 실패와 비용 한도가 기본 플레이를 막지 않는다.
- [ ] 새로고침 후 게임을 다시 시작할 수 있다.
- [ ] 치명적 콘솔 오류, 무한 로딩과 진행 차단이 없다.

## 공개 플레이 링크

- [ ] 공개 HTTPS URL을 제공한다.
- [ ] 초대, 개별 승인, 지역 제한과 유료 결제 없이 접속된다.
- [ ] 링크 진입 후 추가 설치 없이 첫 플레이를 시작할 수 있다.
- [ ] 로그인은 가능하면 제거한다.
- [ ] 로그인이 불가피하면 심사용 테스트 계정 흐름이 실제로 작동한다.
- [ ] 인증 실패 시 플레이어가 이해할 수 있는 안내가 표시된다.
- [ ] 심사 기간 동안 URL을 유지할 수 있는 배포 구조다.

## 첫 화면과 실행 안내

- [ ] 링크를 연 직후 목표를 확인할 수 있다.
- [ ] 조작법과 실행 방법을 즉시 확인할 수 있다.
- [ ] 첫 30초 안에 핵심 조작과 목표를 이해할 수 있다.
- [ ] 키보드, 마우스 또는 터치 등 지원 입력이 실제 화면 안내와 일치한다.
- [ ] 게임 화면과 제출 설명의 조작 안내가 서로 일치한다.

## `pub` 통합 준비

- [ ] `dev` 기준 빌드 명령과 필요한 환경을 문서화한다.
- [ ] 배포 산출물의 생성 위치와 제외 파일을 문서화한다.
- [ ] 공개 URL 배포 및 갱신 절차를 재현할 수 있다.
- [ ] 롤백 또는 이전 정상 빌드 복구 방법을 기록한다.
- [ ] 빌드 식별자, 커밋 SHA와 배포 시각을 연결한다.
- [ ] 사용자의 명시적 요청 전에는 `pub`에 변경을 반영하지 않는다.

## 프로그래머 자체 검증

- [ ] 로컬 개발 실행을 확인한다.
- [ ] 프로덕션 웹 빌드 성공을 확인한다.
- [ ] 빌드 결과를 로컬 서버에서 실행한다.
- [ ] 공개 HTTPS URL에서 핵심 플레이 루프를 완주한다.
- [ ] 새 브라우저 또는 시크릿 창에서 링크 접근을 확인한다.
- [ ] 테스트하지 않은 범위와 알려진 제한을 기록한다.

## 역할 인계 정보

프로그래머는 다른 역할의 판정을 대신하지 않고 다음 정보만 전달한다.

- 변경 범위와 주요 구현 내용
- 대상 브랜치와 커밋 SHA
- 실행, 빌드와 배포 명령
- 공개 플레이 URL과 배포 시각
- 지원 환경과 입력 방식
- 테스트 계정이 필요한 경우 사용 흐름
- 알려진 접근 제한과 미검증 범위
- 재현 가능한 결함 확인 방법

## 완료 차단 조건

다음 중 하나라도 해당하면 프로그래머 구현 완료로 보고하지 않는다.

- 웹 프로덕션 빌드가 실패한다.
- 공개 HTTPS 플레이 URL이 없다.
- 설치, 초대 또는 개별 승인 없이는 플레이할 수 없다.
- 링크 접속 후 첫 플레이를 시작할 수 없다.
- 조작법과 실행 방법을 즉시 확인할 수 없다.
- 외부 API나 비밀 키 문제로 기본 플레이가 막힌다.
- 빌드와 배포 절차를 재현할 수 없다.
