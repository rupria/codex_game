## 한 문장 설명

딜러가 먼저 공개한 공용 카드 한 장을 기준으로, 두 필드에서 동일 문양의 표시 수 합이 정확히 3인 곳을 찾아 손패 세 장을 모으고, 마지막 공용 카드가 열린 뒤 완성된 5장으로 딜러와의 승패를 예측한다.

## 타깃 플레이어와 플레이 상황

- 짧은 시간에 끝나는 브라우저 카드·퍼즐 게임을 원하는 플레이어
- 포커 족보를 완전히 외우지 않았어도 화면 안내를 통해 선택하려는 플레이어
- 공개 HTTPS 링크에 접속해 설치·로그인·초대·별도 승인 없이 마우스 또는 터치로 바로 플레이하는 상황

## 링크 진입부터 첫 플레이까지의 기획 흐름

1. 플레이어가 제출된 공개 HTTPS 링크를 연다.
2. 첫 화면에서 게임 목표, 핵심 규칙, 조작법과 시작 방법을 즉시 확인한다.
3. `게임 시작` 버튼 한 번으로 첫 번째 공용 카드와 최초 필드가 열린다.
4. 최초 필드는 한쪽만 `같은 문양 합계 = 3`이 되도록 구성해 첫 성공을 유도한다.
5. 플레이어는 별도 설명 없이 카드 3장 획득, 승패 예측, 결과 확인까지 한 라운드를 완주한다.
6. 결과 화면에서 즉시 같은 흐름으로 다시 시작할 수 있다.

현재 프로토타입에는 회원가입과 로그인을 포함하지 않는다. 추후 불가피하게 인증이 추가될 경우, 테스트 계정 입력 위치와 인증 실패 시 대응 안내를 첫 화면에서 찾을 수 있도록 별도 기획해야 한다.

### 첫 화면 필수 안내

- 목표: 필드에서 카드 3장을 모아 완성한 5장으로 딜러전 승패를 예측한다.
- 핵심 규칙: `같은 문양의 표시 수 합이 정확히 3이면 벨을 누른다.`
- 조작법: 좌우 벨 선택, 보상 카드 선택, 승리·패배 예측은 마우스 또는 터치로 진행한다.
- 실행 방법: `게임 시작` 버튼을 누르면 즉시 첫 라운드가 시작된다.
- 안내 위치: 별도의 외부 문서를 열지 않아도 첫 화면 또는 첫 조작 직전에 항상 확인할 수 있어야 한다.

## 프로토타입 검증 목표

1. 동일 문양과 합계 3을 판별해 벨을 누르는 행동이 직관적인가
2. 두 선택지가 모두 유효할 때 포커 카드 선택이 의미 있는가
3. 첫 공용 카드가 손패 구성의 방향을 제공하는가
4. 마지막 공용 카드 공개가 기대와 반전을 만드는가
5. 완성된 5장으로 딜러와의 승패를 예측하는 순간이 긴장되는가

## 플레이어 목표와 코어 루프

플레이어의 목표는 필드에서 손패 3장을 구성하고, 최종 5장이 딜러보다 강할지 약할지를 정확하게 예측하는 것이다.

`첫 공용 카드 확인 → 좌우 필드 판독 → 벨 선택 → 카드 획득 → 3회 반복 → 마지막 공용 카드 공개 → 승패 예측 → 딜러 쇼다운 → 즉시 재시작`

반복되는 핵심 행동은 다음 두 가지다.

1. 동일 문양의 표시 수 합이 정확히 3인 필드를 찾는다.
2. 유효한 선택지가 둘이면 자신의 포커 가능성에 더 유리한 카드를 고른다.

## 최종 카드 구성

플레이어와 딜러는 각각 총 5장으로 포커 족보를 판정한다.

| 카드 구분 | 플레이어 | 딜러 | 공개 시점 |
|---|---:|---:|---|
| 첫 번째 공용 카드 | 1장 | 1장 | 라운드 시작 |
| 개인 카드 | 필드에서 획득한 3장 | 비공개 3장 | 딜러 카드는 쇼다운 때 공개 |
| 마지막 공용 카드 | 1장 | 1장 | 필드 종료 후 |
| 최종 족보 | 총 5장 | 총 5장 | 승패 비교 시점 |

공용 카드 2장은 플레이어와 딜러가 함께 사용한다.

## 라운드 진행

### 1. 첫 번째 공용 카드 공개

딜러가 공용 카드 한 장을 공개한다. 플레이어는 이 카드의 숫자와 무늬를 보고 페어·트리플, 스트레이트, 플러시 또는 높은 카드 방향을 고려한다.

### 2. 필드 플레이 3회

한 번에 포커 카드 한 장을 획득하며 총 3회 진행한다. 매 회차에는 왼쪽과 오른쪽 두 선택지가 동시에 나타난다.

각 선택지는 다음 정보를 가진다.

- 동일 문양 판정을 위한 시각 정보
- 획득 가능한 포커 카드 1장
- 해당 선택지의 벨 버튼

#### 벨 판정

- 한 선택지 안에서 동일 문양의 표시 수 합이 정확히 3이면 유효하다.
- 한쪽만 유효하면 해당 벨을 눌러 포커 카드를 획득한다.
- 양쪽 모두 유효하면 둘 중 하나를 선택해 해당 포커 카드만 획득한다.
- 양쪽 모두 유효하지 않으면 두 선택지를 교체한다.
- 카드 한 장을 획득하면 다음 필드 회차로 진행한다.

```text
왼쪽 선택지                  오른쪽 선택지
해골 ×1 + 해골 ×2            달 ×2 + 달 ×2
보상 카드: K♥                보상 카드: 7♣

왼쪽: 정확히 3 — 선택 가능
오른쪽: 합계 4 — 선택 불가
```

### 3. 마지막 공용 카드 공개

플레이어가 손패 3장을 모두 모으면 딜러가 마지막 공용 카드 한 장을 공개한다. 이후에는 카드를 교체하거나 추가 획득하지 않는다. 플레이어 손패 3장과 공용 카드 2장을 합쳐 최종 족보를 표시한다.

### 4. 승패 예측

플레이어는 자신의 최종 5장과 족보 이름을 확인한 뒤 `내가 이긴다` 또는 `내가 진다`를 선택한다. 딜러 상대 승률은 표시하지 않는다.

### 5. 딜러 쇼다운

딜러의 비공개 카드 3장을 한 장씩 공개한다. 딜러도 공용 카드 2장과 자신의 카드 3장을 합쳐 총 5장으로 족보를 판정한다.

결과 화면에는 양측 최종 카드, 족보, 실제 승패, 플레이어 예측과 예측 성공·실패를 표시한다.

## 선택·위험·즉각 피드백

| 상황 | 플레이어 선택 | 위험 | 즉각 피드백 |
|---|---|---|---|
| 한 필드만 유효 | 올바른 벨 터치 | 문양 또는 합계 오판 | 유효/오답 표시와 획득 카드 이동 |
| 두 필드 모두 유효 | 필요한 포커 카드 선택 | 미래 조합 가능성을 좁힐 수 있음 | 손패 합류와 현재 가능성 갱신 |
| 마지막 공용 카드 공개 | 추가 선택 없음 | 준비한 조합이 완성되지 않을 수 있음 | 최종 5장과 족보 표시 |
| 승패 예측 | 승리 또는 패배 | 딜러 비공개 3장을 알 수 없음 | 딜러 순차 공개와 예측 결과 표시 |

- 오른쪽 벨 터치
- 양쪽 모두 유효할 때 가져올 카드 선택
- 최종 승리 또는 패배 예측
- 다음 라운드 진행

마우스와 터치 입력을 필수 대상으로 한다. 키보드 입력 지원 여부는 구현 가능성 검토 후 확정한다.

### 필수 화면 정보

## 첫 30초 경험

1. 링크 진입 직후 첫 화면에서 목표, `같은 문양 합계 = 3`, 마우스·터치 조작법과 시작 방법을 보여준다.
2. 플레이어가 `게임 시작`을 누르면 딜러가 첫 공용 카드 한 장을 공개한다.
3. 좌우 필드와 벨 버튼을 보여준다.
4. 최초 필드는 한쪽만 명확하게 유효하도록 구성한다.
5. 벨을 누르면 포커 카드가 손패로 이동해 행동과 결과를 즉시 연결한다.

첫 30초 안에 플레이어가 이해해야 하는 목표는 `정확히 3인 필드의 벨을 눌러 최종 포커 손패를 만든다`이다.

## 3분 감정 곡선

- 초반: 유효한 필드를 발견하는 이해와 작은 성공
- 중반: 두 선택지가 모두 유효할 때 포커 카드를 비교하는 고민
- 후반: 마지막 공용 카드가 족보를 완성하거나 무너뜨리는 기대와 반전
- 결말: 딜러 비공개 카드가 열리며 예측 결과를 확인하는 긴장과 해소
- 재도전: 다른 카드 선택을 했다면 결과가 달라졌을지 확인하고 싶은 욕구

## 성공·실패와 세션 종료

- 라운드 성공: 실제 승패와 플레이어 예측이 일치한다.
- 라운드 실패: 실제 승패와 플레이어 예측이 일치하지 않는다.
- 프로토타입 세션 종료: 한 라운드의 결과 확인 시 종료하며 즉시 재시작할 수 있다.
- 장기 점수, 연승, 체력과 전체 게임 종료 조건은 이번 프로토타입에서 사용하지 않는다.
- 동률 처리 규칙은 구현 인계 전에 확정해야 한다.

## 포함 범위

- 첫 공용 카드 1장 선공개
- 동일 문양 정확히 3 판정
- 좌우 두 개의 필드 선택지
- 필드에서 플레이어 손패 3장 획득
- 마지막 공용 카드 1장 후공개
- 기본 5장 포커 족보 판정
- 승리·패배 예측
- 딜러 카드 공개와 결과 표시
- 한 라운드 재시작

## 제외 범위

- 공격력, 방어력, 체력과 대미지
- 아이템과 특수 능력
- 카드 강화와 덱 빌딩
- 베팅과 배당
- 스토리와 다수의 딜러
- 온라인 대전
- 장기 성장과 저장

## 초기 테스트 가정

- 필드 제한 시간을 사용하지 않는다.
- 딜러가 필드 벨을 먼저 누르지 않는다.
- 오답을 눌러도 즉시 다음 선택지를 다시 제공한다.
- 기본 52장 덱과 조커 없는 5장 포커 족보를 사용한다.
- 한 라운드 종료 후 즉시 다시 시작할 수 있게 한다.

속도 압박과 페널티는 문양 판정과 카드 선택 자체가 재미있다는 결과를 확인한 뒤 추가한다.

- 동률 패 처리

- 초보자를 위한 포커 족보 안내 수준
- 키보드 입력 지원 여부
- 지원 브라우저와 최소 화면 크기

이 문서는 미확정 내용을 포함한 기획 공유 초안이며, 항목이 확정되면 인계 상태를 갱신한다.

## 플레이테스트 질문

- 별도 설명 없이 벨을 누를 수 있는 조건을 이해했는가
- 두 선택지가 모두 유효할 때 카드 선택 이유를 설명할 수 있는가
- 첫 공용 카드가 선택에 영향을 주었는가
- 마지막 공용 카드 공개 순간에 기대 또는 아쉬움을 느꼈는가
- 자신의 승패를 예측할 때 고민이 발생했는가
- 결과 공개가 공정하고 이해 가능했는가
- 한 번 더 플레이하고 싶은가, 그렇다면 이유는 무엇인가

## 후속 비교안

프로토타입 1 검증 후 `필드에서 손패 3장 획득 → 공용 카드 2장 모두 공개 → 승패 예측` 순서를 비교할 수 있다. 이 방식은 계획보다 불확실성과 도박 감정을 강화한다.
