## 1. 문서 목적

사용자가 작성한 게임 진행 플로우 PDF를 구현·검증 가능한 Markdown 흐름으로 변환한다. PDF에 포함된 기획 메모와 미확정 질문은 본 흐름에서 분리하며, 기존 게임플레이 명세에서 이미 확정된 공용 카드 2장과 개인 카드 3장 규칙을 함께 연결한다.

## 2. 전체 게임 흐름

```text
메인 화면
→ 게임 시작 버튼 선택
→ 게임 화면 노출
→ 첫 번째 공용 카드 1장 공개
→ 할리갈리 단계 시작
→ 카드 펼치기와 벨 경쟁 반복
→ 한쪽이 벨 승리 3회 달성
→ 개인 카드 3장 정리
→ 마지막 공용 카드 1장 공개
→ 아이템 사용 여부 확인
→ 패 확정
→ 플레이어와 AI의 5장 포커 승패 확인
→ 승자 보상 / 패자 HP 감소
→ HP 0 확인
   ├─ HP가 남음: 다음 라운드
   └─ HP가 0: 해당 경기 종료
→ 다음 스테이지 또는 종료
```

공용 카드 공개와 최종 5장 구성은 PDF에 연결된 기존 게임플레이 명세의 확정 규칙을 반영했다.

## 3. 메인 화면

메인 화면은 다음 네 항목을 가진다.

- 게임 시작
- 설정
- 게임 가이드
- 종료

### 게임 시작

```text
게임 시작
→ 버튼 선택
→ 게임 화면 노출
→ 첫 번째 공용 카드 공개
→ 할리갈리 단계 시작
```

### 게임 가이드 필수 내용

- `W`: 카드 펼치기
- `Q`: 왼쪽 카드 더미 벨
- `E`: 오른쪽 카드 더미 벨
- 마우스: 중앙 펼치기 영역과 좌우 더미 선택
- 목표: 좌우 더미의 카드를 직접 보고 해골 합계가 정확히 3인 더미를 먼저 선택
- 할리갈리 단계: 먼저 벨 승리 3회를 달성
- 포커 단계: 개인 카드 3장과 공용 카드 2장으로 총 5장 족보 완성

## 4. 할리갈리 단계 시작

### 초기화

1. 플레이어와 AI의 벨 승리 수를 0으로 초기화한다.
2. 양측의 획득 카드 영역을 비운다.
3. 첫 번째 공용 카드 1장을 공개한다.
4. 다음 카드가 놓일 방향을 플레이어 기준 왼쪽으로 지정한다.
5. 중앙 카드 펼치기 영역을 강조하거나 조작 가이드를 표시한다.

### 카드 펼치기 조작

| 입력 장치 | 입력 | 결과 |
|---|---|---|
| 키보드 | `W` | 다음 카드 1장 펼치기 |
| 마우스 | 중앙의 지정 영역 클릭 | 다음 카드 1장 펼치기 |

- 카드는 플레이어 기준 `왼쪽 → 오른쪽 → 왼쪽 → 오른쪽` 순서로 펼친다.
- 최초 1회 카드 펼치기 입력 후 할리갈리 판정 시간제한을 시작한다.
- 카드 획득 결과가 확정된 뒤에는 다음 펼치기 입력 전까지 시간 진행을 멈춘다.
- 플레이어가 다시 `W` 또는 중앙 영역을 클릭하면 다음 카드를 펼치고 시간제한을 재개한다.

## 5. 카드 합계 분기

합계는 시스템 내부에서만 계산한다. 화면에는 현재 합계와 정답 더미를 표시하지 않는다.

### 합계 3 미만

```text
카드 합계 < 3
→ 다음 카드 펼치기 가능
→ 벨 입력도 가능
   └─ 벨 입력 시 오조작 판정
```

### 합계 3 초과

```text
카드 합계 > 3
→ 다음 카드 펼치기 가능
→ 벨 입력도 가능
   └─ 벨 입력 시 오조작 판정
```

### 합계 정확히 3

```text
왼쪽 또는 오른쪽 카드 더미 합계 = 3
→ 벨 경쟁 활성화
→ 플레이어와 AI 입력 비교
→ 승패 결정
```

좌우 카드 더미가 각각 3인 경우에도 벨을 울릴 수 있다. 양쪽 모두 조건을 만족하면 먼저 유효한 입력을 한 쪽이 원하는 더미 하나를 선택한다.

## 6. 벨 선택 방법

| 선택 | 키보드 | 마우스 |
|---|---|---|
| 왼쪽 더미 | `Q` | 왼쪽 카드 또는 벨 영역 클릭 |
| 오른쪽 더미 | `E` | 오른쪽 카드 또는 벨 영역 클릭 |

- 조건에 맞지 않는 더미도 입력할 수 있어야 한다.
- 정답 벨만 활성화하거나 정답 더미를 미리 강조하지 않는다.
- 오조작은 해당 벨 판정의 패배로 연결한다.
- 오조작의 추가 페널티와 재입력 제한 시간은 아직 확정하지 않는다.

## 7. 벨 승패 처리

```text
벨 입력 수신
→ 선택한 더미의 조건 확인
→ 플레이어와 AI의 유효 입력 시점 비교
→ 승자와 패자 결정
```

### 승자

- 선택한 더미의 해당 카드를 획득한다.
- 벨 승리 수가 1 증가한다.

### 패자

- 해당 판정에서는 카드를 획득하지 못한다.

### 결과 이후

- 승패 결정부터 다음 카드 펼치기 입력까지 시간제한을 정지한다.
- 플레이어는 첫 공용 카드, 자신의 획득 카드와 AI가 가져간 카드를 확인할 수 있다.
- 다음 카드 펼치기는 플레이어의 `W` 또는 중앙 영역 클릭을 기다린다.

## 8. 벨 승리 수 분기

### 양측 모두 3승 미만

```text
플레이어 승리 수 < 3
그리고 AI 승리 수 < 3
→ 다음 카드 펼치기 대기
→ 할리갈리 단계 반복
```

### 한쪽이 3승 달성

```text
플레이어 또는 AI가 벨 승리 3회 달성
→ 할리갈리 단계 종료
→ 양측의 개인 카드 수 확인
```

## 9. 개인 카드 3장 정리

| 획득 카드 수 | 처리 |
|---:|---|
| 3장 미만 | 3장이 될 때까지 사용하지 않은 덱에서 무작위 획득 |
| 정확히 3장 | 현재 카드를 개인 카드로 확정 |
| 3장 초과 | 플레이어가 원하는 3장을 선택하고 나머지 제거 |

- AI도 같은 수량 규칙을 사용한다.
- AI가 3장을 초과해 획득했다면 AI 카드 평가 기준으로 3장을 선택한다.
- 정리가 끝난 AI 개인 카드는 포커 승패 확인 전까지 뒷면으로 표시한다.

## 10. 펼치기 횟수 제한 예외

PDF에서는 52장의 카드를 두 참가자 기준으로 나눈 `최대 26회 펼치기`를 제한 후보로 제시한다.

```text
26회 펼치기 전에 한쪽이 3승 달성
→ 정상적으로 할리갈리 단계 종료

26회 펼치기까지 양쪽 모두 3승 미달
→ 제한 종료 예외 처리
```

### PDF에 기록된 제한 종료 처리안

1. 양측이 필요한 카드를 무작위로 획득한다.
2. 공통 페널티로 카드 1장을 선택해 버린다.
3. 다시 개인 카드 3장이 될 때까지 무작위 획득한다.

이 처리안은 아직 확정 규칙이 아니다. 보유 카드가 없는 참가자에게 동일한 버리기 페널티를 적용할 수 없으므로 별도 예외가 필요하다.

## 11. 마지막 공용 카드와 아이템 단계

```text
양측 개인 카드 3장 확정
→ 마지막 공용 카드 1장 공개
→ 개인 카드 3장 + 공용 카드 2장 확인
→ 아이템 사용 여부 확인
```

### 아이템을 사용하는 경우

```text
아이템 선택
→ 사용 가능 조건 확인
→ 아이템 효과 적용
→ 변경된 카드와 상태 확인
→ 패 확정
```

### 아이템을 사용하지 않는 경우

```text
아이템 건너뛰기
→ 현재 카드 유지
→ 패 확정
```

- 보유 아이템이 없어도 `패 확정` 버튼을 표시한다.
- 아이템은 마지막 공용 카드 공개 후, 패 확정 전에만 사용할 수 있다.
- 패 확정 이후에는 아이템 사용과 카드 변경이 불가능하다.

## 12. 포커 승패와 HP 처리

```text
패 확정
→ 플레이어와 AI의 최종 5장 확인
→ AI 개인 카드 공개
→ 양측 포커 족보 비교
→ 승패 결정
```

### 승리한 참가자

- 라운드 보상을 획득한다.
- 보상의 종류와 수량은 미확정이다.
- 향후 아이템 또는 재화 획득과 연결할 수 있다.

### 패배한 참가자

- HP가 감소한다.
- 기본 피해량과 아이템에 의한 증감은 미확정이다.

### HP 확인

```text
양측 HP > 0
→ 다음 라운드

플레이어 또는 AI HP = 0
→ 해당 경기 종료
→ 다음 스테이지 또는 종료
```

## 14. 기획 업무가 필요한 부분

### P0 - 코어 진행 확정 필요

- 시간제한의 정확한 길이와 시작·정지·재개 시점을 결정해야 한다.
- 시간이 종료됐을 때 AI 승리, 무효 처리 또는 다음 카드 진행 중 무엇을 적용할지 결정해야 한다.
- 오조작 시 `해당 벨 판정 패배` 외에 카드 또는 HP 페널티가 필요한지 결정해야 한다.
- 플레이어와 AI 입력이 동시로 판정될 때 우선순위를 결정해야 한다.
- 카드 획득 대상이 `현재 판정 카드 전체`인지 `최상단 카드 1장`인지 최종 확정해야 한다.
- 최대 26회 안에 3승자가 나오지 않았을 때의 종료 규칙을 확정해야 한다.

### P1 - 공정성과 고의 지연 대응

- 플레이어가 원하는 카드를 기다리기 위해 정답 벨을 고의로 누르지 않는 행동을 허용할지 결정해야 한다.
- 다음 카드를 플레이어만 펼치므로 생길 수 있는 우선권과 AI 반응 시작 시점의 공정성을 검토해야 한다.
- 카드가 없는 참가자에게 `카드 1장 버리기` 페널티를 어떻게 대체할지 결정해야 한다.
- 카드 수와 펼치기 횟수 제한이 한 전투의 전체 덱 소모량에 맞는지 검증해야 한다.

### P2 - 보상과 확장

- 포커 라운드 승리 보상의 종류와 수량을 결정해야 한다.
- 아이템 획득 재화와 보유 한도를 결정해야 한다.
- 설정 화면과 게임 가이드의 상세 항목을 정의해야 한다.
- 다음 스테이지 진입과 전체 게임 종료 구조를 결정해야 한다.
