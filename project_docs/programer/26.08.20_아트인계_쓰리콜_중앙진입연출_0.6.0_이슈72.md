# #72 쓰리콜 중앙 진입 연출 0.6.0 아트 인계

## 결론

쓰리콜 진입 배너는 상단 커뮤니티 카드를 가리지 않는 화면 중앙 전용 연출로 교체한다. 아트는 완료됐으며 Unity 연결은 프로그래머 작업이다.

| 새 파일 | Unity 연결 위치 | 화면 좌표(960×540) | 기존 연결에서 제거할 파일 |
|---|---|---:|---|
| `Assets/Art/Prototype/UI/ThreeCallEntry_0_6_0/three_call_entry_center_plaque_380x112_0_6_0.png` | `Presentation0124Panel.DrawThreeCallEntry`의 쓰리콜 전용 중앙 플라크 | `290,214,380,112` | 공용 `EntryLabel(336,34,288,80)` 쓰리콜 사용 |
| `Assets/Art/Prototype/UI/ThreeCallEntry_0_6_0/three_call_bell_pulse_8f_512x64_0_6_0.png` | `PresentationUiArtSet`의 쓰리콜 진입 아이콘/8프레임 펄스 | 프레임 `307,238,64,64` | `Assets/Art/Prototype/UI/IconOverhaul_0_5_0/phase_three_call_western_64_0_5_0.png` |

## 프로그래머 작업

1. `PlayableDevSceneBuilder`에서 `threeCallIcon`이 `IconOverhaul_0_5_0`을 읽는 현재 연결을 제거한다.
2. `Presentation0124Panel.DrawThreeCallEntry`만 중앙 전용 레이아웃을 사용하도록 분리한다. 쇼다운 공용 레이아웃은 이번 작업 범위가 아니다.
3. 플라크와 8프레임 벨 펄스를 위 표의 좌표로 그린다.
4. `GameRules.ThreeCallEntryPresentationMicroseconds`의 5초 값을 1.55초로 조정한다.
5. 타이밍은 `0.00–0.12 축소`, `0.12–0.32 확대`, `0.32–1.25 유지`, `1.25–1.55 페이드`다.
6. 새 연결과 구형 경로 제거는 같은 커밋에서 처리한다. 구형 PNG는 실행 경로에서 제거하고 `ArtReferences/Archive/Issue72_LegacyRuntime/` 보관본만 유지한다.

## 확인 조건

- 커뮤니티 카드와 잠금 카드가 배너에 가려지지 않는다.
- 화면 중앙에서 벨 펄스 → 제목 고정 → 페이드가 1.55초 안에 끝난다.
- ko/en 문자열이 플라크 밖으로 넘치지 않는다.
- 진입 중 입력 잠금과 실제 게임 규칙은 바뀌지 않는다.
- `IconOverhaul_0_5_0/phase_three_call_western_64_0_5_0.png`을 읽는 코드가 0건이다.
