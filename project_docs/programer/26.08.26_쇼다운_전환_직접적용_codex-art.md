# 쇼다운 전환 직접 적용 — codex/art

## 적용 기준

- Three Call 종료 후 `GameRules.ThreeCallToSelectionPresentationMicroseconds`에 정의된 2초 동안 입력을 잠근다.
- 전환 화면 중앙에는 커뮤니티 카드 최대 2장만 순서대로 공개한다.
- 첫 번째 카드 공개 완료 진행률은 `0.22`, 두 번째 카드 공개 완료 진행률은 `0.46`을 그대로 사용한다.
- 두 장이 모두 공개된 뒤 최소 1초 이상 완성 상태를 유지하고 개인 카드 선택으로 넘어간다.
- 개인 카드, 획득 카드 트레이, 벨, Three Call 조작 UI는 전환 화면에 노출하지 않는다.

## 런타임 변경

- `PlayableDevView`에서 `HalliTransition`을 일반 Three Call 렌더 경로와 분리했다.
- 전환 전용 화면을 먼저 그린 후 즉시 반환하므로 기존 카드 더미·획득 UI가 뒤에서 섞여 나오지 않는다.
- `Presentation0124Panel.DrawThreeCallToSelection`에는 전체 개인 카드 선택 스냅샷 대신 두 커뮤니티 카드 값만 전달한다.
- 기존 쇼다운 프레임, 아이콘, 카드 앞·뒷면 및 플립 모션을 그대로 사용한다.

## 비변경 범위

- 게임 규칙 및 2초 전환 시간
- 개인 카드 선택 기능과 팝업
- 카드 판정
- 사운드 에셋과 사운드 연결
- 저장 장면과 Unity `.meta`
