# 쇼다운 전환 직접 적용 — codex/art

## 적용 기준

- 승인 영상 `three_call_to_showdown_fullflow_v02_10s.mp4`의 10초 호흡을 전환 기준으로 사용한다.
- Three Call 종료 후 `GameRules.ThreeCallToSelectionPresentationMicroseconds`에 정의된 10초 동안 입력을 잠근다.
- 0~1초에는 기존 좌우 카드와 벨을 어둡게 정리하면서 중앙으로 포커스를 모은다.
- 첫 번째 커뮤니티 카드는 0.8~1.7초, 두 번째 커뮤니티 카드는 1.6~2.4초에 순서대로 이동·플립한다.
- 2초부터 SHOWDOWN 표찰을 노출하고, 두 카드가 모두 공개된 뒤 남은 시간 동안 완성 상태를 유지한다.
- 개인 카드, 획득 카드 트레이, 조작 문구와 활성 벨 입력 UI는 전환 화면에 노출하지 않는다.
- 승인 영상 후반부의 개인 카드 3장·선택 프레임은 최신 확정에서 제외됐으므로 런타임에 재현하지 않는다.

## 런타임 변경

- `PlayableDevView`에서 `HalliTransition`을 일반 Three Call 렌더 경로와 분리했다.
- 전환 전용 화면을 먼저 그린 후 즉시 반환하므로 기존 카드 더미·획득 UI가 뒤에서 섞여 나오지 않는다.
- `Presentation0124Panel.DrawThreeCallToSelection`에는 전체 개인 카드 선택 스냅샷 대신 두 커뮤니티 카드 값만 전달한다.
- 기존 쇼다운 프레임, 포커스 마스크, 카드 앞·뒷면 및 플립 모션을 사용한다.
- 좌우 Three Call 카드와 벨은 전환 초반 잔상으로만 남고 입력 대상이 아니다.

## 비변경 범위

- 카드 판정과 선택 규칙
- 개인 카드 선택 기능과 팝업
- 사운드 에셋과 사운드 연결
- 저장 장면과 Unity `.meta`
