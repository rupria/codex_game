# 할리갈리 밧줄 타이머·종료 폭발 아트 교체 인계

## 변경 목적

현재 커뮤니티 카드 아래 제한시간 표시는 밧줄보다 주황색 진행 막대로 인식된다. 서부 살룬 게임의 물성에 맞게 굵은 황마 도화선, 탄 단면, 불씨, 연기와 화약 폭발로 교체한다.

## 2026-08-15 V3 확정 보정

- 승인 레퍼런스: `ArtReferences/Bullet_Rope_0_3_9/references/approved_rope_burn_sequence_20260815.png`
- 불꽃 접점은 32×32 스프라이트 중앙 `(16,16)`이다. 런타임의 남은 밧줄 `xMax`와 이 점을 일치시킨다.
- 불꽃은 위로 선 긴 삼각형이나 촛불 아이콘이 아니다. 밧줄 쪽으로 짧게 눕는 불꽃, 아이보리색 고온 코어, 검댕, 2~4개 불티, 짧은 연기로 구성한다.
- 정적 폴백 이미지도 동일한 중앙 접점을 사용하도록 교체했다.
- 폭발은 승인 레퍼런스처럼 별형 섬광, 주황 파편, 검은 검댕 덩어리 순서로 유지한다.

## 연결 시 반드시 함께 반영할 내용

- 현재 `PlayableDev.unity`의 `_ropeBody`, `_ropeFlame`, `_ropeExplosion`이 `{fileID: 0}`이라서 런타임은 흰 텍스처 기반의 주황색 대체 막대를 표시한다.
- `PlayableDevSceneBuilder`의 `HalliUiArtSet` 생성 시 위 세 리소스를 `Halli_0_3_9` 경로에서 연결한다.
- 밧줄 본체는 `258 x 14~16 px`로 표시한다. 10px 미만으로 축소하지 않는다.
- 남은 시간은 텍스처 전체를 폭에 맞춰 압축하지 않고 왼쪽 기준 UV 크롭으로 줄인다. 꼬임 간격이 진행 시간에 따라 찌그러지지 않아야 한다.
- 밧줄 본체에는 중립 흰색 틴트를 사용한다. 긴급 색상은 밧줄 전체가 아니라 불씨·탄 단면·주변 광량에만 적용한다.
- 정적 연결만 가능한 경우 `halli_rope_burn_flame_32x32_0_3_9.png`과 `halli_rope_timeout_burst_64x64_0_3_9.png`을 사용한다.
- 애니메이션 연결 시 불꽃은 6프레임, 폭발은 8프레임을 사용하며 카탈로그의 재생시간을 따른다.
- 종료 폭발은 현대식 원형 HUD 링으로 보이지 않게 회전·색상 오버레이를 추가하지 않는다.

## 기존 기능 보존 조건

- 제한시간 계산, 입력 잠금, 타임아웃 판정은 변경하지 않는다.
- 카드 배치의 생성 순서와 레이어 정렬을 변경하지 않는다.
- 먼저 펼쳐진 카드는 계속 최상단에 표시하고 이후 카드는 아래 레이어로 누적한다.
- 밧줄은 커뮤니티 카드와 안내 문구를 가리지 않는다.

## 확인 항목

- 정상 상태에서 첫눈에 밧줄 또는 도화선으로 인식된다.
- 남은 시간이 줄어도 꼬임 굵기와 간격이 일정하다.
- 긴급 상태에서 검게 탄 단면, 불씨, 불꽃이 한 덩어리로 보인다.
- 타임아웃 시 아이보리 섬광 → 황동색 파편 → 검은 연기 순서가 읽힌다.
- `PlayableDev.unity` 직렬화 결과에서 세 rope 필드가 더 이상 `{fileID: 0}`이 아니다.
- 카드의 앞뒤 순서가 기존 프로그래머 수정 상태를 유지한다.
