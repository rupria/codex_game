## 완료 범위

- 가이드 상태와 렌더링을 `GuideModalState`·`GuideModalPanel`로 분리했다.
- 가이드는 뒤 UI를 식별할 수 없는 불투명 전면 화면이며 4쪽, 이전, 다음, ESC 닫기, 페이지 번호를 제공한다.
- 가이드가 열리면 시작, 언어 전환, 할리갈리, 개인 카드 선택, 포커 입력을 모두 반환 전에 차단한다.
- 메인에서 가이드를 여는 동안 `StartRequested`가 발생하지 않아 게임 타이머가 시작되지 않는다.
- 아트 커밋 `9a60447`의 0.1.7 가이드 배경·4쪽 이미지·버튼 상태·페이지 표시판을 런타임에 연결했다.
- Google 문자열 원본과 런타임 CSV를 137개 Key로 동기화하고 중복·빈 값·ko/en 변수 불일치를 검증한다.
- AI 획득 카드는 획득 이동과 트레이에서 공통 뒷면으로 표시하고 총 장수는 유지한다.
- 공개 재화를 코인에서 총알로 변경하고, AI HP 0 도달 즉시 잔여 플레이어 HP만큼 스테이지당 1회 정산한다.
- 정산 뒤 최소 바 화면을 거쳐 다음 스테이지로 이동한다. 미확정 상점 상품·가격·회복 수치는 구현하지 않았다.
- 최초 진입과 다음 스테이지 전환 순서는 `StageFlowPlan`으로 분리하고, 연출 중 전투 입력 잠금 경계를 제공한다.
