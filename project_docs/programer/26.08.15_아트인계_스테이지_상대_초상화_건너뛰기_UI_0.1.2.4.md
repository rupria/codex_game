## 3. 입장 패널 연결 규격

- 기존 프레임: `Assets/Art/Prototype/UI/Presentation_0_1_2_4/stage_entry_opponent_intro_frame_360x152_0_1_2_4.png`
- 초상화 원본 크기: `108 x 108 px`
- 프레임 내부 초상화 사각형: `x 20 / y 22 / width 108 / height 108`
- 960×540 입장 프리뷰 기준 화면 좌표: `x 320 / y 206 / width 108 / height 108`
- `preserveAspect = true`, 중앙 정렬, 추가 자르기 금지
- 프레임에 포함된 검은 실루엣 위에 초상화를 겹쳐 표시합니다. 초상화 로딩 실패 시 기존 실루엣이 폴백으로 남습니다.

권장 Unity 임포트 설정:

- Texture Type: `Sprite (2D and UI)`
- Filter Mode: `Point`
- Compression: `None / Uncompressed`
- Generate Mip Maps: `Off`
- Pixels Per Unit: `1`

버튼 PNG 중앙은 비워 두었습니다. `건너뛰기` 또는 각 언어의 번역 문자열만 Unity Text/TMP로 표시합니다. `>>`, 화살표, 별도 아이콘은 추가하지 않습니다.

## 5. 프로그래머 연결 순서

1. 입장 패널의 초상화 영역에 `Image`를 하나 배치하거나 기존 초상화용 `Image`를 사용합니다.
2. 현재 스테이지 번호 1~4를 위 표의 권장 포스터형 Sprite에 매핑합니다.
3. 초상화는 프레임보다 위, 입장 제목·설명 텍스트보다 아래 레이어에 둡니다.
4. 입장 전환이 끝날 때 초상화 오브젝트도 기존 패널과 함께 숨깁니다.
5. `건너뛰기` 버튼은 기존 클릭 동작과 번역 텍스트를 유지하고 배경 Sprite 3종만 교체합니다.

## 6. 변경 금지 범위

- 할리갈리 카드 생성 순서, 형제 순서, Sorting Order 변경 금지
- 먼저 나온 카드가 위에 보이도록 프로그래머가 수정한 카드 표시 규칙 유지
- 게임 판정, 입력 잠금, 스테이지 진행 시간 변경 금지
- 초상화 PNG 안에 스테이지명·인물명·번역 문자열 삽입 금지

이번 아트 커밋은 초상화·프리뷰·Aseprite 원본·카탈로그·버튼 이미지와 생성 스크립트만 포함하며 게임 로직과 씬 파일은 수정하지 않습니다.
