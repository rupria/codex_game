# 스테이지 상대 초상화·건너뛰기 UI 아트 연결 작업서 0.1.2.4

## 1. 작업 상태

- 스테이지 1~4 상대의 생전 모습 초상화 3종씩 준비 완료
  - **기본 연결:** 배경 없는 투명 컷아웃형. 작은 인게임 UI에서 가장 잘 읽힘
  - **입장 연출용:** 인물별 장소가 다른 환경형. 카드룸·카바레 무대·광산·묘지로 구분
  - **대안:** 어두운 살룬 조명과 기존 카드 아트에 가까운 회화형
- 실제 상용 게임 표지의 적·황색 원형 배경과 구도를 답습한 시안은 폐기하고 환경형을 전면 교체함
- 입장 화면 `건너뛰기` 버튼의 이미지 내부 `>>` 제거 완료
- 프로그래머 작업: 스테이지 번호에 따라 투명 컷아웃 Sprite를 입장 패널에 연결

## 3. 배경 사용 규칙

- 작은 108×108 입장 패널과 HUD: `cutout`
- 큰 입장 연출·도감·상대 소개: 필요할 때만 `poster`
- 환경형 배경은 인물마다 다른 장소를 사용합니다.
  - 스테이지 1: 사설 카드룸
  - 스테이지 2: 살룬 카바레 무대
  - 스테이지 3: 광산 갱도
  - 스테이지 4: 야간 묘지
- 외부 레퍼런스에서는 굵은 잉크선·큰 명암 덩어리·인쇄 질감 같은 일반적 표현 방식만 참고합니다.
- 상용 표지의 원형 브러시 배경, 적·황색 배치, 인물 배치나 구도를 복제하지 않습니다.

## 4. 입장 패널 연결 규격

- 기존 프레임: `Assets/Art/Prototype/UI/Presentation_0_1_2_4/stage_entry_opponent_intro_frame_360x152_0_1_2_4.png`
- 초상화 원본 크기: `108 x 108 px`
- 프레임 내부 초상화 사각형: `x 20 / y 22 / width 108 / height 108`
- 960×540 입장 프리뷰 기준 화면 좌표: `x 320 / y 206 / width 108 / height 108`
- `preserveAspect = true`, 중앙 정렬, 추가 자르기 금지
- 투명 컷아웃을 검은 실루엣 위에 겹쳐 표시합니다. 로딩 실패 시 기존 실루엣이 폴백으로 남습니다.

권장 Unity 임포트 설정:

- Texture Type: `Sprite (2D and UI)`
- Filter Mode: `Point`
- Compression: `None / Uncompressed`
- Generate Mip Maps: `Off`
- Alpha Is Transparency: `On`
- Pixels Per Unit: `1`

## 6. 프로그래머 연결 순서

1. 입장 패널의 초상화 영역에 `Image`를 하나 배치하거나 기존 초상화용 `Image`를 사용합니다.
2. 현재 스테이지 번호 1~4를 위 표의 **기본 투명 컷아웃** Sprite에 매핑합니다.
3. 초상화는 프레임보다 위, 입장 제목·설명 텍스트보다 아래 레이어에 둡니다.
4. 입장 전환이 끝날 때 초상화 오브젝트도 기존 패널과 함께 숨깁니다.
5. `건너뛰기` 버튼은 기존 클릭 동작과 번역 텍스트를 유지하고 배경 Sprite 3종만 교체합니다.

## 7. 변경 금지 범위

- 할리갈리 카드 생성 순서, 형제 순서, Sorting Order 변경 금지
- 먼저 나온 카드가 위에 보이도록 프로그래머가 수정한 카드 표시 규칙 유지
- 게임 판정, 입력 잠금, 스테이지 진행 시간 변경 금지
- 초상화 PNG 안에 스테이지명·인물명·번역 문자열 삽입 금지

이번 아트 커밋은 초상화·프리뷰·Aseprite 원본·카탈로그·버튼 이미지와 생성 스크립트만 포함하며 게임 로직과 씬 파일은 수정하지 않습니다.
