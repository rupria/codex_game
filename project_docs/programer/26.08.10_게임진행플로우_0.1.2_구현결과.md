# 게임진행플로우 0.1.2 구현 결과

- 기준: `게임진행플로우_0.1.2.md`, `게임진행플로우_0.1.2_작업요청.md`
- 작업 브랜치: `codex/gameplay-0.1.2`
- 배포: 진행하지 않음

## 구현

- 예측 제한 2분, 성공 최대 5회 누적, 실패·무반응 유지, 사망 초기화
- 스테이지 보상 `기본 총알 + floor(잔여 HP × 예측 성공 × 0.5)` 및 상세 표시
- 4칸 고유 ItemId 인벤토리와 IT-01 재장전, IT-02 밑장빼기, IT-03 바람잡이, 체력 회복
- 버린 카드의 동일 아이템 후보군 재편입, 후보 부족·중복 실패의 원자적 처리
- 상점 4슬롯, 무료 리롤 1회, 가격·중복·잔액·인벤토리 제한 검증
- Issue #36 구매 연출: 주머니 반응, 0.50초 총알 투척·접촉 확정, 0.60초 입력 잠금, 잔액 부족 0.12초 흔들림
- 개발 전용 F10 치트: 스테이지 통과, ItemId 지급, 포커 프리셋, 최근 20개 기록과 `CHEAT / QA` 워터마크
- 치트 진입 코드는 `UNITY_EDITOR || ENABLE_GAMEPLAY_CHEATS` 조건부 컴파일로 일반 빌드에서 제외
- Unity 프로젝트 버전 `0.1.2`

## 아트 연결 경계

`BarShopUiArtSet`의 버튼 상태, 탄약 주머니, 총알 회전 프레임, 황동 스파크와 상품 아이콘을 직렬화 필드로 분리했다. 최종 아트가 확정되면 해당 리소스만 연결하며 구매·경제 로직은 수정하지 않는다.

## 검증

- .NET 코어·애플리케이션 스모크 테스트 통과
- HP 1~3 × 예측 성공 0~5의 18개 보상 조합 통과
- 개발 치트 포함 조건부 컴파일 통과
- Unity 6000.3.18f1 배치 스크립트 컴파일 통과

## 남은 범위

- 아트 PR #29의 최종 리소스 확정 후 Unity 직렬화 연결과 화면별 시각 QA
- WebGL 빌드·배포·실브라우저 QA는 별도 요청 시 진행
