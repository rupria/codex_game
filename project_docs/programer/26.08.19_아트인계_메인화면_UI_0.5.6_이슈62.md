# 아트 인계 — 메인 화면 기본 UI 개선 0.5.6 (#62)

## 1. 작업 목적

이슈 #62의 기존 메인 화면은 살룬 배경 위에 큰 청록·적색 외곽선과 단순 해골 마크가 직접 들어가 있어 초기 프로토타입 인상이 강했습니다. 살룬 배경은 유지하되 중앙 UI를 현재 인게임의 서부·황동·가죽 기조에 맞춰 교체했습니다.

이번 아트의 시각 언어는 다음과 같습니다.

- 중앙 상징: 해골 벨 + 보안관 별 + 교차 리볼버 + 좌우 카드
- 버튼 본체: 검은 가죽, 짙은 목재, 낡은 황동
- START/GUIDE 구분: 전체 네온 외곽선이 아니라 좌우의 작은 청록/적색 표식
- 텍스트: 이미지에 굽지 않고 `UI_MAIN_START`, `UI_MAIN_GUIDE` 현지화 문자열 유지

## 4. 프로그래머 연결 요청

정적 프레임은 드롭인 교체로 바로 노출됩니다. 검토용 시안과 동일한 hover/pressed 표현을 사용하려면 아래 연결이 필요합니다.

1. `PlayableDevView.DrawIntroArtButton`의 내부 단색 `Texture2D.whiteTexture` 덮개를 제거하거나 새 상태 이미지 뒤로 보내기
2. 기존 히트 영역 유지
   - START: `(312, 266, 336, 76)`
   - GUIDE: `(312, 354, 336, 78)`
3. 포인터/키보드 포커스 상태에 따라 `idle → hover → pressed` 텍스처 선택
4. 실제 버튼 문구는 계속 `L("UI_MAIN_START")`, `L("UI_MAIN_GUIDE")`로 중앙 정렬
5. 눌림 상태는 현재처럼 Y +2px 입력 피드백을 유지해도 됨
6. 언어 버튼과 START/GUIDE 기능 이벤트는 변경하지 않음

주의: 미리보기 PNG에 적힌 START/GUIDE는 상태 비교를 위한 검토용입니다. 개별 런타임 버튼 PNG에는 문자가 없습니다.

## 5. 변경하지 않은 범위

- 게임 시작/가이드 기능 로직
- 첫 실행 가이드 분기
- 언어 선택 기능
- 살룬 배경과 테이블 구도
- `pub` 및 웹 배포

## 6. 확인 조건

- [ ] 메인 화면에서 기존 큰 청록/적색 외곽선이 남지 않는다.
- [ ] 중앙 엠블럼에서 벨·서부 보안관·결투 카드의 인상이 식별된다.
- [ ] START/GUIDE 클릭 영역과 기능이 이전과 동일하다.
- [ ] ko/en 전환 시 버튼 문자열이 이미지와 겹치지 않는다.
- [ ] 마우스 hover와 pressed가 각각 다른 아트 상태로 보인다.
- [ ] 960×540, 1280×720, 1920×1080에서 프레임이 잘리지 않는다.
