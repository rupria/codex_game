## 문제

신규 4종은 기능 규칙과 가격이 확정됐지만 기존 `PokerItemUiArtSet`은 기존 4종만 연결한다. 신규 상품을 임시 도형으로 노출하면 팝업 확대에서 식별력이 부족하고, 문양 변경·방어·보험 충전·양측 교환의 결과 상태도 구분할 수 없다.

## 추가 산출물

### 공통

- 신규 4종 각각 `popup 80px`
- 신규 4종 각각 `default / hover / selected / disabled 64px`
- 상태 구분은 색상과 함께 광택 다이아몬드, 체크 프레임, 철제 사선·자물쇠 형태를 사용
- Unity Point/무압축/미프맵 끔용 `.meta` 생성 스크립트
- Aseprite 편집 원본과 전체 카탈로그

### IT-04 와일드 잉크

- 검은 보라 유리 잉크병, 황동 해골 인장, 4문양 왁스 인장
- `wild_ink_spread_8f_512x64_0_5_2.png`: 총 0.65초 기준 8프레임
- 문양 인장 4종, 카드 적용 마커, 적용 후 교환 잠금 마커
- 카드의 좌상단 랭크·우상단 문양을 가리지 않는 중앙 하단 배치 기준

### IT-05 술통

- 황동 보안관 방패가 박힌 서부식 술통
- 준비 상태와 충돌·파손 8프레임을 분리
- 정상 족보 패배 피해 방어 뒤 HP 보존을 나타내는 방패·하트 마커
- 시간 초과 피해에는 사용하지 않음

### IT-06 예측 보험

- 계약서·황동 보안관 인장·충전 2발을 한 실루엣으로 구성
- 충전 `2 / 1 / 0`은 숫자 없이 탄피 개수와 파손 사선으로 구분
- 실제 성공은 별형 배지, 보험 성공은 방패형 배지로 분리
- 인장 적용 6프레임 제공

### IT-07 용병단

- 두 인물의 모자와 교차 리볼버, 계약 카드 뒷면으로 구성
- 플레이어·AI 카드가 서로 다른 레인에서 동시에 교환되는 10프레임
- AI 앞면은 연출에서 사용하지 않으며 뒷면·자물쇠 마커만 사용

## 프로그래머 연결 위치

- Runtime PNG: `Assets/Art/Prototype/UI/ItemExpansion_0_5_2/`
- Aseprite/프리뷰/카탈로그: `ArtReferences/ItemExpansion_0_5_2/`

## 런타임 수용 조건

- [ ] 960×540, 1280×720, 1920×1080에서 아이콘·팝업이 안전 영역 안에 있다.
- [ ] 와일드 잉크 인장이 랭크·문양·조커 정보를 가리지 않는다.
- [ ] 술통 발동 순서가 `AI 승리 → 술통 방어 → HP 유지`로 보인다.
- [ ] 보험의 실제 성공, 보험 성공, 남은 충전이 각각 별도 형태로 보인다.
- [ ] 용병단 연출 중 AI 카드 앞면이 노출되지 않는다.
- [ ] 아이템 연출 중 2분 타이머가 정지하지 않는다.
- [ ] disabled 상태가 색상 없이도 철제 사선과 자물쇠로 식별된다.
