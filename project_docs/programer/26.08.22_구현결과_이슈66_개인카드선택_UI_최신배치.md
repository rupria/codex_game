# #66 개인 카드 선택 UI 최신 직접 적용 결과

## 기준

- 이 문서는 2026-08-24 현재 대화에서 사용자가 실제 실행 화면의 큰 빈 공간과 분리된 버튼 구성을 재수정하도록 지시한 최신 기준을 기록한다.
- 과거 좌측 확정 단일 행 배치와 최대 8장 구형 배치는 모두 폐기한다.
- 아트 패키지는 `Assets/Art/Prototype/UI/PrivateSelection_0_6_0/`의 승인 PNG를 그대로 사용한다. 구형 패키지나 과거 좌표를 복구하지 않는다.

## 런타임 배치

기준 캔버스는 960×540이다.

| 역할 | 좌표·규격 | 계약 |
|---|---:|---|
| 선택 진행 | `(72, 412, 184, 64)` | 좌측 하단 전용 수량 패널, 입력 없음 |
| 확정 시각 | `(580, 412, 280, 60)` | 우측 하단 유일 `패 확정` 버튼 |
| 확정 클릭 | `(568, 400, 304, 84)` | 시각보다 큰 단일 히트 영역 |
| 확정 제목 | `(604, 428, 232, 28)` | `패 확정` / `LOCK HAND` |
| 후보 상단 | `y=136` | 최대 4장, 선택 영역 중앙 정렬 |
| 다섯 번째 후보 | `(452, 294, 112, 150)` | 확정 히트 영역과 겹치지 않는 하단 배치 |
| 후보 프레임 | `112×150` | 최대 5장 |
| 후보 간격 | `20px` | 4+1 배치, 큰 빈 공간 제거 |

## 기능 계약

- 좌측 하단은 선택 수량 표시만 담당하고 입력을 받지 않는다.
- 우측 하단 확정 시각·히트 영역은 하나만 유지한다.
- 마우스 확정과 Enter 확정은 동일한 기존 `PrivateCardsConfirmRequested` 경로를 사용한다.
- `snapshot.CanConfirm`이 거짓이거나 조커 공개 입력 잠금 중이면 버튼은 disabled이며 이벤트를 만들지 않는다.
- 후보 카드의 선택·포커스·조커 공개 동작은 유지하고 5장일 때 4+1로 배치한다.
- 카드 앞면은 각 112×150 후보 프레임의 내부 `(x+14, y+13, 84, 117)`에 들어간다.

## 회귀 금지

- #54: 쓰리 콜 필드 카드 최대 2장, 가로 겹침 10% 이하, 최신 카드 최상단.
- 쇼다운 커뮤니티 카드 최대 2장.
- `PrivateSelection_0_5_5`, 좌측 확정 단일 행, 최대 8장 배치를 활성 경로로 복구하지 않는다.
- 승인 PNG는 이 작업에서 변경하지 않는다.

## 2026-08-24 최신 직접 적용 기준

- 우측 확정은 최신 대화 지시에 따라 복구하되 최대 후보 수는 5장으로 고정한다.
- 기존 0.6.0 승인 PNG를 재사용하며 신규 이미지나 사운드·장면 변경은 만들지 않는다.
- 충돌 시 적용 순서는 `가장 최근 사용자 승인 코멘트·이미지 > 최신 기획 리비전 > 과거 아트·프로그래머 인계서`다.
- 후속 인계서나 자동 생성 코멘트가 이 문서보다 늦게 작성됐다는 이유만으로 폐기된 좌표를 복구해서는 안 된다.
- 검증 게이트는 선택 수량 전용 패널, 우측 단일 확정, 4+1 후보 배치, 최대 5장 및 구형 좌측 확정 부재를 함께 확인한다.
