# #66 개인 카드 선택 UI 최신 배치 구현 결과

## 기준

- 이 문서는 #66의 2026-08-22 사용자 승인 **두 번째 시안**을 최종 기준으로 기록한다.
- `26.08.21_아트인계_UI보완_이슈49_66_68_73_0.6.5.md`의 우측 하단 확정 버튼 좌표는 폐기한다.
- 아트 패키지는 `Assets/Art/Prototype/UI/PrivateSelection_0_6_0/`의 승인 PNG를 그대로 사용한다. 구형 패키지나 과거 좌표를 복구하지 않는다.

## 런타임 배치

기준 캔버스는 960×540이다.

| 역할 | 좌표·규격 | 계약 |
|---|---:|---|
| 확정 시각 | `(72, 412, 280, 60)` | 좌측 하단 단일 `패 확정` 버튼 |
| 확정 클릭 | `(60, 400, 304, 84)` | 시각보다 12px 큰 단일 히트 영역 |
| 확정 제목 | `(96, 417, 232, 28)` | `패 확정` / `LOCK HAND` |
| 선택 진행 | `(96, 444, 232, 20)` | `선택 {selected}/{required} · ENTER` |
| 후보 시작 | `(270, 124)` | 우측 사각 선택 영역 내부 |
| 후보 프레임 | `112×150` | 최대 5장 |
| 후보 간격 | `12px` | 5장을 한 줄로 표시, 마지막 프레임 xMax 878 |

## 기능 계약

- 우측 하단의 확정 시각·히트 영역은 모두 제거한다.
- 별도 선택 수량 플라크는 그리지 않고 진행 수량을 확정 버튼 안에 통합한다.
- 마우스 확정과 Enter 확정은 동일한 기존 `PrivateCardsConfirmRequested` 경로를 사용한다.
- `snapshot.CanConfirm`이 거짓이거나 조커 공개 입력 잠금 중이면 버튼은 disabled이며 이벤트를 만들지 않는다.
- 후보 카드의 선택·포커스·조커 공개 동작은 유지하고 배치만 4열+2행에서 최대 5장 단일 행으로 바꾼다.
- 카드 앞면은 각 112×150 후보 프레임의 내부 `(x+14, y+13, 84, 117)`에 들어간다.
