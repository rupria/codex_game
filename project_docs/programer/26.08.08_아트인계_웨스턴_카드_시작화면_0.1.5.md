# 웨스턴 카드·시작 화면 아트 인계 0.1.5

## 이번 변경

- 포커 A–10 40장의 카드 본체를 최신 웨스턴 프레임 후보로 제작했다.
- 문양 테두리, 해골 디자인, 슈트 색과 핍 배열은 기존 0.1.0 후보를 그대로 유지했다.
- A 해골의 머리띠와 이마 장식은 사용하지 않는다.
- 시작 화면 배경을 어두운 웨스턴 살롱으로 교체했다.
- 시작 화면의 해골·카드·벨 로고, `START`/`GUIDE` 문구, 버튼 위치·크기·청록/적색 UI 디자인은 기존 픽셀을 그대로 유지했다.

## 제작 방식

- OpenAI 내장 ImageGen으로 머리 장식 제거와 웨스턴 카드·시작 화면 방향을 확인했다.
- 실제 64×90 카드 40장은 기존 문양을 변경하지 않도록 원본 전경 픽셀과 새 카드 본체를 결정적으로 합성했다.
- 실제 960×540 시작 화면은 기존 UI 픽셀을 웨스턴 살롱 배경 위에 재합성해 문구와 조작 UI의 변형을 막았다.
