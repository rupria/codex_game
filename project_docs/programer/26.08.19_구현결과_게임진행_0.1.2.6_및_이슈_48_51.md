## 구현

- 카드 펼치기 가능 시에만 현지화된 일회성 안내를 노출하고, 입력 즉시 제거했습니다.
- 잔여 카드 5장부터 5→1 카운트다운 아트를 연결했습니다. 상시 카드 수·조작 안내는 제거했습니다.
- 스테이지 보상 패널을 720×300 안전 영역과 최대 2×2 배열로 제한했습니다.
- 상점 HP 패널을 제거했습니다.
- 밧줄 끝점 기준으로 6프레임 불꽃, 8프레임 폭발, 그을음 아트를 연결했습니다.
- 아이템은 사용 확인 전까지만 취소할 수 있고, 대상 선택 진입 후에는 취소할 수 없도록 했습니다.
- 예측 보험 적용/발동 연출과 충전 표시 시점을 분리했습니다.
- 조커 연출 시간, 상점 리롤 1발·방문당 2회, 풀 HP 체력 회복 구매 규칙을 반영했습니다.
- 제한 시간 카드 배분은 보유 미선택 카드 우선, 부족분만 미획득 풀에서 보충하도록 했습니다.
- AI 벨 반응 시간·정답/오답/미입력 확률과 스테이지 보정을 반영하고, 개발·QA 빌드에서만 로컬 CSV 로그를 기록합니다.
- 첫 실행 가이드에 SKIP 입력을 복구했습니다.
- Unity 표시 버전을 `0.1.2.6`으로 갱신했습니다.
