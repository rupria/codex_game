# 이슈 #49 보상 정산 라벨 가독성 회귀 수정

## 최신 기준

- 기준 dev SHA: `f12a8655c072f3fbe316b06b2835d2433e3f83b7`
- 최신 사용자 재현 코멘트: https://github.com/rupria/codex_game/issues/49#issuecomment-5392579050
- 대체되는 잘못된 완료 코멘트: https://github.com/rupria/codex_game/issues/49#issuecomment-5388789968
- 활성 아트 패키지: `StageReward_0_5_6`

## 원인

- 0.5.6 아트 카탈로그는 보상 행에 `기본 보상`, `예측 보너스` 라벨과 값을 분리하도록 정의했다.
- 런타임은 라벨 안전 영역에 총알 아이콘을 추가하고 수량만 출력했다.
- 총 획득 행도 라벨 없이 수량만 출력해 승인 프리뷰와 달랐다.
- 따라서 팝업 경계와 최신 PNG 연결이 정상이어도 사용자에게는 미수정 화면으로 보였다.

## 적용 계약

- 보상 행은 카탈로그의 라벨 안전 영역 `(48,14,148,36)`과 값 안전 영역 `(208,14,76,36)`을 사용한다.
- `기본 보상`은 황동 계열 값, `예측 보너스`는 청록 계열 값으로 표시한다.
- 총 획득 행은 라벨과 합계 값을 각각 분리해 출력한다.
- 보상 행에 런타임 총알 아이콘을 추가하지 않는다.
- ko/en 문자열은 PNG에 굽지 않고 `ui_strings.csv`에서 출력한다.
- 재화 계산, 보상 값, 저장 순서, 사운드 연결은 변경하지 않는다.

## 회귀 방지

- `latest_approved_art_contracts.json`에 #49 최신 계약을 등록한다.
- 구형 아이콘 좌표와 라벨 없는 총합 좌표가 복귀하면 아트 런타임 게이트를 실패시킨다.
- 라벨·값 안전 영역이 행 프레임을 벗어나면 스모크 테스트를 실패시킨다.
- 커밋에는 Audio, AudioMixer, 사운드 클립 및 관련 Unity 직렬화 파일을 포함하지 않는다.
