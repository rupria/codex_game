# 아트 인계 — 가이드 화살표 장식선 제거 0.6.0 (#65)

## 기준

- 최신 작업 기준: `dev` `f6584d0b41d9f0efc09d8a0b2dd361520276b9c1`
- 교체 대상: `GuideNav_0_5_6` 전체 바인딩
- 신규 패키지: `Assets/Art/Prototype/UI/GuideNav_0_6_0/`

## 변경 내용

이전·다음 화살표 내부에 별도 막대처럼 보이던 노란 수평 장식선만 제거했다. 버튼 크기, 배치, 클릭 영역, 청록·적색 구분, 닫기 버튼, 레일, 페이지 표시판과 `idle / hover / pressed / disabled` 상태는 0.5.6을 그대로 유지한다.

## 연결 요청

`PlayableDevSceneBuilder`의 `GuideNav_0_5_6` 텍스처 경로를 같은 파일 역할의 `GuideNav_0_6_0` 경로로 일괄 변경한다. 0.5.6과 0.6.0 상태 이미지를 섞지 않는다.

설계 Rect는 변경하지 않는다.

| 요소 | Rect |
|---|---|
| 하단 레일 | `(0, 436, 960, 104)` |
| 이전 | `(352, 451, 56, 58)` |
| 페이지 표시판 | `(414, 461, 132, 38)` |
| 다음 | `(552, 451, 56, 58)` |
| 닫기 | `(850, 451, 56, 58)` |

## 확인 조건

- [ ] 이전·다음 화살표 안에 노란 수평 막대가 보이지 않는다.
- [ ] 화살표 본체와 hover 상단 강조선은 유지된다.
- [ ] 첫·마지막 페이지 disabled 상태와 버튼 입력 규칙이 유지된다.
- [ ] 960×540, 1280×720, 1920×1080에서 클릭 위치가 보이는 버튼과 일치한다.
- [ ] 가이드 페이지 내용·명칭·페이지 수는 변경되지 않는다.
