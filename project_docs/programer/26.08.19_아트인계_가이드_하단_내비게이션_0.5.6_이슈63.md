# 아트 인계 — 가이드 하단 내비게이션 0.5.6 (#63)

## 1. 문제 확인

이슈 #63 화면은 이전·페이지 표시·다음·닫기 버튼 사이의 간격과 시각적 소속이 불명확합니다. 페이지 이동 버튼은 하나의 조작군처럼 보이지 않고, 페이지 표시 프레임의 실제 하이라이트 위치도 배경 장식과 어긋나 보입니다.

## 2. 개선 방향

- `이전 — 페이지 표시 — 다음`을 화면 하단 중앙의 하나의 조작군으로 묶음
- 닫기는 오른쪽 끝의 독립 종료 영역으로 분리
- 32px 아이콘 확대 대신 실제 표시 크기인 56×58 전용 픽셀 아트 사용
- 황동·가죽 프레임으로 가이드 모달과 통일
- 이전은 청록, 다음·닫기는 적색을 작은 행동 표식으로만 사용
- 각 버튼에 `idle / hover / pressed / disabled` 상태 제공

## 5. 코드 연결 요청

대상: `GuideModalPanel`

1. `PreviousButton`, `NextButton`, `CloseButton`을 위 좌표로 변경
2. 기존 배경에 구워진 하단 버튼 영역을 신규 `guide_nav_rail_960x104_0_5_6.png` 오버레이로 덮기
3. 기존 `PageIndicatorMask`와 `PageIndicatorPlate`를 신규 표시판 Rect로 통합
4. 페이지 점은 위 중심 좌표와 24px 간격 사용
5. `DrawIconHitTarget`은 단일 아이콘 확대와 반투명 색 덮개 대신 상태 PNG를 직접 선택
   - 기본: `idle`
   - 포인터/키보드 포커스: `hover`
   - 눌림: `pressed`
   - 이동 불가: `disabled`
6. 첫 페이지 이전 버튼 disabled, 마지막 페이지 다음 동작 및 첫 실행 가이드 완료 분기는 기존 규칙 유지
7. 첫 실행 가이드 중 닫기 미노출 규칙 유지

## 6. 적용 안전 조건

현재 `guide_modal_background.png`에는 예전 버튼이 직접 들어가 있고 히트 영역도 예전 좌표입니다. 새 레일과 새 좌표를 동시에 연결하기 전에는 기존 배경을 단독 교체하지 마십시오. 아트만 먼저 교체하면 보이는 버튼과 클릭 위치가 달라집니다.

## 7. 확인 조건

- [ ] 이전·페이지 표시·다음의 중심이 화면 중앙에 맞는다.
- [ ] 페이지 하이라이트가 표시판 프레임 내부 중앙에 맞는다.
- [ ] 닫기 버튼은 페이지 이동군과 분리되어 보인다.
- [ ] 버튼의 보이는 영역과 클릭 영역이 일치한다.
- [ ] disabled 버튼은 사라지지 않고 비활성 상태가 구분된다.
- [ ] mouse/keyboard hover와 pressed가 각각 표시된다.
- [ ] 960×540, 1280×720, 1920×1080에서 하단 레일이 잘리지 않는다.
