## 문제와 변경

기존 버튼 중앙에 구워진 수평선이 실시간 다국어 텍스트를 관통했다. 신규 버튼은 황동·가죽 프레임과 상태 구분을 유지하면서 중앙 128×20 영역에서 선과 글자를 모두 제거했다. 실제 문구는 기존 현지화 문자열을 런타임에서 그린다.
