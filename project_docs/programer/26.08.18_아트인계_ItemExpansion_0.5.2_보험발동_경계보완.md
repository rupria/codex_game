## 보험 발동 조건 경계

발동 세션 생성은 프로그래머 판정이다. 아트에서는 조건을 추론하지 않는다.

- 생성: 예측 오답, 예측 2분 무입력, 충전 1회 이상.
- 생성하지 않음: 실제 예측 정답, 충전 0, 세 번째 이후 실패, 손패 확정 120초 시간 초과.
- 충전 아이콘 교체와 보험 보정 성공 기록은 실제 발동 종료 전에 한 번만 발생해야 한다.
