# 이슈 #67·#68 승패 예측·결과 UI 아트 인계 — PokerPredictionResult 0.5.7

## 승인된 변경

- 큰 사각형 결과 팝업과 중앙 프레임을 제거한다.
- 카드와 상태 정보를 원형 테이블의 상·중·하 원호에 직접 배치한다.
- 커뮤니티 카드는 규칙대로 **최대 2장**만 노출한다.
- 하단 승패 선택은 청록 `플레이어 승리`, 적색 `AI 승리`의 좌우 경사형 탭으로 교체한다.
- 보험 아이템을 사용한 스테이지에서는 `남은 보험 {count}`만 표시한다.
- `보험 충전`, `실제 성공`, `보험 성공` 3행 묶음은 제거한다.
- 합산 예측 성공은 `예측 성공 {count}/5`로 아이템 상자 옆에 표시한다.
- 결과 단계에서는 선택한 승패 탭을 selected 상태로 유지하고 중앙 하단에 `계속`을 노출한다.

## 프로그래머 연결 작업

### 1. #67 승패 예측 버튼

1. `PokerTableLayout.WinVisual/LoseVisual`의 60×60 중앙 아이콘 배치를 제거한다.
2. 카탈로그의 232×64 좌우 탭 좌표와 248×80 히트 영역을 사용한다.
3. `PokerUiArtSet`에 idle, hover, selected, disabled 상태를 연결한다.
4. 텍스처 위 안전 영역에 `UI_POKER_PLAYER_WINS`, `UI_POKER_PLAYER_LOSES`를 런타임으로 렌더링한다.
5. `AwaitingPrediction`에서는 idle/hover, 선택 직후와 결과 단계에서는 선택 항목 selected, 입력 불가 단계에서는 disabled를 사용한다.
6. 상단 중앙에 `poker_prediction_stage_emblem_40_0_5_7.png`와 `UI_POKER_PREDICTION_TITLE`을 배치한다.

### 2. 보험·예측 성공 정보

1. `PokerDevPanel.DrawPredictionReward()`의 기존 3행 표시를 제거한다.
2. `InsuranceActivatedThisStage == true`일 때만 방패 아이콘과 `남은 보험 {InsuranceChargesRemaining}`을 표시한다. 0회도 활성 스테이지에서는 `남은 보험 0`으로 표시한다.
3. `ActualSuccessCount`, `InsuredSuccessCount`를 UI에서 따로 노출하지 않는다. 감사 기록 데이터는 그대로 보존한다.
4. 상자 옆 카운터는 `RewardSuccessCount`를 사용해 `예측 성공 {count}/5`로 표시한다.
5. 신규 다국어 키 권장값:
   - `UI_PREDICTION_INSURANCE_REMAINING`: ko `남은 보험 {count}` / en `INSURANCE LEFT {count}`
   - `UI_PREDICTION_SUCCESS_COUNT`: ko `예측 성공 {count}/5` / en `PREDICTION {count}/5`

### 3. #68 결과 단계

1. `PokerResultOverlayRenderer.Draw()`가 만드는 큰 중앙 결과 패널을 결과 단계에서 제거한다.
2. 승패·카드·HP 계산은 변경하지 않고 원형 테이블 배치를 유지한다.
3. 플레이어가 선택한 승패 탭을 selected 상태로 유지해 예측 내용을 표시한다.
4. `poker_result_continue_idle/hover_164x44_0_5_7.png`를 중앙 하단에 연결한다.
5. 아이템 발동의 짧은 확대 연출은 유지하되, 완료 뒤에는 `남은 보험`과 상자 옆 합산 카운터만 남긴다.

## 필수 회귀 방지

- 현재 `DrawFaceCards(snapshot.PublicCards, ..., 2, ...)`의 최대값 `2`를 유지한다.
- 커뮤니티 카드 0·1·2장 상태만 검증하며 3장 이상은 화면에 생성하지 않는다.
- 카드 계산·예측 판정·보험 소비·2분 무응답·패 확정 시간 초과·HP·보상 로직은 수정하지 않는다.
- 960×540, 1280×720, 1920×1080에서 탭과 상자·카드가 겹치지 않아야 한다.
- ko/en 문구가 텍스처 밖으로 잘리지 않아야 한다.
- 이전 `보험 충전/실제 성공/보험 성공` 3행 UI와 큰 결과 팝업이 함께 남지 않아야 한다.

## 검수 체크리스트

- [ ] 커뮤니티 카드가 최대 2장이다.
- [ ] 예측 단계임을 상단 엠블럼과 하단 두 선택 탭으로 즉시 알 수 있다.
- [ ] 마우스 hover·선택·disabled가 각각 구분된다.
- [ ] 보험 미사용 스테이지에서는 보험 정보가 보이지 않는다.
- [ ] 보험 사용 스테이지에서는 `남은 보험` 한 줄만 보인다.
- [ ] `예측 성공 0~5/5`가 아이템 상자 옆에 보인다.
- [ ] 결과 단계에서 큰 사각 팝업이 보이지 않는다.
- [ ] 선택한 승패와 `계속` 입력이 동시에 식별된다.
