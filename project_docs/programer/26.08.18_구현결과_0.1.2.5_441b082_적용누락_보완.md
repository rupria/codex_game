## 구현 결과

### 1. 공유 카드 중복 공개 제거

- 첫 번째와 두 번째 공유 카드는 최초 공개 뒤 같은 상태 객체에서 계속 앞면으로 유지한다.
- 개인 카드 선택과 아이템 단계가 동일한 공개 카드 2장을 참조한다.
- 아이템 단계의 `RevealingSecondPublic` 상태와 두 번째 공개 대기 타이머를 제거했다.
- 포커 판정 입력에도 화면에 유지된 동일 카드 ID를 전달한다.

### 2. 밑장빼기 120초 연속 타이머와 취소

- 개인 카드 선택 완료 뒤 시작한 손패 확정 마감 시각을 밑장빼기 후보 UI가 그대로 사용한다.
- 후보 진입은 시간을 정지·연장·초기화하지 않는다.
- 취소 버튼과 `Esc/CANCEL`을 연결했다. 취소하면 손패·아이템·사용 횟수·공용 RNG·진행 상태가 변하지 않는다.
- 후보 생성은 별도 결정적 `BottomDealPreview` 채널을 사용하여 취소와 재진입으로 공용 아이템 RNG가 진행되지 않는다.
- 후보 선택 중 시간 초과는 UI를 닫고 기존 3장을 확정한 뒤 플레이어 강제 패배/HP 1 감소를 1회 처리한다. 예측, 화약통, 예측 보험은 실행하지 않는다.
- `BottomDealAuditEntry`에 진입/취소/확정/시간 초과, 시각, 남은 시간, 대상 카드 ID를 기록한다.

### 3. 예측 보험 실제 발동 분리

- 보험 등록 연출 0.45초와 실제 보정 발동 연출 0.40초를 별도 세션으로 분리했다.
- 예측 오답·예측 무입력에서만 남은 충전이 있을 때 판정당 1회 발동한다.
- 실제 정답, 잔여 0회, 세 번째 실패, 손패 확정 시간 초과에는 발동하지 않는다.
- `PredictionRecordAuditEntry`에 실제 성공 여부, 보험 보정 성공 여부, 충전 전/후 값을 분리 저장한다.
- `PredictionInsuranceActivationSnapshot`은 판정 순서, 선택, 충전 전/후, 진행률, 잔여 연출 시간을 UI에 제공한다.
- 전달된 예측 보험 아이콘/사용 시트를 실제 발동 오버레이에 재사용했다. 추가 아트 요청은 없다.

### 4. 신규 4종 QA 경계 프리셋

개발 치트 패널에서 프리셋을 선택하고 `RUN ITEM QA PRESET` 한 번으로 실행한다. 결과에는 프리셋, 시드, 상태, 손패, 공유 카드, 아이템 상태, 기대/실제 결과를 표시하고 로그에도 같은 결과를 남긴다. 명령과 UI 진입점은 `UNITY_EDITOR` 또는 `ENABLE_GAMEPLAY_CHEATS`에서만 컴파일된다.

프리셋 23개:

- 만능잉크 5개: 플러시 완성, 스트레이트 플러시 완성, 조커 거부, 같은 문양 거부, 후속 교환 잠금
- 화약통 3개: 일반 패배 방어, 승리 시 미발동·예약 소모, 손패 확정 시간 초과 제외
- 예측 보험 5개: 정답 유지, 오답 2회, 무입력 2회, 세 번째 실패 미보정, 손패 확정 시간 초과 제외
- 떠돌이 용병 5개: 정상 교환, 최다 문양 보존, 유효 교환쌍 없음, AI 조커 비공개, 동일 시드 반복
- 공통 5개: 사용 제한 0/1/2회, 신규 4종 조합, 카드풀 총량·CardId 고유성

프리셋은 결과를 직접 덮어쓰지 않고 `PokerItemSession`, `PokerRoundSession`, `PredictionStreak`, `MercenaryExchangeResolver`, `StageItemRestrictionSession`의 실제 판정 경로를 사용한다.

### 5. 아이템 사용 단계 데이터화

- `GameItemDefinition.UseTiming`과 `GameItemUseTimingPolicy`를 추가했다.
- 현재 8종을 모두 `AfterPublicCardsAndPrivateSelectionBeforePrediction`으로 설정했다.
- UI 활성화, 실제 사용 검증, 비활성 안내 문구가 같은 정의 데이터를 사용한다.
- 잘못된 단계의 요청은 카드, 아이템, 횟수, RNG, 상태를 바꾸지 않고 거부한다.
- 테스트에서 정의 데이터만 바꿔 사용 단계를 이동할 수 있음을 확인했다.
