## 보존 상태와 복구 근거

- 최신 아트 커밋과 패키지 폴더는 `dev` 이력에 남아 있다.
- `runtime-bindings-0.6.1` 작업트리의 미커밋 연결 변경은 삭제·초기화하지 않고 보존했다.
- 대량 Unity 자동 `.meta` 변경은 연결 복구 근거로 간주하지 않으며, 실제 코드·장면 변경과 분리해 검토한다.
- 아트 재제작은 필요하지 않다. 보존된 연결 변경을 최신 `dev`에 선별 통합하고 최신 인계서·매니페스트 기준으로 다시 검증해야 한다.
