### #48과 Q-030의 충돌 정리

GitHub #48의 기존 문구 제거 요구와 0.1.2.6 Q-030의 `Flip` 표시 요구가 충돌한다. 최신 기획 리비전 `2026-08-18-03`을 우선한다.

- 제거: 상단 `배분 x/12 · 남은 덱 y` 상시 문구
- 제거: `Q 왼쪽`, `E 오른쪽`, `W 1장 펼치기`, `1장 펼치기` 등 상시 조작 설명
- 유지: 남은 덱이 5~1로 바뀔 때 한 번 나타나는 `HalliAlerts 0.5.4` 숫자 배지
- 추가/유지: 실제 다음 펼치기가 가능해지는 순간의 현지화 `Flip` 문구
- `Flip`은 안내 애니메이션 완료를 기다리지 않으며, 입력을 받으면 즉시 숨긴다.

`Flip`은 텍스트가 새겨진 PNG로 만들지 않는다. 현지화 문자열을 기존 입력 가능 상태와 연결하며, 필요하면 `phase_entry_label_frame_288x80_0_1_2_4.png`의 황동 프레임 문법만 사용한다.

## F-06 조커 당첨 연출

`JokerReveal 0.5.3`의 그림을 재사용한다. 단, 기존 카탈로그의 시간값보다 최신 Q-029가 우선한다.

### 플레이어

- 조건: 플레이어가 조커 당첨에 실제 성공
- 총 길이: 약 `1.00초`
- 건너뛰기: 불가
- 카드 앞면 하이라이트: `0.50초` 포함
- 미당첨: 별도 연출 없이 즉시 진행

권장 타임라인:

| 구간 | 표현 |
|---:|---|
| 0.00~0.15 | 포커 후보 영역을 어둡게 하고 초점 프레임 진입 |
| 0.15~0.35 | 조커 카드가 후보 영역에서 중앙으로 이동·앞면 확정 |
| 0.35~0.85 | `frame_glow`·`glint`로 앞면 0.50초 하이라이트 |
| 0.85~1.00 | 실제 후보 슬롯으로 정착하고 입력 잠금 해제 |

### AI

- AI가 획득만 하고 최종 패에 선택하지 않으면 끝까지 비공개다.
- AI 최종 패에 조커가 실제 포함된 경우 Showdown에서만 `0.50초` 축약 하이라이트를 재생한다.
- Showdown 전에는 카드 수, 마커, 지연, 광택, 소리로 소유 여부를 암시하지 않는다.

기존 카탈로그의 플레이어 `1.30초`, AI `0.35초`는 0.1.2.6에서 사용하지 않는다. PNG는 교체하지 않고 런타임 타임라인만 최신화한다.
