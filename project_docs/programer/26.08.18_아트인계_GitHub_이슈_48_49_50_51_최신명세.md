## #48 상단 잔여 카드·플립 문구 제거

> 0.1.2.6 최신 기획 리비전 `2026-08-18-03` 보완: 상시 수량·Q/E/W 조작 문구는 제거하지만, Q-030에 따라 실제 다음 펼치기가 가능해지는 순간에는 현지화 `Flip` 문구를 잠깐 표시한다. 입력이 들어오면 페이드 완료를 기다리지 않고 즉시 숨긴다. 아래의 `5→1` 카운트다운 배지는 그대로 유지한다.

현재 `HalliDevPanel.DrawScoreboard`는 `FlipCount/HalliDistributionLimit`와 `RemainingDeckCards`를 화면 상단에 계속 그린다. 이 문자열은 제거한다.

신규 런타임 에셋:

- `Assets/Art/Prototype/UI/HalliAlerts_0_5_4/halli_last_five_countdown_sheet_5f_480x96_0_5_4.png`
- `Assets/Art/Prototype/UI/HalliAlerts_0_5_4/halli_last_five_countdown_plate_96_0_5_4.png`

연결 규칙:

1. 정상적인 카드 펼치기로 `RemainingDeckCards`가 직전 값보다 감소했을 때만 확인한다.
2. 새 값이 `5, 4, 3, 2, 1` 중 하나이면 해당 프레임을 한 번 표시한다.
3. 배지는 0.48초 동안 `팝 인 0.08초 → 유지 0.20초 → 페이드 0.20초`로 재생한다.
4. 배지는 상시 정보가 아니다. 값이 바뀌지 않는 프레임, 결과 대기, 입력 잠금 중에는 새로 재생하지 않는다.
5. 기존 상단 수량·플립 가능 문구를 되살리지 않는다.

참조 위치:

- `Assets/Scripts/Presentation/Views/HalliDevPanel.cs`의 `DrawScoreboard`
- 현재 제거 대상은 `snapshot.FlipCount`, `GameRules.HalliDistributionLimit`, `snapshot.RemainingDeckCards`를 합친 라벨이다.
