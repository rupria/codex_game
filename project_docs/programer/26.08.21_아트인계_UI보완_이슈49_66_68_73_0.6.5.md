## 6. 임포트 설정

모든 PNG 공통:

- Texture Type: `Sprite (2D and UI)`
- Sprite Mode: `Single`
- Filter Mode: `Point`
- Compression: `None/Uncompressed`
- Generate Mip Maps: `Off`
- Alpha Is Transparency: `On`

새 `.meta`는 패키지 경로 기반 안정 GUID로 생성됐다. 프로그래머는 기존 구형 `.meta`를 복원·수정하지 않는다.
