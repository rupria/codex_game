# 26.08.10 아트 인계 — 할리갈리 공유 더미·아이템 선택 UI 0.3.7

## 범위

프로그래머 쪽에서 진행 중인 카드 제출 규칙 로직은 변경하지 않았다. 이번 작업은 해당 로직에 연결할 할리갈리 좌우 공유 더미와 포커 아이템 선택 단계의 런타임 PNG·Aseprite 원본·상태 시안을 제공한다.

- 연결 이슈: [#37](https://github.com/rupria/codex_game/issues/37)
- 상세 아트 안내: `programer/CodexGame/ArtReferences/Halli_Item_0_3_7/README.md`
- 기계 판독 카탈로그: `programer/CodexGame/ArtReferences/Halli_Item_0_3_7/halli_item_ui_catalog_0_3_7.json`

## 할리갈리 적용 규칙

1. 화면 기준 왼쪽 공유 더미에는 플레이어 1번째 카드 뒤 AI 2번째 카드가 들어간다.
2. 화면 기준 오른쪽 공유 더미에는 AI 1번째 카드 뒤 플레이어 2번째 카드가 들어간다.
3. 같은 더미에 두 번째 카드가 들어오면 이전 카드를 아래·왼쪽으로 `42×22px` 이동한다.
4. 이전 카드는 최신 카드 위 레이어에 그려 두 카드 정보가 모두 보이게 한다.
5. 더미당 최대 2장만 표시하며, 불투명 검은 사각 배경은 제거한다.
6. 판정 대상은 규칙 로직에서 최신 카드로 유지한다.

## 할리갈리 필수 고정 UI

아래 항목은 우선순위나 선택 적용 항목이 아니며 같은 빌드에 모두 반영한다.

1. 화면 좌측 하단에 플레이어 획득 카드 트레이를 할리갈리 진행 내내 표시한다.
2. 트레이 PNG는 `Halli_0_3_4/player_acquired_tray_open_378x130_0_3_4.png`, 기준 좌표는 `(24,406)`, 크기는 `378×130`이다.
3. 획득 카드 앞면은 트레이 내부 `(112,29)`부터 `50px` 간격으로 최대 5장 표시한다.
4. 플레이어 획득 수가 0이어도 트레이 본체는 유지한다.
5. AI용 우측 하단 획득 카드 트레이는 표시하지 않는다.
6. `Q 왼쪽`, `E 오른쪽`, `W 1장 펼치기` 조작 문구를 화면에서 제거한다.
7. 상단의 `커뮤니티 카드` 또는 `커뮤니티` 문구를 제거한다. 카드와 잠금 상태는 유지한다.

## 아이템 선택 단계 적용

1. 보유 아이템이 없으면 단계를 자동 건너뛴다.
2. 보유 아이템이 있으면 4칸 목록과 선택 아이템 상세를 불투명 모달로 연다.
3. 대상 카드가 필요한 효과는 상세 영역을 대상 카드 선택 상태로 전환한다.
4. 유효 대상 선택 전 `사용`은 비활성, `건너뛰기/패 확정`은 활성 상태로 둔다.
5. 아이템 사용 후 목록을 다시 평가해 다음 아이템을 선택하거나 단계를 종료한다.
6. 모달이 열린 동안 뒤쪽 입력을 완전히 차단한다.
