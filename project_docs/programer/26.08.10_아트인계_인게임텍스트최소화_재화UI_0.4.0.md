# 아트 인계 — 인게임 텍스트 최소화·재화 UI 0.4.0

## 적용 범위

`07_인게임_텍스트_최소화_및_재화_UI_기준.md`를 기존 아트 패키지와 대조했다. 아래 항목은 우선순위나 선택 항목이 아니며 같은 적용 범위에 전부 포함한다.

1. 일반 플레이 화면에서 장르·단계·재화 명칭을 제거한다.
2. 기본 재화와 일회성 재화를 색이 아닌 아이콘 형태와 고정 위치로 구분한다.
3. 상점에서 일회성 → 기본 재화 순서를 왼쪽 → 오른쪽으로 고정한다.
4. 일회성 재화가 남은 첫 상점 이탈 입력은 문장 없는 경고 상태를 재생한다.
5. 두 번째 이탈 입력은 일회성 재화 소멸 상태를 재생한다.
6. 5장 승부 예측은 승리·패배 버튼 대신 플레이어·AI 초상 중 예상 승자를 선택한다.
7. 할리갈리 좌측 하단 플레이어 획득 카드 트레이는 진행 내내 유지한다.

## 문자열 표시 정책

| 정보 | displayPolicy | 표시 방식 |
|---|---|---|
| 장르·단계 명칭 | `hidden` | 카드·벨·테이블 배치로 전달 |
| 재화 명칭 | `hidden` | 탄환 아이콘+숫자 |
| 카드 펼치기·좌·우 문구 | `hidden` | 카드/벨 아이콘과 키캡 |
| Q/W/E | `icon_only` | 키캡 그래픽만 표시 |
| 승리·패배 문구 | `hidden` | 플레이어·AI 초상 선택 |
| 아이템 이름·효과 | `focus_only` | 포커스·hover·상세에서만 표시 |
| 수량·타이머 | `always` | 숫자만 표시 |

기존 문자열 키는 삭제하지 않는다. 표시 정책만 변경해 접근성 이름과 개발·QA 로그에는 내부 명칭을 유지한다.

## 연결 수용 기준

- [ ] 일반 플레이 화면에 `총알`, `일회성 총알`, `할리갈리`, `포커`가 보이지 않는다.
- [ ] 기본·일회성 아이콘을 흑백으로 보아도 형태로 구분할 수 있다.
- [ ] 상점의 두 재화가 일회성(왼쪽) → 기본(오른쪽) 순으로 보인다.
- [ ] 상품 가격은 탄환 아이콘+숫자만 보인다.
- [ ] 첫 이탈 경고와 두 번째 이탈 소멸에 설명 문장이 없다.
- [ ] 예측 입력은 플레이어·AI 초상 선택으로만 완료된다.
- [ ] `승리/패배` 체크·X 메달과 문구가 화면에 남지 않는다.
- [ ] 할리갈리의 Q/W/E는 키캡만 보이고 `왼쪽/오른쪽/카드 펼치기` 문구는 없다.
- [ ] 좌측 하단 플레이어 획득 카드 트레이가 항상 보인다.
- [ ] 접근성 이름과 QA 로그의 내부 상태명은 유지된다.

게임 규칙·소비 순서·재화 데이터는 프로그래머 작업 범위이며, 이번 변경에는 C# 파일을 포함하지 않는다.
