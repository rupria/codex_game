## 구현 범위

- 할리갈리 승자 최종 획득 카드가 4장 이상일 때만 참가자별 독립 10% 조커 판정을 1회 수행한다.
- 패자 획득 카드는 조커 판정 전에 무작위 풀로 이동하며, 패자는 조커 지급 대상이 되지 않는다.
- 조커는 52장 기본 덱·공용 카드·무작위 풀에 들어가지 않고 개인 선택 후보에 최대 1장만 추가된다.
- 2번째 공용 카드를 개인 카드 선택 전에 결정·공개하고, 선택 완료 뒤에도 같은 카드가 유지된다.
- 1라운드는 3장 직접 선택, 2라운드부터는 2장 직접 선택 후 1장 무작위 보충으로 처리한다.
- 선택된 조커는 개인 카드 3장 중 1장으로 계산하며, 미선택 조커는 해당 포커 라운드에서 폐기한다.
- 아이템 처리 뒤 플레이어 조커 연출 → 완성 가능한 족보 선택 → 패 확정 → 승패 예측 순서로 잠근다.
- 족보별 가능한 대체 카드 중 기존 랭크·문양 우선순위로 가장 강한 1개를 결정하고 실카드 중복을 금지한다.
- AI는 가장 강한 합법 족보를 내부에서 자동 선택하며, 쇼다운 전에는 조커 보유·선택 정보를 노출하지 않는다.
- 조커 선택 UI 문자열을 ko/en Key 기반 카탈로그에 추가했다.
- QA 치트에 플레이어·AI 각각의 조커 미대상·미출현·출현 downstream 프리셋을 추가했다.
