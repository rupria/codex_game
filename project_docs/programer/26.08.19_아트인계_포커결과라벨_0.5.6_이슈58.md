# 이슈 #58 포커 결과 라벨 아트 인계 — PokerResultLabel 0.5.6

## 확인된 원인

`PokerDevPanel.DrawResult()`는 기본 결과 요약 2줄 뒤에 아이템 상태 문구를 추가해 3줄 이상을 만들 수 있지만, 현재 `PokerResultOverlayRenderer.Draw()` 호출 영역은 `(86, 204, 788, 92)`로 고정되어 있다. 23px 글꼴과 상하 여백을 포함하면 세 번째 줄이 아래쪽에서 잘린다.

## 추가된 위치

- 런타임 PNG: `Assets/Art/Prototype/UI/PokerResultLabel_0_5_6/`
- 편집 원본·Aseprite 생성 스크립트: `ArtReferences/PokerResultLabel_0_5_6/source/`
- 960×540 시안: `ArtReferences/PokerResultLabel_0_5_6/preview/`
- 좌표·상태 카탈로그: `ArtReferences/PokerResultLabel_0_5_6/poker_result_label_art_catalog_0_5_6.json`
- 승인 해시: `ArtReferences/PokerResultLabel_0_5_6/APPROVED.sha256`

## 아트 구성

- 높이: compact 108px / standard 132px / expanded 164px
- 결과 상태: success 청록 / failure 적색 / neutral 황동
- 선택형 아이템 상태 칩: `poker_result_item_status_chip_360x32_0_5_6.png`
- 좌측 44×44 결과 배지 영역과 우측 텍스트 안전 영역을 분리했다.
- 기존의 굵은 상·하단 색 막대를 얇은 상태 테두리로 교체해 실제 문구 공간을 늘렸다.

## 프로그래머 연결 작업

1. 고정 `Rect(86f, 204f, 788f, 92f)`를 제거하고, 로컬라이즈된 문구의 `GUIStyle.CalcHeight` 결과로 높이를 선택한다.
2. 필요한 높이를 108 / 132 / 164 중 하나로 올림 처리한다. 권장 배치는 compact `(86,190)`, standard `(86,178)`, expanded `(86,160)`이다.
3. 기본 2줄 결과 요약과 선택형 아이템 상태를 같은 문자열에 합치지 않는다. 요약은 패널 텍스트 영역, 아이템 상태는 360×32 칩에 별도 렌더링한다.
4. 실제 성공 또는 보험 보정 성공은 success, 실패는 failure, 예측 판정이 아닌 안내는 neutral을 사용한다.
5. 배지 영역 이후 로컬 x=72부터 텍스트를 배치하고, 패널 외곽 16px 안전 여백을 유지한다.
6. 결과 계산, 보험 충전 소비, 타임아웃과 다음 단계 진행 로직은 변경하지 않는다.

## 검수 조건

- 한국어·영어에서 2줄, 3줄, 4줄 결과가 모두 패널 안에 보인다.
- 보험 성공, 실제 성공, 실패, 총열 방어 등 선택형 아이템 상태가 요약 문구와 겹치지 않는다.
- 960×540, 1280×720, 1920×1080에서 중앙 정렬과 텍스트 안전 여백을 유지한다.
- 패널이 이전 92px 결과 라벨을 완전히 덮고 테이블 문양이 문구 아래로 비치지 않는다.
- 팝업이 열린 동안 기존 결과 확인·다음 진행 입력은 유지한다.
