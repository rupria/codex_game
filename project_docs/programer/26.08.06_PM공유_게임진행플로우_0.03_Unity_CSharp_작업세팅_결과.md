## 3. 작업 진행 방식

### 코드와 표현 분리

- 승패·카드 획득·종 반응 속도는 Unity 물리엔진과 분리된 순수 C# 규칙으로 시작했다.
- Unity 장면, 애니메이터, 파티클, 셰이더와 오디오는 판정 결과를 표현하는 역할로 제한한다.
- 카드와 종 오브젝트는 필요할 때 UI EventSystem 또는 단순 Raycast로 입력만 받고 충돌 결과를 게임 규칙으로 사용하지 않는다.
- 동시 종 입력은 기획 0.03에 따라 플레이어 승리로 판정한다.
- 기획에 없는 경우를 임의 구현하지 않고 `Unspecified` 상태로 노출한다.
