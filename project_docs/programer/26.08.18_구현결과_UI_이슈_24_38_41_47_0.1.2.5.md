## 반영 내용

- #24: 탄 단면, 6프레임 불꽃, 8프레임 시간 초과 폭발을 최신 아트에 연결했다.
- #42~#44: 가이드 페이지 판과 점 좌표를 맞추고 첫 튜토리얼 건너뛰기 UI를 제거했다.
- #43: 플레이 화면 가이드에서 구 명칭을 제거하고 `Three Call`·`Showdown`을 사용한다.
- #45: 상대 소개 프레임에 스테이지별 현지화 이름과 진행 표식을 배치하고 값 없는 설명은 숨긴다.
- #54 최종 기준: 좌우 더미는 최대 2장, 59px 간격으로 표시하며 가장 마지막에 펼친 카드가 최상단에 그려진다. #46의 3장 기준은 폐기됐다.
- #47: 카드 선택 팝업은 최초 자동 선택 없이 시작하고 명시적인 클릭·키 입력으로만 선택한다.
- #38·#41: 0.1.2.5 보험 충전 2회/실제·보험 보정 분리, 플레이어 획득 카드 공개·AI 정보 비공개, 벨 6상태 연결을 회귀 확인했다.
