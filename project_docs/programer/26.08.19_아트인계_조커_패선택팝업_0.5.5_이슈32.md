# 이슈 #32 후속 — 조커 획득 뒤 패 선택 팝업 아트 인계

아트 세트: `PrivateSelection 0.5.5`  
연결 대상: `PrivateSelectionDevPanel`, `PlayableDevView`  
규칙 기준: 0.1.2.6, 이슈 #47의 최초 자동 선택 금지 유지

## 개선 목적

현재 개인 카드 선택 화면은 테이블 위에 제목·카드·기본 버튼을 직접 배치하여 살룬 배경과 시각적으로 섞인다. 조커 등장 연출 직후에도 선택 단계가 새 팝업으로 전환되었다는 인지가 약하다.

개선본은 화면 중앙의 단일 불투명 모달 안에 다음 요소를 고정한다.

- 왼쪽: 공개 카드 2장, 선택 수/필요 수, 확정 버튼
- 오른쪽: 후보 카드 최대 8장, 4열×2행
- 상단: 현지화 제목·제한 시간·한 줄 안내 안전 영역
- 전체 배경: 입력 차단용 감광 레이어

## 상태 표현

| 상태 | 표현 |
|---|---|
| idle | 어두운 황동 테두리, 선택 없음 |
| hover/focus | 청록 테두리, 키보드 포커스와 마우스 호버 공용 |
| selected | 밝은 청록 이중 테두리와 하단 다이아 표식 |
| confirmed | 황동 하이라이트, 확정 이동 전 잠금 상태 |
| disabled | 저채도 철색, 클릭 불가 |

`focus`와 `selected`는 반드시 별도 상태로 유지한다. 화면 진입 시 첫 번째 카드에 키보드 포커스가 있더라도 자동 선택으로 처리하지 않는다.

## 프로그래머 연결 작업

0. 현재 `dev` 점검 기준 `PrivateSelection_0_5_5` 전용 아트 세트와 `PlayableDevSceneBuilder` 바인딩이 없고, `PrivateSelectionDevPanel`은 여전히 공용 `GUILayout`과 기존 `PresentationUiArtSet.Candidate*`를 사용한다. 아래 연결이 완료되기 전에는 새 모달이 화면에 나오지 않는다.
1. `PlayableDevView`의 공용 `(48, 28, 864, 484)` GUILayout 영역 안에 선택 화면을 흘려 그리지 않고, `PrivateSelectionDevPanel`을 960×540 기준 전용 모달 레이어로 렌더링한다.
2. `private_selection_modal_dim_960x540_0_5_5.png`을 전체 화면에 합성한 뒤 `private_selection_modal_panel_860x456_0_5_5.png`을 `(50, 42)`에 배치한다.
3. 공개 카드 2장은 패널 로컬 `(18, 82, 190, 226)` 안에 배치하고, 후보 카드는 `(220, 82, 622, 336)` 안에서 4×2로 배치한다.
4. 후보 셀은 112×150, 카드 본체는 셀 로컬 `(14, 13, 84, 117)`을 사용한다. 카드 비율을 변형하지 않는다.
5. `snapshot.SelectedCards`, 현재 focus/hover, `snapshot.CanConfirm`을 각각 대응 상태 PNG에 연결한다.
6. 확정 버튼은 패널 로컬 `(23, 376, 180, 52)`에 배치하고 `idle/active/disabled` 상태를 사용한다.
7. 후보 목록에 플레이어 조커가 포함된 경우, 이 화면의 조커 후보 셀에서 `JokerReveal 0.5.4`를 먼저 재생하고 `JokerRevealSettled` 이후에만 선택 입력을 연다. 연출 중 클릭이 뒤쪽 후보로 전달되지 않게 한다.
8. 현재 선택 토글·키보드 좌우 이동·Enter 확정·제한 시간·카드 분배 규칙은 변경하지 않는다.

## 검수 조건

- 살룬 배경 위에서 팝업 외곽, 제목, 공개 카드, 후보 카드, 확정 버튼이 즉시 구분된다.
- 조커가 후보에 포함돼도 JOKER 표기와 인물이 잘리지 않는다.
- 후보 1장, 4장, 5장, 8장 상태에서 모두 모달 내부에 들어간다.
- 첫 진입 시 선택 수는 0이며 첫 카드가 자동 선택되지 않는다.
- 선택된 카드만 청록 이중 테두리를 사용한다.
- 960×540, 1280×720, 1920×1080 및 ko/en에서 팝업이 잘리지 않는다.
- 모달이 열린 동안 테이블의 벨·덱·아이템 입력이 차단된다.
