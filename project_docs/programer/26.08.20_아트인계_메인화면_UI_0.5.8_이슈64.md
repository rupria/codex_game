## 프로그래머 연결

1. `PlayableDevSceneBuilder.MainMenuUi056ArtRoot`를 새 0.5.8 루트로 교체하고 이름도 최신 버전에 맞춘다.
2. `MainMenuUiArtSet` 구조는 그대로 사용한다. START·GUIDE 각각 idle/hover/pressed를 새 PNG에 연결한다.
3. `PlayableDevView.DrawIntroArtLayout()` 배치를 아래 값으로 바꾼다.
   - START: `(290, 264, 380, 84)`
   - GUIDE: `(290, 354, 380, 84)`
4. 인트로 배경은 `start_screen_background_960x540_0_5_8.png`를 사용한다. 기존 `Halli_0_1_0/start_screen_background.png`를 다시 덮어쓰는 방식은 사용하지 않는다.
5. `UI_MAIN_START`, `UI_MAIN_GUIDE` 현지화 텍스트를 런타임에 계속 그린다. PNG에 글자를 굽지 않는다.
6. 한국어·English 언어 전환 컨트롤과 현재 동작은 유지한다.

## 검수 조건

- 960×540, 1280×720, 1920×1080에서 버튼이 중앙 정렬된다.
- 마우스 hover, 키보드 focus, pressed 상태가 각각 표시된다.
- START와 GUIDE 클릭 영역은 보이는 380×84 프레임보다 작지 않다.
- 첫 시작 가이드와 일반 GUIDE 동작은 회귀하지 않는다.
- 화면에 0.5.6 문장이나 버튼이 중복 노출되지 않는다.
- `pub`에는 별도 승인 없이 반영하지 않는다.

## 아트 제작 기록

- 승인 화면을 구성·재질 기준으로 사용했다.

- 최종 크기, 버튼 상태, 합성, Aseprite 원본과 Unity 메타는 Aseprite 기반으로 제작·검수했다.
