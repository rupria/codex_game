- GitHub: [#19 할리갈리 단계에서 카드 UI가 어색하게 노출되는 현상](https://github.com/rupria/codex_game/issues/19)
- 범위: 게임 화면 하단 좌측 플레이어 획득 카드 보관함과 우측 AI 획득 상태 패널
- 언어 설정, 카운트 문자열, 게임 로직과 중앙 조작 UI는 변경하지 않았다.

## 디자인 변경

### 플레이어

- 큰 청록 네온 박스를 어두운 월넛·가죽 트레이로 변경했다.
- 왼쪽 작은 칸은 아이템 슬롯이며 `+` 버튼이 아니다. 혼선을 막기 위해 금색 링만 표시한다.
- 오른쪽은 획득 카드 최대 3장용 슬롯이다.
- 플레이어 구분은 얇은 청록 하단선과 중앙 마커로 제한했다.

### AI

- 잘못 노출되던 왼쪽 청록색 잔여 픽셀을 제거했다.
- 반응·판단 표시, 승인 카드 뒷면 스택, 3개 카운트 표시를 한 패널 안에서 분리했다.
- AI 구분은 얇은 적색 하단선과 중앙 마커로 제한했다.

## 레이아웃 주의

- 두 텍스처의 상단 20px는 투명 영역이다. 기존 `플레이어 획득 N`, `AI 획득 N` 언어 텍스트가 패널 테두리나 카드와 겹치지 않도록 비워 두었다.
- 현재 RectTransform 크기를 유지해도 되지만 세로로 과도하게 늘어날 경우 원본 비율 3:1에 가깝게 맞추는 것을 권장한다.
- 카드 슬롯 위에 동적으로 앞면을 출력한다면 플레이어 카드 중심은 로컬 X 약 153, 238, 323을 기준으로 한다.
- Point 필터를 유지한다.
