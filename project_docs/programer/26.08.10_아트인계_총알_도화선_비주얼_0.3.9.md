# 26.08.10 아트 인계 — 총알·할리갈리 도화선 비주얼 0.3.9

## 문제

- 총알은 0.3.3에서 황동 탄환으로 개선됐지만 실제 UI 크기에서 탄두와 탄피의 구조가 약하게 읽힌다.
- 할리갈리 타이머는 최종 투명 아트가 없어 단색 사각 막대, 절차형 매듭, 정적인 불꽃·폭발 대체 표현을 사용하고 있다.
- 밝고 깨끗한 황마 밧줄은 어두운 웨스턴 살룬 배경과 분리되어 보인다.

## 아트 완료

### 총알

- 구리 탄두, 고정 홈, 탄피 목, 황동 몸통, 추출 림, 뇌관을 `24×40` 안에서 분리했다.
- `idle / shine / low` 상태를 다시 제작했다.
- 1~2발 플립·반짝임과 3발 이상 불규칙 붓기 시트를 새 총알로 재생성했다.

### 도화선

- 밝은 밧줄 대신 기름·그을음이 밴 짙은 웨스턴 도화선으로 변경했다.
- 본체, 탄 끝 char cap, 6프레임 불꽃, 8프레임 시간 초과 폭발을 분리했다.
- 불꽃에는 속불·불티·연기, 폭발에는 섬광·화염·검은 연기 단계를 포함했다.

## 프로그래머 연결

1. `HalliUiArtSet.RopeBody`에는 `halli_rope_braided_body_258x16_0_3_9.png`를 연결한다.
2. 기존 정적 연결만 사용할 경우 `RopeFlame`과 `RopeExplosion`에는 각각 static fallback PNG를 연결한다.
3. 최종 연출은 6프레임 flame sheet와 8프레임 explosion sheet를 프레임 단위로 재생한다.
4. 남은 밧줄은 전체 텍스처를 폭에 맞춰 찌그러뜨리지 말고 UV 또는 clip rect로 왼쪽부터 잘라 꼬임 간격을 유지한다.
5. char cap을 남은 밧줄의 `xMax`에 겹쳐 그린 다음 불꽃을 그린다.
6. 텍스처 밧줄에는 현재의 갈색 `GUI.color`를 중복 적용하지 않고 흰색 또는 중립 tint를 사용한다.
7. 긴급 상태는 밧줄 전체를 빨갛게 만들지 않고 불꽃 속도·크기와 char cap 잔불만 강화한다.
8. 상점·주머니·결제 연출의 총알 참조를 `BarShop_0_3_9`로 교체한다.
