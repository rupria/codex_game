## 완료 게이트

1. 인계서의 `새 파일 → Unity 슬롯 → 구형 경로 제거`를 모두 반영한다.
2. `rg` 또는 Unity 참조 검색으로 구형 실행 경로 참조 0건을 확인한다.
3. Unity 실제 화면에서 시안과 같은 위치·크기·상태를 확인한다.
4. 프로그래머가 이슈에 실제 빌드 스크린샷과 연결 커밋을 남긴다.
5. 위 4단계 전에는 배포하지 않는다.

새 실행 자산의 `.meta`는 `ArtReferences/RuntimeBindingTools/generate_stable_unity_meta_0_6_0.ps1`로 생성한다. GUID 시드는 로컬 절대 경로가 아니라 Unity `Assets/` 상대 경로이므로 다른 PC와 worktree에서도 동일하다.
