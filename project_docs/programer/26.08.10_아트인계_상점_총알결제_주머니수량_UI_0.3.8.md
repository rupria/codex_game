# 26.08.10 아트 인계 — 상점 총알 결제·주머니 수량 UI 0.3.8

## 확인된 문제

재화 소모 시 주머니 안 표시 총알이 줄지 않고 추가되는 화면이 확인됐다. 고정 총알이 포함된 주머니 이미지와 런타임 총알 표시가 동시에 사용되면 실제 `BulletCount`와 화면 수량이 불일치한다.

## 아트 변경

- 고정 총알이 없는 빈 주머니 PNG 제공
- 개별 총알 PNG 제공
- 구매 중 수량 변경을 가리는 플레이어 장갑 손 PNG 제공
- 가격 1~2: 화면 하단에서 동전처럼 튕기는 8프레임 회전·반짝임 시트
- 가격 3 이상: 주머니를 기울여 테이블에 붓는 8프레임 시트

## 프로그래머 연결 기준

1. 기존 고정 총알 포함 주머니는 런타임 잔액 표시에 사용하지 않는다.
2. `PlayableGameSnapshot.BulletCount`를 표시 수량의 단일 원본으로 사용한다.
3. 구매 시작 시 손 오버레이로 주머니를 가린다.
4. 완전 가림 프레임에서 총알 자식을 현재 `BulletCount`와 같은 수로 재구성한다.
5. `Price <= 2`면 튕김, `Price >= 3`이면 붓기 연출을 재생한다.
6. 손이 빠진 뒤 차감된 수량을 공개한다.
7. 구매 차감·인벤토리 반영은 기존 규칙대로 한 번만 수행한다.
