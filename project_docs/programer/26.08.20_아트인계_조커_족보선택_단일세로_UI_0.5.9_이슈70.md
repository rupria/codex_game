## 프로그래머 연결

1. #70 전용 아트 세트의 경로를 `JokerHandChoice_0_5_9`로 갱신한다.
2. `PokerDevPanel.DrawJokerHandChoice()`의 임시 `GUI.Box` 및 2열 계산을 제거한다.
3. 960×540 기준 배치는 다음을 사용한다.
   - dim: `(0, 0, 960, 540)`
   - panel: `(180, 60, 600, 420)`
   - 첫 버튼: `(260, 236, 440, 44)`
   - 한 열, 행 pitch `46`
4. `snapshot.LegalPlayerJokerOptions`의 실제 항목만 원래 순서대로 그린다. 목록에 없는 족보의 빈 자리나 비활성 자리표시는 만들지 않는다.
5. 1~5개는 패널 안에 직접 표시한다. 6개 이상이면 단일 열을 유지한 채 스크롤 처리하며 2열로 되돌리지 않는다.
6. 제목·가이드·족보명은 기존 현지화 경로를 유지한다.
   - `UI_POKER_JOKER_CHOICE_TITLE`
   - `UI_POKER_JOKER_CHOICE_GUIDE`
   - `CategoryName(option.Category, localization)`
7. 족보 버튼을 누르면 기존처럼 `chooseJokerHand(option.Category)`를 즉시 호출한다. 별도 확인 버튼은 추가하지 않는다.
8. 팝업이 열린 동안 뒤쪽 카드·예측·키보드 입력을 완전히 차단한다.

## 비변경 범위

- 조커 족보 계산, 치환 카드 결정, 포커 비교 규칙을 변경하지 않는다.
- 조커 카드 앞면은 최신 `Cards_0_08`을 유지한다.
- 보험·예측 UI는 #67·#68의 최신 명세를 유지한다.
- `MainMenu_0_5_8`과 #64 연결에는 변경이 없다.

## 검수 조건

- 가능한 족보가 적을 때 빈 슬롯 없이 한 열로만 보인다.
- 4개 상태에서 시안과 같은 크기·간격으로 표시된다.
- 패널 내부가 완전히 불투명하고 뒤 카드·텍스트가 족보명과 겹치지 않는다.
- hover/focus, selected, disabled 상태가 구별된다.
- ko/en에서 440×44 버튼 안의 족보명이 잘리지 않는다.
- 팝업 밖 클릭이나 단축키가 포커 화면에 전달되지 않는다.
- `pub`에는 별도 승인 없이 반영하지 않는다.

## 제작 기록

- 승인된 단일 세로 목록 시안은 내장 이미지 편집 도구로 방향을 확정했다.
- 최종 런타임 패널, 버튼 상태, 프리뷰, Aseprite 원본과 Unity 메타는 Aseprite로 제작·검수했다.
