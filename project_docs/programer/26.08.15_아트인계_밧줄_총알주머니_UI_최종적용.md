# 아트 인계 — 밧줄·총알 주머니·할리갈리 UI 최종 적용

## 적용 범위

이 문서는 2026-08-15 사용자 확정안의 프로그래머 연결 기준이다. 아트 파일은 `dev`에만 반영하며, 제한시간 계산·카드 판정·Q/E/W 입력·카드 레이어 순서는 변경하지 않는다.

## 1. 할리갈리 밧줄·불꽃·폭발

- `halli_rope_burn_storyboard_1920x540_0_3_9.png`: 실제 화면과 투명 배경 비교 프리뷰.

### 유지 파일

- `halli_rope_braided_body_258x16_0_3_9.png`
- `halli_rope_burn_char_cap_24x16_0_3_9.png`
- `halli_rope_timeout_burst_64x64_0_3_9.png`
- `halli_rope_timeout_burst_8f_512x64_0_3_9.png`

### 런타임 연결

1. `PlayableDev.unity`와 빌더 생성 경로에서 `_ropeBody`, `_ropeFlame`, `_ropeExplosion`이 `{fileID: 0}`이 아니어야 한다.
2. 밧줄은 UV 크롭으로 오른쪽 끝이 줄어든다. 텍스처 폭을 압축하지 않는다.
3. 남은 밧줄 `xMax`에 `RopeFlame` 중앙 피벗을 배치한다. 불꽃 바닥을 맞추면 다시 분리되어 보인다.
4. 정적만 지원하면 `halli_rope_burn_flame_32x32_0_3_9.png`을 사용한다. 애니메이션 지원 시 6프레임 시트를 사용한다.
5. 타임아웃에서는 별형 섬광 뒤에 검댕 파편이 남는 8프레임 시트를 사용한다.

## 2. 상점 총알 주머니

런타임 경로: `Assets/Art/Prototype/UI/BarShop_0_3_8/`

### 추가 파일

- `bar_shop_ammo_pouch_pile_5_180x150_0_3_8.png`: 5발이 자연스럽게 쌓인 정적 폴백.

### 교체된 파일

- `bar_shop_ammo_pouch_empty_180x150_0_3_8.png`: 가죽 주머니 실루엣은 유지하고 내부의 사각 프레임과 5개 세로 슬롯을 제거. 입구는 둥근 열린 포켓.
- `bar_shop_pouch_count_change_states_880x180_0_3_8.png`: 5→4→3→2발, 손 없이 눕힌 탄알 더미가 감소하는 프리뷰.
- `bar_shop_pouch_count_change_states_0_3_8.aseprite`: 동일 상태의 원본.

### 유지 파일

- `bar_shop_ammo_pouch_bullet_24x40_0_3_8.png`: 개별 총알.
- `bar_shop_bullet_coin_flip_glint_8f_512x64_0_3_8.png`: 가격 1~2발 투척·회전.
- `bar_shop_bullet_pour_table_8f_1280x120_0_3_8.png`: 가격 3발 이상 불규칙 붓기.

### 사용 중단 파일

- `bar_shop_ammo_pouch_hand_cover_220x180_0_3_8.png`: 삭제하지는 않지만 연결하지 않는다. 손 연출은 전부 제거한다.

### 런타임 연결

1. 주머니 본체 위에 개별 총알 자식을 표시한다. 자식 수는 항상 현재 `BulletCount`와 같아야 한다.
2. 0~5발은 카탈로그의 서로 다른 X/Y/회전값을 사용해 전부 가로·사선으로 눕힌다. 6발 이상도 눕힌 상태로 행을 엇갈리게 배치한다.
3. 구매 뒤 `BulletCountAfter = BulletCountBefore - Price`가 되어야 하며, 소비 시 화면의 총알이 늘어나면 실패다.
4. 손 가림 또는 손 등장 코루틴은 호출하지 않는다.
5. 가격 1~2발은 화면 하단에서 총알을 던지는 시트만 재생한다. 가격 3발 이상은 테이블에 불규칙하게 붓는 시트를 재생한다.

## 3. 인게임 텍스트 제거

할리갈리 전투 화면에서 다음 텍스트는 표시하지 않는다.

- `할리갈리`
- `커뮤니티`
- `← 왼쪽 오른쪽 →`
- `↑ 1장 펼치기`
- `Q 왼쪽`, `E 오른쪽`, `W 1장 펼치기` 형태의 키 안내

벨·카드 덱·클릭 영역은 유지한다. 키 입력 Q/E/W와 게임 판정은 삭제하지 않는다. 조작 설명은 가이드/접근성 화면에만 둔다.

## 4. 보존 조건

- 먼저 나온 카드가 위 레이어에 유지되는 현재 프로그래머 수정 상태를 건드리지 않는다.
- 후속 카드는 아래 레이어로 누적하며 가로 겹침은 폭의 10% 이내 기준을 유지한다.
- 밧줄·불꽃·텍스트 제거 때문에 커뮤니티 카드, 벨, 획득 카드 UI 위치를 이동하지 않는다.
- 기존 `.meta` GUID를 유지한 교체 파일은 코드 경로를 바꾸지 않는다.

## 5. 완료 판정

- [ ] 밧줄이 주황 막대가 아니라 굵은 꼬임 도화선으로 보인다.
- [ ] 불꽃이 밧줄 끝과 붙어 있고 촛불형 삼각 아이콘으로 보이지 않는다.
- [ ] 타임아웃 폭발이 별형 섬광·파편·검댕 순서로 보인다.
- [ ] 주머니 내부에 세로 슬롯, 사각 패널 또는 사각 총알 프레임이 없다.
- [ ] 주머니 안 총알이 실제 수량만큼 모두 눕혀져 자연스럽게 쌓인다.
- [ ] 손 이미지가 한 프레임도 나타나지 않는다.
- [ ] 결제 시 총알 투척 또는 붓기만 재생된다.
- [ ] 지정된 인게임 문구가 모두 보이지 않는다.
- [ ] Q/E/W 입력과 카드 레이어 순서는 기존처럼 동작한다.
