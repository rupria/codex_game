# 아트 인계 — 밧줄·총알 주머니 UI 최종 적용

## 적용 원칙

- 아트 파일은 `dev`에만 반영합니다.
- 게임 규칙, 카드 순서, 제한시간 계산, Q/E/W 입력 코드는 변경하지 않습니다.
- 런타임 C#·Unity 장면·프리팹 수정은 프로그래머 작업입니다.

## 1. 할리갈리 밧줄·불꽃·폭발

경로: `Assets/Art/Prototype/UI/Halli_0_3_9/`

- `halli_rope_braided_body_258x16_0_3_9.png`: 꼬임이 읽히는 밧줄 본체
- `halli_rope_burn_char_cap_24x16_0_3_9.png`: 타들어 간 끝단
- `halli_rope_burn_flame_32x32_0_3_9.png`: 정적 불꽃
- `halli_rope_burn_flame_6f_192x32_0_3_9.png`: 32×32, 6프레임 불꽃
- `halli_rope_timeout_burst_64x64_0_3_9.png`: 정적 폭발
- `halli_rope_timeout_burst_8f_512x64_0_3_9.png`: 64×64, 8프레임 폭발

연결 조건:

1. 밧줄은 남은 시간 비율에 맞춰 오른쪽 끝이 줄어듭니다.
2. 불꽃 중심은 남은 밧줄의 오른쪽 끝에 고정합니다.
3. 시간 종료 시 불꽃을 숨기고 폭발 시트를 한 번 재생합니다.
4. 커뮤니티 카드, 벨, 카드 레이어 순서는 변경하지 않습니다.

## 2. 상점 총알 주머니 — 최종 정적 확정

경로: `Assets/Art/Prototype/UI/BarShop_0_3_8/`

### 반드시 연결할 파일

- `bar_shop_ammo_pouch_static_5_180x150_0_3_8.png`

승인된 열린 가죽 주머니와 총알 5발을 그대로 사용한 180×150 투명 PNG입니다. 이 한 장을 상점 우측 하단 주머니 슬롯에 표시합니다.

### 호환 파일

- `bar_shop_ammo_pouch_pile_5_180x150_0_3_8.png`

기존 경로를 즉시 교체할 수 있도록 위 정적 이미지와 동일한 내용으로 갱신했습니다. 신규 연결은 `static_5` 파일을 기준으로 합니다.

### 제거할 연결

- `PlayableGameSnapshot.BulletCount`로 주머니 이미지를 조립하는 로직
- 개별 총알 자식 오브젝트와 수량별 레이아웃
- 빈 주머니 이미지 전환
- 손 가림 애니메이션
- 총알 던지기·튕기기·붓기 애니메이션
- 구매 전후 주머니 스프라이트 변경

주머니는 더 이상 재화 수량 표시기가 아닙니다. 재화 값과 구매 계산은 기존 데이터·텍스트 UI에서 처리하고, 주머니 이미지는 항상 동일하게 유지합니다.

## 3. 프로그래머 적용 순서

1. 현재 상점 주머니 `Image.sprite`를 `bar_shop_ammo_pouch_static_5_180x150_0_3_8.png`로 교체합니다.
2. `SetNativeSize`를 강제하지 말고 기존 180×150 슬롯 안에서 종횡비를 유지합니다.
3. 주머니 아래 또는 위에 붙어 있는 개별 총알·손·상태 프레임 자식을 비활성화합니다.
4. 주머니 오브젝트를 `BulletCount` 변경 이벤트에서 분리합니다.
5. 구매 전후 같은 이미지가 유지되는지 확인합니다.

## 4. 완료 판정

- [ ] 상점 우측 하단에 승인 이미지가 한 장만 표시된다.
- [ ] 총알 5발이 모두 온전히 보인다.
- [ ] 자홍색 또는 사각 배경이 보이지 않는다.
- [ ] 손과 추가 총알 자식이 겹치지 않는다.
- [ ] 구매 후에도 주머니 모습이 바뀌지 않는다.
- [ ] 구매·재화 차감 기능은 정상 동작한다.
- [ ] 밧줄·불꽃·폭발 리소스 연결이 유지된다.
