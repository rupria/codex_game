## 알려진 범위와 후속 처리

- 최종 공개판에서 개발 치트를 제거할 때는 일반 WebGL 빌드 방식으로 재빌드한다.
- 아트 개선본이 추가되면 런타임 연결 지점은 유지하고 리소스만 교체한다.
- 배포 산출물 자체는 Git에 커밋하지 않으며 Cloudflare Pages에 별도 업로드한다.
- 자동 플레이 로그 수집은 이번 배포에 포함하지 않았다. 수집 항목의 명시적 승인과 Production의 `DATABASE_URL`, `GUEST_TOKEN_SECRET`, TiDB 스키마 적용 후 별도 반영한다.
- 승인 후보 로그는 익명 UUID, 승·패·중도 이탈, 스테이지, 소요 시간, 콘텐츠 버전, QA 치트 사용 여부이며 이름·이메일·키 입력 원문·자유 텍스트는 수집하지 않는다.
- Cloudflare Production 브랜치는 `pub`으로 확인했다. Production 고정 URL에는 별도 로그인·설치가 필요 없다.
