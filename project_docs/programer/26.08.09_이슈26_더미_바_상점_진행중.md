## 현재 구현 범위

- `StageWon → BarShop → NextStageTransition → 다음 스테이지` 런타임 경계를 분리했다.
- 스테이지 보상은 상점 진입 전에 기존 잔여 HP 기준으로 한 번만 정산한다.
- 더미 상품 데이터 6종에 `id`, 현지화 이름 Key, 아이콘 Key, 가격, 효과 Key, 표시 상태를 둔다.
- 방문 시 시드 기반으로 3개 슬롯을 구성하고, 무료 리롤 1회로 나머지 3개 상품을 전부 교체한다.
- 같은 방문의 두 번째 리롤과 `다음 가게로` 중복 입력은 상태 게이트에서 거부한다.
- 다음 상점 방문에서는 리롤 상태를 초기화한다.
- 상점 화면에는 정산된 총알, 현재 HP, 상품 3개, 리롤과 다음 가게 버튼만 표시한다.
- 구매 버튼은 비활성이고 실제 구매·총알 차감·인벤토리·아이템 효과를 호출하지 않는다.
- 상점과 다음 스테이지 전환 중에는 할리갈리·포커 입력 및 전투 타이머를 진행하지 않는다.

## 아트 연결 경계

최종 아트 SHA `bf2ebd9137b9d24c8cfdf330d165daba259b7b8f`의 전달물을 `BarShopUiArtSet`에 주입했다. 아트 미연결 시에는 절차형 폴백 화면이 표시되며 런타임 로직은 동일하다.

- 배경: `Background` — 960×540
- 상품 슬롯 공통 프레임: `SlotFrame`
- 리롤 버튼: `RerollIdle`, `RerollHover`, `RerollPressed`, `RerollDisabled`
- 다음 가게 버튼: `ContinueIdle`, `ContinueHover`, `ContinuePressed`
- 상태 패널: `BulletPanel`, `HealthPanel`
- 상품 아이콘 바인딩: `bar_shop.item.dummy_01`~`bar_shop.item.dummy_06`

문자열은 이미지에 굽지 않고 런타임 현지화 Key로 출력한다. 최종 인계 좌표에 맞춰 상태 패널, 상품 슬롯, 리롤·다음 진행 버튼의 표시 및 클릭 영역을 연결했다.
