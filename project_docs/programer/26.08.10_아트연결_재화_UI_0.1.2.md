# 0.1.2 재화 UI 아트 연결 슬롯

최종 아트는 아래 경로와 이름으로 추가한 뒤 Unity 메뉴 `Codex Game/Playable Dev/Create Scene`을 실행하면 런타임에 자동 연결된다. 파일이 없을 때는 코드 폴백이 유지되므로 아트 도착 전에도 기능 테스트가 가능하다.

경로: `programer/CodexGame/Assets/Art/Prototype/UI/Economy_0_1_2/`

| 파일 | 런타임 용도 |
|---|---|
| `currency_base_icon_48_0_1_2.png` | 현재 런 동안 유지되는 기본 재화 |
| `currency_temporary_icon_48_0_1_2.png` | 직후 상점에서 우선 소비되는 일회성 재화 |
| `currency_price_icon_24_0_1_2.png` | 상품 가격 |
| `currency_base_panel_160x58_0_1_2.png` | 상점·전투 기본 재화 수량 프레임 |
| `currency_temporary_panel_160x58_0_1_2.png` | 상점·전투 일회성 재화 수량 프레임 |
| `stage_reward_base_frame_240x96_0_1_2.png` | 스테이지 기본 보상 결과 프레임 |
| `stage_reward_temporary_frame_240x96_0_1_2.png` | 예측 성공 일회성 보상 결과 프레임 |
| `shop_exit_warning_icon_48_0_1_2.png` | 일회성 재화 잔량이 있을 때 첫 이탈 입력 경고 |

연결 규칙:

- 상점 표시는 `일회성 → 기본` 순서다.
- 결제는 일회성 수량을 먼저 줄이고 부족분만 기본 수량에서 줄인다.
- 일회성 잔량이 있으면 첫 이탈 입력은 아이콘 경고만 표시하고, 두 번째 입력에서 잔량을 소멸한 뒤 전환한다.
- 화면에는 재화 내부 명칭을 출력하지 않고 아이콘과 숫자만 사용한다.
- 새 에셋은 모두 선택 사항이다. 일부만 도착해도 해당 슬롯만 교체되며 게임 로직에는 영향이 없다.
