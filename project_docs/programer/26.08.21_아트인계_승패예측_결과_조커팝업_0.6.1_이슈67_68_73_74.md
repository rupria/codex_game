## #68 결과 화면 연결

1. `PokerResultOverlayRenderer.Draw(...)`가 만드는 중앙 대형 사각 결과 패널을 표시 계층에서 제거한다.
2. 결과 제목은 상단 320×48 플레이트에 표시한다. 예: `플레이어 승리`, `AI 승리`.
3. AI 개인 카드 3장은 결과 시점에 공개한다.
4. 커뮤니티 카드는 중앙에 최대 2장만 표시한다.
5. 플레이어 개인 카드 3장과 아이템 상자를 유지한다.
6. 사용자가 선택한 승리/패배 탭은 결과 상태에서도 selected 텍스처로 유지한다.
7. `poker_result_continue_{idle|hover}_164x44_0_6_1.png`를 `398,490,164,44`에 그린다. 히트 영역은 `390,482,180,56`이다.
8. 결과 계산, HP, 보상, 보험 소비, 진행 입력은 변경하지 않는다.

승인 화면은 `ArtReferences/PokerPredictionClean_0_6_1/preview/poker_result_no_modal_approved_960x540_0_6_1.png`이다.

## 보험·예측 성공 표시

- 보험을 사용한 스테이지에서만 `남은 보험 {InsuranceChargesRemaining}`을 표시한다. 0회도 표시한다.
- 우측의 별도 보험 충전 패널은 만들지 않는다.
- 아이템 상자 옆에는 `예측 성공 {RewardSuccessCount}/5`만 표시한다.
- 실제 성공과 보험 보정 성공을 UI에서 분리해 나열하지 않는다.

## 커뮤니티 카드 회귀 방지

- 커뮤니티 카드는 **최대 2장**이다.
- `416,218`부터 x축 72px 간격으로 0장·1장·2장만 검수한다.
- 3장 인계나 구형 프리뷰를 더 최신 기준으로 해석하지 않는다.
- AI 개인 카드 3장, 플레이어 개인 카드 3장은 변경하지 않는다.

## #74 조커 족보 팝업 연결

### 이미지와 배치

- 감광: `joker_hand_choice_dim_960x540_0_6_0.png`, `0,0,960,540`
- 패널: `joker_hand_choice_panel_compact_600x420_0_6_0.png`, `180,60,600,420`
- 족보 버튼: `joker_hand_option_{idle|hover|selected|disabled}_440x44_0_6_0.png`
- 첫 버튼: `260,236,440,44`
- 행 간격: 46px

0.6.0 패널은 버튼 뒤에 남던 중앙 세로 황동선을 제거했다. 패널의 가죽·황동 재질, 제목 영역, 단일 세로 목록 배치는 유지한다.

### 동작 계약

1. `snapshot.LegalPlayerJokerOptions`만 원래 순서대로 한 열에 표시한다.
2. 없는 족보를 위한 빈 슬롯을 만들지 않는다.
3. 1~5개는 직접 표시하고, 6개 이상은 한 열을 유지한 채 스크롤한다.
4. 클릭 시 기존 `chooseJokerHand(option.Category)`를 즉시 호출한다. 확인 단계를 추가하지 않는다.
5. 팝업 동안 뒤쪽 카드·예측·키보드 입력을 차단한다.
6. 제목·가이드·족보명은 기존 현지화 문자열을 사용한다.

## 장면 재생성과 확인 게이트

1. `PlayableDevSceneBuilder`에 두 신규 패키지를 연결한다.
2. `Codex Game/Playable Dev/Create Scene`으로 `PlayableDev.unity`를 재생성·저장한다.
3. 장면 YAML에서 구형 88px 예측 버튼 GUID와 구형 조커 패키지 GUID가 남지 않았는지 확인한다.
4. `ArtReferences/RuntimeBindingTools/audit_runtime_art_bindings_0_6_3.ps1`을 실행한다.
5. Unity에서 다음 스크린샷을 남긴다.
   - 승패예측 ko/en, idle/hover/selected/disabled
   - 결과 화면: 중앙 사각 팝업 0개, AI 카드 공개, Continue
   - 커뮤니티 0/1/2장
   - 조커 합법 족보 4개: 세로선 0개, 빈 슬롯 0개
6. 연결 검증 전에는 WebGL 공개 배포를 진행하지 않는다.
