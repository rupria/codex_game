## 1. #46 카드 펼치기 겹침

검수 시안:

`programer/CodexGame/ArtReferences/Halli_0_4_1/preview/halli_combined_improved_mock_960x540_0_4_1.png`

연결 기준:

- 한 더미에서 최대 3장의 앞면을 유지한다.
- 먼저 나온 카드가 위 레이어에 남는다. 최신 카드를 위로 올리지 않는다.
- 카드 간 가로 겹침은 카드 폭의 `10% 이하`로 제한한다.
- 아래 카드도 랭크·문양·해골 수를 판독할 수 있어야 한다.
- 위치만 변경하고 `history`, 판정 카드, 카드 ID 순서를 뒤집지 않는다.
- `HalliPileOverlapLayout.DrawOrderIndex`와 공개 이력의 논리 순서는 수정하지 않는다.

권장 960×540 값:

- 카드: 현재 런타임의 64×90 유지
- 옆 카드 이동: 58~60 px
- 가로 겹침: 4~6 px
- 세로 이동: 2~4 px
- 레일과 카드 사이 최소 간격: 12 px

구현 시 `PreviousCardOffsetX=-42`를 그대로 사용하면 22 px(폭의 약 34%)가 겹치므로 실패다. 3장을 보일 때는 `distanceFromNewest`를 사용해 `newestX - 58~60 × distanceFromNewest`로 계산한다.
