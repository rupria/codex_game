## 프로그래머 연결

1. 조커 족보 선택 전용 `JokerHandChoiceUiArtSet`을 추가하거나 `PokerUiArtSet`에 전용 필드를 추가한다.
2. `PlayableDevSceneBuilder`에서 0.5.8의 dim, panel, 네 버튼 상태를 연결한다.
3. `PokerDevPanel.DrawJokerHandChoice()`의 `GUI.Box` 임시 패널을 제거하고 아래 배치를 사용한다.
   - dim: `(0, 0, 960, 540)`
   - panel: `(100, 60, 760, 420)`
   - 첫 버튼: `(130, 236, 340, 44)`
   - 2열×5행, 열 간격 20, 행 pitch 46
4. 제목·가이드·족보명은 현재 현지화 경로를 유지한다.
   - `UI_POKER_JOKER_CHOICE_TITLE`
   - `UI_POKER_JOKER_CHOICE_GUIDE`
   - `CategoryName(option.Category, localization)`
5. 옵션은 반드시 `snapshot.LegalPlayerJokerOptions`만 그린다. 열 개보다 적으면 빈 자리는 그리지 않는다.
6. 현재처럼 족보 버튼을 누르면 `chooseJokerHand(option.Category)`를 즉시 호출한다. 확인 단계를 새로 추가하지 않는다.
7. 팝업이 열린 동안 테이블 뒤의 마우스·키보드 입력을 완전히 차단한다.

## 비변경 범위

- 조커 족보 계산, 치환 카드 결정, 포커 비교 규칙을 변경하지 않는다.
- 조커 카드 앞면은 최신 `Cards_0_08`을 유지한다.
- 보험·예측 UI는 #67·#68의 0.5.7 명세를 유지한다.

## 검수 조건

- 패널 내부가 완전히 불투명하여 뒤 카드와 텍스트가 족보명에 겹치지 않는다.
- 합법 족보가 1~10개일 때 모두 패널 안에 들어간다.
- hover/focus, selected, disabled 상태가 구별된다.
- ko/en에서 버튼 글자가 잘리지 않는다.
- 팝업 밖 클릭이나 단축키가 포커 화면에 전달되지 않는다.
- `pub`에는 별도 승인 없이 반영하지 않는다.
