# [보관본] #73 승패예측 UI 더미선 제거 0.6.0 아트 인계

> 이 문서는 2026-08-21 기준으로 대체됐다. 신규 연결에는 `PokerPredictionClean_0_6_1`과 `project_docs/programer/26.08.21_아트인계_승패예측_결과_조커팝업_0.6.1_이슈67_68_73_74.md`만 사용한다. 0.6.0 실행 자산을 복원하지 않는다.

## 결론

승패예측 화면의 노출된 임시 선과 구형 88px 초상화 버튼을 제거한다. 원형 테이블 배치, 커뮤니티 카드 최대 2장, 보험 잔여·예측 성공 표시 기준은 유지한다. 아트는 완료됐으며 Unity 연결은 프로그래머 작업이다.

## 프로그래머 작업

1. `PlayableDevSceneBuilder.pokerUiArtSet`의 구형 `IconOverhaul_0_5_0` 88px 예측 초상화 6개 연결을 제거하고 0.6.0 상태 이미지를 연결한다.
2. `PokerTableLayout.WinVisual/LoseVisual`의 60×60 좌표를 위 232×64 좌표로 교체하고 히트 영역은 시각 이미지보다 크게 유지한다.
3. `PokerDevPanel.DrawPredictionButton`은 빈 버튼을 그린 뒤, 전달받은 `label`을 각 `TextRect` 중앙에 실제 텍스트로 출력한다. PNG에는 문구가 없다.
4. `DrawPredictionTimer`의 720px 전폭 가이드 레이블을 제거한다. 제목 플레이트의 `384,30,232,28`에 `UI_POKER_PREDICTION_TITLE`을 출력하고 남은 시간은 별도 상태 문구에 출력한다.
5. `[MISSING:UI_POKER_PREDICTION_TITLE]`이 나오지 않도록 ko/en 키를 모두 연결한다.
6. 보험 아이템 사용 시에만 `남은 보험`을 표시하고, 예측 성공 횟수는 아이템 상자 옆에 표시한다.
7. 커뮤니티 카드는 `416,218`부터 72px 간격으로 최대 2장만 출력한다.
8. 0.5.7 실행 자산은 `ArtReferences/Archive/PokerPredictionResult_0_5_7_Runtime/`으로 이동됐다. 새 연결에서 해당 구형 실행 경로를 복구하지 않는다.

## 확인 조건

- 화면에 장식용 빈 수평선과 `[MISSING:...]` 문자열이 없다.
- 플레이어/AI 승부 예측 버튼에 ko/en 문구가 중앙 정렬된다.
- 커뮤니티 카드가 0장·1장·2장일 때 중앙 정렬되며 3장은 표시되지 않는다.
- 보험 미사용 시 보험 UI가 없고, 사용 시 `남은 보험`만 표시된다.
- 예측 성공은 아이템 상자 옆 텍스트로 표시된다.
- 예측 판정·보험 소모·시간 제한·HP·보상 계산은 변경하지 않는다.
