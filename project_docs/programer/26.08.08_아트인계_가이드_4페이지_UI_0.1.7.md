## 작업 결과

- 기존 3단 그림 한 장을 대체할 4쪽 가이드 아트를 제작했다.
- 공통 모달은 960×540 전체가 불투명하며 뒤쪽 메인 화면의 글자와 버튼이 보이지 않는다.
- 실제 PNG에는 한국어·영어 문장을 굽지 않았다. 페이지 제목·본문·이동 버튼은 다국어 Key로 별도 출력한다.
- 기존 `guide_overlay_background.png`는 기능 연결 전 빈 가이드가 노출되지 않도록 유지했다. 4쪽 구현 시 `guide_modal_background.png`를 사용한다.

## 960×540 기준 배치

- 페이지 그림: `(37, 126)`, 320×280
- 페이지 제목: `(336, 48)`, 267×50
- 본문: `(390, 145)`, 475×260
- 입력 중지 안내: `(48, 437)`
- 이전: `(270, 471)`
- 페이지 번호: `(430, 475)`
- 다음: `(542, 471)`
- 닫기: `(788, 471)`

모든 좌표는 좌측 상단 기준이며 실제 구현 방식에 따라 비율 좌표로 변환해도 된다.

## 기능 연결 필수사항

1. 모달이 열린 동안 전체 화면 입력 차단 레이어가 카드·버튼·언어 선택보다 위에 있어야 한다.
2. 모달 내부의 이전·다음·닫기만 입력을 받으며 `ESC`는 닫기로 연결한다.
3. 첫 쪽 이전과 마지막 쪽 다음에는 `guide_nav_button_disabled.png`를 사용하고 실제 입력도 막는다.
4. 가이드가 열려 있는 동안 게임 타이머와 게임 플레이 입력을 진행하지 않는다.
5. 페이지를 바꿔도 현재 언어를 유지하고 Google Sheets의 12개 가이드 Key를 조회한다.
6. 960×540, 1280×720, 1920×1080에서 본문 잘림과 버튼 겹침을 검수한다.
