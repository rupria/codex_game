## 1. 현재 결론

기능별 병렬 개발을 위한 아키텍처 기반과 0.06 카드 획득 판정은 `origin/dev`에 공유됐다.

현재 상태는 순수 C# 테스트와 Unity 컴파일이 가능한 개발 기반이다. 플레이 씬과 전체 게임 흐름은 아직 없으므로 실행 가능한 게임 빌드 상태는 아니다.

## 2. 구현 완료 범위

### 레이어 경계

- `CodexGame.Core`: Unity 비의존 결정적 규칙
- `CodexGame.Application`: Core를 사용하는 명령·이벤트·상태 머신·Port 셀
- `CodexGame.Presentation`: Unity 입력·View·Animation·Audio·Art 셀
- `CodexGame.Infrastructure`: 저장·온라인·시간 구현 셀
- `CodexGame.Bootstrap`: 런타임 조립 셀

레이어 간 참조 방향은 asmdef로 제한했다.

### 기능 셀

Core를 기능별 asmdef로 과도하게 나누지 않고 하나의 Core 어셈블리 안에서 폴더와 namespace로 병렬 작업 경계를 만들었다.

### 0.06 판정

- 판정 입력에 카드 문양과 해골 수를 함께 전달한다.
- 같은 문양의 `1+2`, `2+1`만 양쪽 카드를 획득한다.
- 서로 다른 문양의 `1+2`, `2+1`은 합이 3이어도 획득하지 않는다.
- 해골 3 카드는 상대 카드 문양과 관계없이 해골 3 카드만 획득한다.
- 미확정 `3+3`은 임의 결정하지 않고 `Unspecified`로 유지한다.
