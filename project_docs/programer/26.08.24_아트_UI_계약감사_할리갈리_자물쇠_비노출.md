# 아트·UI 계약 감사 — 할리갈리 자물쇠 비노출

## 목적

- 총괄 담당이 장면 재생성·빌드 통합을 수행하기 전에 최신 `dev`의 UI 회귀를 정리한다.
- 이미 공개된 첫 커뮤니티 카드 옆에 기능 없는 두 번째 카드 자물쇠가 계속 노출되는 문제를 제거한다.
- 사운드, 게임 규칙, 카드 데이터, 승인 PNG와 저장 장면은 이 수정에서 변경하지 않는다.

## 런타임 수정 위치

| 파일 | 적용 내용 |
|---|---|
| `Assets/Scripts/Presentation/Views/HalliDevPanel.cs` | `HalliOpening`과 본 단계의 `DrawLockedPublicSlot` 호출 및 폴백 렌더러 제거 |
| `Assets/Scripts/Presentation/Views/HalliBoardLayout.cs` | 더 이상 화면에 쓰지 않는 `LockedPublicCard` 좌표 제거 |
| `ArtReferences/RuntimeBindingTools/audit_runtime_art_bindings_0_6_5.ps1` | 자물쇠 슬롯 렌더링이 복구되면 게이트 실패하도록 계약 추가 |

## 유지 계약

- 상단에는 공개된 첫 커뮤니티 카드와 상대 방향의 AI 덱만 노출한다.
- 두 번째 커뮤니티 카드는 쇼다운 공개 연출에서만 등장하며 할리갈리 테이블에 자물쇠 자리표시자를 만들지 않는다.
- 좌우 벨, 중앙 하단 플레이어 덱, 최대 2장 공유 더미, 왼쪽 하단 플레이어 획득 카드 UI는 유지한다.
- `UI_HALLI_LEFT_BELL`, `UI_HALLI_RIGHT_BELL`, `UI_HALLI_FLIP_ONE`, `UI_HALLI_COMMUNITY` 문자열은 현재 할리갈리 런타임 표시 코드에서 호출하지 않는다.
- `PrivateSelection_0_6_0`, 스테이지 보상, 포커 결과 및 사운드 이벤트 연결을 변경하지 않는다.

## 총괄 통합 확인

1. 본 커밋 이상을 기준으로 `PlayableDev.unity`를 재생성한다.
2. 할리갈리 오프닝과 본 단계 모두에서 상단 자물쇠가 없는지 확인한다.
3. 첫 커뮤니티 카드, AI 덱, 밧줄 타이머가 서로 겹치지 않는지 960×540에서 확인한다.
4. 전체 스모크와 `audit_runtime_art_bindings_0_6_5.ps1`를 통과한 뒤 빌드한다.
