- 공유 브랜치: `dev`
- 프로그래머가 직접 사용하는 파일은 `programer/CodexGame/Assets/Art/Prototype/` 아래가 기준이다.

## 단계별 카드 구분

### 할리갈리 단계

- 앞면: `Cards_0_06/halli_variants/card_halli_{suit}_{rank}_skull_{01..03}.png`
- 용도: 해골 수 판정과 좌우 벨 입력
- 공통 뒷면: `Cards_0_06/card_back.png`

### 포커 단계

- 앞면: `Cards_0_06/poker_variants/card_poker_{suit}_{rank}.png`
- 2–10: 일반 포커 핍만 표시
- A/J/Q/K: 해골 캐릭터·로열 디자인 표시
- 공통 뒷면: `Cards_0_06/card_back.png`

두 단계의 앞면 폴더가 분리되어 있으므로 할리갈리 판정 카드와 포커 손패를 섞어 사용하지 않는다.

## 적용 주의사항

1. 배경 PNG 위에 카드, 벨, HUD를 별도 오브젝트로 배치한다.
2. 카드와 UI 텍스처는 Point 필터를 유지한다.
3. 할리갈리 카드 4장 출력 순서는 플레이어 왼쪽 → AI 왼쪽 → 플레이어 오른쪽 → AI 오른쪽이다.
4. 벨은 좌우 필드 아래 중앙에 배치하고 Q는 왼쪽, W는 카드 펼치기, E는 오른쪽 입력에 연결한다.
5. 포커 와이드 화면에서는 할리갈리 벨과 펼치기 더미를 제거하고 획득 카드를 손패 위치로 재배치한다.
