# 0.1.2.4 연출 UI 아트 인계

## 적용 목적

- 0.1.2.4의 입장, 단계 전환, 개인 카드 선택, 쇼다운, 결과 연출에 필요한 교체형 UI 아트입니다.
- 화면을 덮는 샘플 사각 프레임을 제거하고, 어두운 서부 살룬의 원형 테이블을 중심으로 얇은 황동 클립, 검은 철제 레일, 작은 리벳만 사용했습니다.
- 플레이어는 청록, AI는 탁한 적색, 선택·보상은 황동 금색, 잠금은 저채도 철색으로 구분합니다.
- 모든 런타임 PNG에는 문자를 넣지 않았습니다. 현재 언어별 문구는 Unity 텍스트로 표시하거나 숨길 수 있습니다.

## 파일 경로

- 런타임 PNG와 Unity 메타: `Assets/Art/Prototype/UI/Presentation_0_1_2_4/`
- Aseprite 원본과 프리뷰: `ArtReferences/Presentation_0_1_2_4/`
- 전체 파일명, 재사용 리소스, 타이밍: `ArtReferences/Presentation_0_1_2_4/presentation_art_catalog_0_1_2_4.json`

## 연결 기준

1. 기존 임시 도형이나 굵은 사각 테두리를 동일 의미의 PNG로 교체합니다.
2. 카드 본체와 살룬 배경은 유지하고, 카드 상태는 `private_card_candidate_*`의 투명 코너 클립으로 표시합니다.
3. 쇼다운은 전체 화면 박스를 추가하지 않고 `showdown_wide_frame`의 상·하단 레일만 사용합니다.
4. 결과와 보상은 `result_*`, `wrong_reward_*`의 철제 패널을 사용하며 게임 화면 전체를 가리지 않습니다.
5. 스프라이트 임포트는 `Sprite`, `Point`, `Uncompressed`, `Mip Maps Off`, `Pixels Per Unit 1` 기준입니다.

## 연출 타이밍

- 스테이지 입장: 6초, 스킵 가능
- Three Call 입장: 5초, 스킵 불가
