## 문제 → Codex 활용 → 사람이 결정한 내용 → 결과

- 문제: 신규 아이템 4종은 기획·아트가 확정됐지만 런타임 ItemId, 상점, 효과, 시간 초과 예외와 UI 연결이 없었다.
- Codex 활용: 기존 카드·포커·보상·상점 모듈을 유지한 채 효과별 상태를 분리하고, 결정적 카드 교환과 회귀 테스트를 추가했다.
- 사람이 결정한 내용: 가격 `3/4/3/4`, 상점 8종 동일 가중치, 무료 리롤 1회, 보험 충전 2회, 보상 합산 최대 5회, 패 확정 시간 초과는 술통·보험 제외.
- 결과: 도메인 규칙, 런타임 UI, 0.5.2 아트 훅, ko/en 문자열과 QA 치트를 같은 데이터 경계로 연결했다.

## 추가 반영 범위

- 와일드 잉크: 원본 CardId·랭크를 유지하는 `EffectiveSuit`, 조커·같은 문양 거부, 적용 뒤 카드 교환 그룹 잠금
- 술통: 정상 포커 패배의 플레이어 HP 피해만 `1→0`, 승자·예측 결과 유지, 패 확정 시간 초과 제외
- 예측 보험: 실제 성공·보험 성공·남은 충전 분리, 실패·2분 무응답만 충전 소비, 보상 계산 합계 5 상한, 스테이지 전환 초기화
- 용병단: 양측 우세 문양 계산, AI 대상 자동 선택, 서로 다른 미획득 카드 2장 결정적 동시 교환, 조커·AI 정보 비공개
- 상점: 총 8종 중 보유 ID와 최대 HP 회복약 제외, 최대 4종 비복원 추첨, 후보 부족 빈 슬롯, 무료 리롤 1회
- 패 확정: 두 번째 공용 카드 공개 뒤 2분 타이머 시작, 아이템 연출 중 계속 진행, 초과 시 자동 패배·HP 1 피해·예측 생략
- UI·아트: `ItemExpansion_0_5_2`의 기본/hover/selected/disabled, 팝업, 잉크·술통·보험·용병단 연출과 결과 마커 연결
- 현지화: 기존 설명과 신규 이름·설명·상태를 포함한 ko/en 197 Key 검증
- 치트: 백쿼트 패널에서 기존·신규 8종을 모두 지급할 수 있도록 4×2 배치
