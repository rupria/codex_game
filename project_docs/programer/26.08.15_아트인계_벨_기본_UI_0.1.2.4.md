# 벨 기본 UI·스테이지 상대 소개 패널 아트 인계 — 0.1.2.4

## 1. 결과

기존 흰색 종 아이콘과 임시 선형 패널을 게임의 서부 살룬 기조에 맞는 픽셀 아트로 교체했습니다.

- 실제 물성으로 읽히는 황동 살룬 벨
- `idle / hover / pressed / wrong / correct / disabled` 6상태
- 상단 3회 대결 단계용 황동 벨 인장
- 가죽·목재·황동 소재의 상대 소개 프레임
- 문자열이 들어 있지 않은 투명 PNG
- Aseprite 원본·재생성 스크립트·카탈로그·실화면 미리보기 포함

이번 변경은 아트 파일만 포함합니다. C#, 프리팹, 씬, 카드 생성·정렬·판정 로직은 수정하지 않았습니다.

## 2. 할리갈리 벨 파일

현재 런타임이 읽는 기존 경로와 `.meta` GUID를 유지했습니다. 아래 6개 파일은 한 세트로 교체합니다.

| 상태 | 파일 |
|---|---|
| 기본 | `Assets/Art/Prototype/UI/bell_idle.png` |
| 마우스 오버 | `Assets/Art/Prototype/UI/bell_hover.png` |
| 누름 | `Assets/Art/Prototype/UI/bell_pressed.png` |
| 오답 | `Assets/Art/Prototype/UI/bell_wrong.png` |
| 정답 | `Assets/Art/Prototype/UI/Halli_0_1_0/bell_correct.png` |
| 비활성 | `Assets/Art/Prototype/UI/Halli_0_1_0/bell_disabled.png` |

표현 규칙:

- `idle`: 낡은 황동 돔, 검은 철제 받침, 억제된 테이블 조명 반사
- `hover`: 밝아진 황동, 금색 외곽선, 상단 반짝임
- `pressed`: 몸체가 눌리고 손잡이가 내려간 형태
- `wrong`: 붉게 달아오른 구리색, 금이 간 충격 표시
- `correct`: 밝은 금빛, 청록 확인 외곽선, 흰색 반짝임
- `disabled`: 저채도 철색, 낮은 불투명도, 체인 띠

## 3. 벨 화면 규격

- 원본 PNG: `128×128 px`, RGBA
- 실제 표시 영역: `64×64 px`
- 기존 클릭 영역: `88×88 px` 유지
- 왼쪽 표시: `x390 y286 w64 h64`
- 오른쪽 표시: `x506 y286 w64 h64`
- 왼쪽 방향 레일: 청록 `#37DBD2`
- 오른쪽 방향 레일: 적색 `#E63F37`

벨 본체 전체를 청록·적색으로 칠하지 않습니다. 물체는 같은 황동 벨을 쓰고 위치와 방향 레일로 좌우 소속을 구분합니다.

Unity 임포트:

- Texture Type: `Sprite (2D and UI)`
- Filter Mode: `Point`
- Compression: `None / Uncompressed`
- Generate Mip Maps: `Off`
- Alpha Is Transparency: `On`
- Preserve Aspect: `On`

## 5. 상대 소개 프레임

파일:

`Assets/Art/Prototype/UI/Presentation_0_1_2_4/stage_entry_opponent_intro_frame_360x152_0_1_2_4.png`

기존 연결 좌표를 유지하면서 외형만 바꿨습니다.

- 프레임: `360×152 px`
- 화면 배치: `x300 y184 w360 h152`
- 초상화 슬롯: 프레임 내부 `x20 y22 w108 h108`
- 실제 초상화 화면 좌표: `x320 y206 w108 h108`
- 이름 안전 영역: `x148 y22 w194 h30`
- 설명 안전 영역: `x154 y59 w182 h47`
- 단계 표시 중심: `(164,120)`, `(192,120)`, `(220,120)`

이름·설명은 PNG에 굽지 않습니다. Unity에서 현지화 텍스트로 올립니다. 초상화는 기존 108×108 컷아웃을 그대로 사용합니다.

## 6. 인게임 텍스트 최소화

일반 할리갈리 전투 화면에서는 다음 문구를 제거합니다.

- `Q 왼쪽`
- `E 오른쪽`
- `W 1장 펼치기`
- `커뮤니티`

입력 이름은 가이드·접근성 레이블·개발 로그에만 남길 수 있습니다. 벨 PNG와 단계 인장에는 문자열이 없습니다.
