# 26.08.10 아트 인계 — 게임진행플로우 0.1.2

## 목적

`게임진행플로우_0.1.2`에서 프로그래머 연결을 기다리는 상점·할리갈리·포커 아트를 Unity 임포트 가능한 상태로 전달한다. 게임 규칙 코드는 이 작업에서 변경하지 않았다.

- 프로그래머 작업 이슈: [#37](https://github.com/rupria/codex_game/issues/37)

## 연결 시작점

- 한 페이지 미리보기: `programer/CodexGame/ArtReferences/Gameplay_0_1_2/PROGRAMMER_README.md`
- 전체 카탈로그: `programer/CodexGame/ArtReferences/Gameplay_0_1_2/gameplay_art_catalog_0_1_2.json`
- 상세 인계: `programer/CodexGame/ArtReferences/Gameplay_0_1_2/gameplay_art_programmer_handoff_0_1_2.md`
- 공용 런타임: `programer/CodexGame/Assets/Art/Prototype/UI/Gameplay_0_1_2/`
- 할리갈리 런타임: `programer/CodexGame/Assets/Art/Prototype/UI/Halli_0_3_5/`
- 포커 런타임: `programer/CodexGame/Assets/Art/Prototype/UI/Poker_0_3_5/`

## 우선 연결 순서

1. 상점 상품을 최대 4칸으로 연결하고 주머니를 `(776,384)`에 독립 배치한다.
2. IT-01·IT-02·IT-03·HP-01 ItemId를 새 아이콘 4종에 매핑한다.
3. 할리갈리 네 필드 더미에 최근 3장 이력 표시를 연결한다. 최신 카드만 판정에 사용한다.
4. 포커 AI 아이템 슬롯을 제거한다.
5. 플레이어 목재 상자를 4칸 인벤토리의 접힘/열림 상태에 연결한다.
6. 예측 성공 0~5와 기본·추가·최종 총알 결과를 내부 데이터에 연결한다.

## 회귀 주의

- 기존 카드 이미지와 카드 목록 데이터를 하드코딩하지 않는다.
- 할리갈리 이전 카드 이력은 표시용이며 판정 카드를 추가하지 않는다.
- AI는 0.1.2에서 아이템을 사용하지 않는다.
- TMP 문자열과 PNG 장식 버튼을 중복 생성하지 않는다.
- `pub`에는 QA 확인 전 반영하지 않는다.
