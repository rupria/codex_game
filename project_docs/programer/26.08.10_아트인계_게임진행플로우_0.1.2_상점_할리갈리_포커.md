# 26.08.10 아트 인계 — 게임진행플로우 0.1.2

## 목적

상점·할리갈리·포커 아트를 프로그래머가 즉시 연결할 수 있게 런타임 PNG, Aseprite 원본, 상태 시안, 좌표와 조명값을 한 묶음으로 전달한다. 게임 규칙 코드는 변경하지 않았다.

- 연결 이슈: [#37](https://github.com/rupria/codex_game/issues/37)
- 상세 안내: `programer/CodexGame/ArtReferences/Gameplay_0_1_2/PROGRAMMER_README.md`
- 기계 판독 카탈로그: `programer/CodexGame/ArtReferences/Gameplay_0_1_2/gameplay_art_catalog_0_1_2.json`

## 이번 확정 변경

1. 상점 상품 4개를 Y `146`으로 내려 상단 UI와 간격을 확보했다.
2. 우측 하단 총알 주머니의 사각 배경 프레임을 제거했다.
   총알은 빈 주머니 위에 현재 `BulletCount`만큼 별도 생성하며, 구매 중 손이 가린 사이 수량을 갱신한다.
3. 할리갈리 화면을 좌우 공유 더미 2개, 더미당 최대 2장 구조로 바로잡았다.
4. 포커 본 화면의 총알 개수/총알 미터를 제거했다.
5. 포커 아이템 상자를 닫힘, 빈 상자 팝업, 아이템 보유 팝업의 3상태로 나눴다.
6. 테이블 키 라이트를 기존 대비 20% 올리고 살룬 전체를 보여 주는 보조광 기준을 추가했다.

## 프로그래머 적용 순서

1. Unity 아트 참조를 위 런타임 PNG로 교체한다.
2. 포커 상자 클릭 시 보유 수에 따라 empty/filled 팝업을 분기한다.
3. 팝업이 열린 동안 뒤쪽 입력을 차단한다.
4. `lighting_profile_0_3_6.json`의 상대 광량으로 프레젠테이션 리그를 조정한다.
5. 할리갈리 좌우 공유 더미가 화면별로 2장씩 읽히는지 확인한다.
6. 아이템 선택·대상 선택 상태가 데이터에 따라 전환되는지 확인한다.
7. 3개 해상도에서 카드, 상자, 버튼, 주머니가 겹치지 않는지 확인한다.
