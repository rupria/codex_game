## 2. 실행 구조

```text
사용자 공개 HTTPS 링크
  → Cloudflare Pages의 Unity WebGL
  → 같은 도메인의 /api
  → Cloudflare Pages Functions
  → TiDB Cloud Starter
```

- 사용자 로그인 화면은 없다.
- 첫 접속 시 서버가 서명된 익명 쿠키를 자동 발급한다.
- Unity WebGL은 TiDB에 직접 접속하지 않는다.
- DB 비밀번호와 쿠키 서명 비밀 값은 Cloudflare Secret에만 둔다.
- DB 또는 API 장애가 코어 플레이를 막지 않는다.

## 3. 0.05 판정과 DB의 경계

다음 판정은 Unity 로컬 상태 머신이 즉시 처리한다.

- 30초 카드 펼치기 제한
- 33.3ms 동시 벨
- AI 최대 1.5초 반응과 30% 놓침
- AI 60%·40% 선택
- 카드 시드, 덱과 난수 소비 순서
- 할리갈리 결과, 포커 승패, HP와 예측 보상

TiDB에는 라운드 또는 전투 종료 후 결과 요약만 비동기로 전송한다. 저장 실패 시 게임은 계속하고 경기 결과를 브라우저 로컬 큐에 최대 20건 보관한다.

## 4. 현재 구현과 0.05 추가 요구

현재 로컬 구현:

- `/api/session`: 로그인 없는 익명 서명 쿠키
- `/api/matches`: 경기 결과 저장
- `/api/save`: JSON 세이브 저장·복원
- `/api/health`: TiDB 상태 확인
- `001_initial.sql`: `guest_saves`, `match_results`
- Unity `AnonymousGameApi`: 비차단 전송과 로컬 재시도 큐

0.05 분석·재현을 위해 추가로 검토할 필드:

| 분류 | 권장 필드 | 현재 상태 |
|---|---|---|
| 명세 | `spec_revision`, `content_version` | 콘텐츠 버전만 구현 |
| 진행 | `stage_number`, `combat_round_number` | 스테이지만 구현 |
| 재현 | `round_seed`, `deck_sequence_version` | 미구현 |
| 벨 | 양측 입력 ms, 동시 입력, AI 놓침 | 단일 입력 ms만 구현 |
| 할리갈리 | 승자, 양측 패배, 획득 더미, 종료 사유 | 미구현 |
| 포커·예측 | 포커 승자, 예측 성공, 보상 종류 | 최종 결과만 구현 |
| 누적 진행 | HP, 코인 증가, 보상 후보 | 세이브 JSON 사용 가능 |

기존 `001_initial.sql`을 임의 수정하지 않는다. 상세 필드는 API 계약 확정 후 `002` 마이그레이션으로 추가한다.
