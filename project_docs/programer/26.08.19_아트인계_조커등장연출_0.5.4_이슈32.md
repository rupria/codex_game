# 이슈 #32 조커 등장 연출 아트 인계 — JokerReveal 0.5.4

## 목적

플레이어가 조커를 처음 확인할 수 있는 개인 카드 후보 선택 화면에서, 조커 후보 셀을 서부극 카드 게임의 결투 연출로 공개한다. 카드 판정·소유권·포커 규칙은 변경하지 않는다.

> 2026-08-19 연결 정정: 기존 문서가 `PokerDevPanel.DrawPlayerJokerPresentation()`을 주 연결 대상으로 적었으나, 그 단계보다 앞선 `PrivateSelection`에서 조커가 이미 노출된다. 플레이어 전체 등장 연출의 주 연결 대상은 `PrivateSelectionDevPanel`과 `PrivateSelection 0.5.5` 후보 셀이다.

## 연결 타임라인

1. `0.00–0.15s`: `PrivateSelection` 진입 직후 전체 비네트로 배경을 감광하고, 조커 후보는 같은 셀의 카드 뒷면으로 시작한다.
2. `0.15–0.35s`: 해당 후보 셀 안에서 카드 뒷면을 앞면으로 뒤집고 arc trail을 재생한다.
3. `0.35–0.85s`: 앞면을 읽을 수 있게 유지. 표적 링과 총구 섬광은 시작부에 짧게, 카드 glint는 이 구간에 1회만 재생.
4. `0.85–1.00s`: 같은 후보 카드 좌표에 안착하고 `PrivateSelection 0.5.5`의 정상 후보 상태로 전환한다.

## 프로그래머 연결 작업

- `JokerRevealUiArtSet`을 만들거나 동등한 직렬화 필드를 추가하고 `PlayableDevSceneBuilder`에서 `JokerReveal_0_5_4` 6종 PNG를 실제로 로드한다. 현재 `dev`에는 이 바인딩이 없다.
- `PrivateSelectionDevPanel` 진입 시 `snapshot.WinnerCandidates`에 조커가 있고 해당 선택 세션에서 아직 공개하지 않았을 때만 1.00초 전체 연출을 재생한다.
- 조커 후보의 실제 카드 좌표를 연출 목표로 사용한다. `card_glint` 112×156은 후보 카드 84×117과 같은 비율이므로 `ScaleToFit`으로 합성한다.
- `0.85s`까지 선택·확정 입력을 막고, `JokerRevealSettled` 뒤에만 `PrivateSelection 0.5.5` 후보 입력을 연다.
- `PokerDevPanel.DrawPlayerJokerPresentation()`의 흰색 사각 강조와 늦은 중복 공개는 제거한다. 해당 상태가 규칙 전환에 필요하다면 시각 연출 없이 즉시 통과시키거나 세션 상태만 유지한다.
- 화면 리드로우, 포커스 이동, 언어 변경, 해상도 변경으로 연출이 재생되지 않도록 스테이지·라운드·선택 세션 단위 공개 완료 플래그를 유지한다.
- 조커 미획득 경로는 감광·입력 잠금·추가 대기 없이 즉시 정상 선택 화면을 연다.
- AI는 쇼다운에서 최종 패에 실제 사용된 경우에만 최대 0.50초 축약 연출을 재생한다. 쇼다운 전에는 마커·지연·광량·음향으로도 보유 사실을 노출하지 않는다.
- 스킵 입력, 카드 평가, 카드 배열 순서, 후보 선택 상태는 변경하지 않는다.

## 검수 조건

- 조커가 있는 플레이어 후보 화면에 처음 진입하면 후보 셀의 카드 뒷면에서 전체 연출이 1회 재생된다.
- 조커가 없는 후보 화면에는 감광·추가 대기·빈 연출이 발생하지 않는다.
- 흰색 사각 임시 강조와 뒤늦은 포커 단계 중복 공개가 남아 있지 않는다.
- 카드 숫자·문양·JOKER 표기는 최소 0.50초 읽을 수 있다.
- 연출 종료 좌표와 실제 선택 가능한 조커 후보 카드 좌표가 일치한다.
- `JokerRevealSettled` 전에는 후보 토글·확정 입력이 동작하지 않고, 이후에는 정상 동작한다.
- 포커스·언어·해상도 변경 후에도 같은 선택 세션에서 연출이 재생되지 않는다.
- 조커 미획득 경로에는 추가 지연이 없다.
- AI 조커 정보가 쇼다운 전에 노출되지 않는다.

## 후속 선택 팝업

조커 카드가 실제 후보 슬롯에 안착한 뒤 표시되는 선택 모달은 `PrivateSelection 0.5.5`로 보완했다. 좌표·상태·연결 방법은 `project_docs/programer/26.08.19_아트인계_조커_패선택팝업_0.5.5_이슈32.md`를 따른다.
