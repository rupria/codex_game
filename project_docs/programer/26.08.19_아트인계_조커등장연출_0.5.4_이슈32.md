## 연결 타임라인

1. `0.00–0.15s`: 비네트로 배경 감광, 조커 카드에 포커스.
2. `0.15–0.35s`: 카드 이동·뒤집기, arc trail 재생.
3. `0.35–0.85s`: 앞면을 읽을 수 있게 유지. 표적 링과 총구 섬광은 시작부에 짧게, 카드 glint는 이 구간에 1회만 재생.
4. `0.85–1.00s`: 실제 획득 슬롯으로 이동·안착, settle glint 재생.

## 프로그래머 연결 작업

- `PokerDevPanel.DrawPlayerJokerPresentation()`의 흰색 사각 강조를 제거하고 `JokerReveal_0_5_4` 자산 세트를 바인딩한다.
- 기존 `CardFlipMotion`과 실제 획득 슬롯 좌표를 유지하고, 위 이펙트는 그 위에 표현 레이어로만 합성한다.
- 플레이어 조커 실제 획득 때만 1.00초 전체 연출을 재생한다.
- AI는 쇼다운에서 최종 패에 실제 사용된 경우에만 최대 0.50초 축약 연출을 재생한다. 쇼다운 전에는 마커·지연·광량·음향으로도 보유 사실을 노출하지 않는다.
- 스킵 입력, 카드 평가, 카드 배열 순서, 후보 선택 상태는 변경하지 않는다.

## 검수 조건

- 흰색 사각 임시 강조가 남아 있지 않는다.
- 카드 숫자·문양·JOKER 표기는 최소 0.50초 읽을 수 있다.
- 연출 종료 좌표와 실제 선택 가능한 획득 카드 좌표가 일치한다.
- 조커 미획득 경로에는 추가 지연이 없다.
- AI 조커 정보가 쇼다운 전에 노출되지 않는다.

## 후속 선택 팝업

조커 카드가 실제 후보 슬롯에 안착한 뒤 표시되는 선택 모달은 `PrivateSelection 0.5.5`로 보완했다. 좌표·상태·연결 방법은 `project_docs/programer/26.08.19_아트인계_조커_패선택팝업_0.5.5_이슈32.md`를 따른다.
