# 프로젝트 공유 문서 스냅샷

이 폴더는 Google Drive·Obsidian의 기준 문서를 Git에서 역할 간 공유하고 버전을 고정하기 위한 스냅샷입니다.

- 기준 원본: `G:\내 드라이브\codex_game\obsidian`
- Git 대상 브랜치: `dev`
- 동기화 순서: 기획 → 프로그래밍 → QA·PM → 규칙·조율
- 운영 원칙: 이 폴더의 복사본을 독립적으로 편집하지 않고, Drive 기준 원본을 수정한 뒤 다시 동기화합니다.
- `pub`는 빌드 통합 및 별도 승인 전에는 커밋하지 않습니다.

최종 동기화 대상과 원본 SHA-256은 `SYNC_MANIFEST.json`에서 확인합니다.
