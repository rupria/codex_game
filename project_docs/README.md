# 프로젝트 공유 문서

이 폴더에는 `dev`와 함께 공유해야 하는 현재 명세, 결정, 실행 기준과 공모전 근거만 둔다. 완료된 역할별 작업보고는 Git 이력과 단일 협업 근거 문서로 통합하고 활성 문서에서는 제거한다.

- 제품 버전: `0.1.2`
- 기준 브랜치: `dev`
- 기준 명세: [게임진행플로우 0.1.0](designer/게임진행플로우_0.1.0.md)
- 프로젝트 현황: [OpenAI Game Builders Seoul](coordination/10_Projects/OpenAI_Game_Builders_Seoul.md)
- Codex 협업 근거: [문제 → Codex 활용 → 사람의 결정 → 결과](coordination/10_Projects/Codex_협업_근거_2026-08-10.md)

- 공통 규칙: [rules/README.md](rules/README.md)

## 보존 원칙

- 기획 명세의 이전 버전과 원본 PDF·XMind는 사람의 결정 변화 근거이므로 보존한다.
- 코드, 테스트, 최종 런타임 아트, 재생성 가능한 원본과 자산 카탈로그를 보존한다.
- 완료된 PM·프로그래밍·아트·QA 작업보고와 중복 인계 문서는 활성 트리에서 제거한다.
- QA는 별도 역할 보고를 만들지 않고 자동 테스트·빌드 스모크 결과를 해당 변경 커밋에 기록한다.
- Google Drive·Obsidian의 규칙·내부 메모 원본은 `G:\내 드라이브\codex_game\obsidian`에서 관리한다.
- `pub`는 사용자 승인 없이 변경하지 않는다.
