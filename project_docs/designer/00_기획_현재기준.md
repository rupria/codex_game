## 현재 게임 정의

- 한 문장: 플레이어와 AI가 카드 더미에서 동일 문양의 해골 합계 3 또는 해골 3 카드를 찾아 벨 경쟁을 하고, 획득한 개인 카드와 공용 카드로 포커 승부를 예측하는 1대1 게임이다.
- 목표 경험: 첫 30초 안에 카드 펼치기와 벨 입력을 이해하고, 3분 안에 관찰·반응·카드 선택·예측의 재미를 경험한다.
- 전투 종료: 어느 한쪽의 HP가 0이 되면 스테이지가 끝난다.
- 필수 제출 형태: 설치 없이 실행되는 브라우저 웹 빌드와 승인 없는 공개 플레이 링크.

## 현재 코어 루프

`첫 공용 카드 공개 → 할리갈리 단계 → 개인 카드 배분 → 포커 단계 진입 → 두 번째 공용 카드 공개 → 아이템·패 확정 → 승패 예측 → 포커 비교 → 피해·보상 → 새 시드로 반복 또는 스테이지 종료`

- 모든 전투 라운드에서 할리갈리 단계를 진행한다.
- 할리갈리 승리 목표는 1번째 전투 라운드 3승, 2번째 2승, 3번째 이후 1승이다.
- 전투 라운드마다 새 시드와 52장 덱을 생성한다.
- 승자의 무작위 보충을 먼저 완료한 뒤 패자에게 무작위 카드 3장을 배분한다.
- 승자가 없으면 플레이어부터 양측에 1장씩 번갈아 배분한다.
- 양측 개인 카드 3장을 확정한 뒤 두 번째 공용 카드를 공개한다.

## 0.06 변경 범위

- 동일 문양의 해골 `1 + 2`, `2 + 1`만 합계 3의 유효한 벨 조건으로 판정한다.
- 서로 다른 문양의 `1 + 2`, `2 + 1`은 합이 3이어도 유효하지 않다.
- 해골 3 카드는 0.05 예외를 그대로 유지하며 다른 카드의 문양 또는 전체 합계와 관계없이 해골 3 카드 한 장만 획득한다.
- 카드 문양은 포커와 할리갈리에서 같은 `♠`, `♣`, `♥`, `♦` 데이터를 사용한다.
- 0.06의 게임 규칙 변경은 위 카드 합산 판정으로 한정하며 시간·AI 난이도 수치·카드 배분·포커·HP·스테이지 규칙은 바꾸지 않는다.

## 1스테이지 AI 기준

- 유효한 벨 기회에 반응하면 최대 1.5초 안에 입력한다.
- 올바른 벨 기회를 놓칠 확률은 30%다.
- 유효 입력 차이가 33.3ms 이하이면 플레이어를 우선한다.
- AI는 포커 판정상 최선의 유효 선택지를 60% 확률로 선택하고, 40% 확률로 유효 선택지 중 하나를 무작위 선택한다.
- 랭크 우선순위는 `A > K > Q > J > 10~2`, 문양 우선순위는 `♠ > ♦ > ♥ > ♣`다.
