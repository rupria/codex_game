## 현재 게임 정의

- 한 문장: 플레이어와 AI가 카드 더미에서 동일 문양의 해골 합계 3 또는 해골 3 카드를 찾아 벨 경쟁을 하고, 획득한 개인 카드와 공용 카드로 포커 승부를 예측하는 1대1 게임이다.
- 목표 경험: 첫 30초 안에 카드 펼치기와 벨 입력을 이해하고, 3분 안에 관찰·반응·카드 선택·예측의 재미를 경험한다.
- 전투 종료: 어느 한쪽의 HP가 0이 되면 스테이지가 끝난다.
- 필수 제출 형태: 설치 없이 실행되는 브라우저 웹 빌드와 승인 없는 공개 플레이 링크.

## 현재 코어 루프

`살룬 입장·중앙 원형 테이블 착석 → 첫 공용 카드 공개 → 할리갈리 단계 → 획득 후보 4장 이상 참가자의 조커 10% 판정 → 포커 단계 진입 → 두 번째 공용 카드 공개 → 개인 카드 3장 선택·배분 → 아이템 → 조커 족보 선택·패 확정 → 승패 예측 → 포커 비교 → 피해 → 새 시드로 반복 또는 AI HP 0 시 재화 정산 → 현재 가게의 바 → 다음 가게 이동·입장`

- AI HP가 0이 되면 스테이지 클리어 기본 재화와 예측 성공 일회성 재화를 분리 정산한다.
- 바에서 총알로 아이템·체력 회복을 이용한 뒤 다음 가게로 이동한다.
- 최초 시작과 다음 스테이지 모두 살룬 스윙도어를 열고 실내 중앙 원형 테이블에 앉은 뒤 전투를 시작한다.

- 모든 전투 라운드에서 할리갈리 단계를 진행한다.
- 할리갈리 승리 목표는 1번째 전투 라운드 3승, 2번째 2승, 3번째 이후 2승이다.
- 전투 라운드마다 새 시드와 52장 덱을 생성한다.
- 승자의 무작위 보충을 먼저 완료한 뒤 패자에게 무작위 카드 3장을 배분한다.
- 승자가 없으면 플레이어부터 양측에 1장씩 번갈아 배분한다.
- 획득 후보가 4장 이상인 참가자는 포커 라운드당 한 번, 독립된 10% 확률로 조커 출현을 판정한다.
- 조커 판정 후 두 번째 공용 카드를 먼저 공개하고, 공개된 공용 카드 2장을 확인한 뒤 개인 카드 3장을 선택·배분한다.
- 조커는 개인 카드 3장 중 한 장으로 선택하며 아이템 처리 후 실제로 완성 가능한 족보를 확정한다.
- AI의 조커 출현·선택·변환 결과는 AI 패 공개 전까지 숨긴다.

## 0.1.0 변경 범위

> 아래 항목 중 입력 잠금·공개 중 벨·카드 부족·보상 규칙은 최신 결정 문서 D-005~D-009, D-015~D-017이 우선한다.

- 최초 실행 화면의 조작 버튼은 `START`와 `GUIDE`만 표시한다.
- 딜러가 첫 공용 카드를 펼친 뒤 할리갈리 클로즈업 구도로 전환한다.
- 플레이어 청록색·AI 붉은색의 대결 구도를 사용하고 벨 2개를 테이블 중앙에 나란히 배치한다.
- 플레이어 덱은 화면 하단 중앙, AI 덱은 화면 상단 중앙에 배치한다. 플레이어 카드는 아래에서 위로, AI 카드는 위에서 아래로 판정 슬롯에 제출해 서로 마주보고 카드를 내는 인상을 전달한다.
- 기본 조작 표기는 `Q = 왼쪽 벨`, `W = 카드 펼치기`, `E = 오른쪽 벨`이다.
- 플레이어 획득 후보는 앞면 트레이, AI 획득은 일시 공개 후 뒷면과 장수로 표시한다.
- `W` 또는 마우스 펼치기 입력 1회에 플레이어 카드 1장과 그에 응수하는 AI 카드 1장을 순차 공개한 뒤 다음 플레이어 입력을 기다린다.
- 첫 입력은 `플레이어 왼쪽 → AI 왼쪽`, 다음 입력은 `플레이어 오른쪽 → AI 오른쪽` 순서로 진행해 4장 배분을 완성한다.
- 카드 1장 이동은 `0.18~0.22초`, 카드 사이 간격은 `0.06~0.10초`, 4장 전체는 `0.9~1.2초`다.
- 4장 배분 중에는 `W/Q/E` 입력을 잠그고 AI 반응 시간은 네 번째 카드 공개 완료부터 계산한다.
- 카드 펼치기 제한은 최대 12회 4장 배분 또는 카드 4장 미만으로 변경한다.
- 할리갈리 종료 시 테이블을 줌아웃하고 획득 카드를 재배치해 포커 단계로 진입한다.
- 0.08의 AI 반응·잠금·오답 UI·`3→2→2`·예측 시간과 포커 규칙은 그대로 계승한다.

## 0.08 계승 규칙과 0.1.0 예외

- 0.08의 카드 판정, AI 확률, 승수, 보상, 개인 카드 배분과 포커 규칙을 계승한다.
- 카드 펼치기 단위·순서·간격, AI 반응 시작 시점과 최대 횟수는 0.1.0 규칙으로 대체한다.
- AI 반응 시간은 네 번째 카드 공개 완료부터 1~3초, 일반값 2초로 계산한다.
- AI 벨 결과 확률은 정답 60%, 오답 20%, 놓침 20%다.
- 정답 조건 대기와 정답 카드 획득 후 다음 펼치기를 각각 1초 잠근다.
- 오답 보상 UI는 포커 카드 앞면 스크롤 목록을 사용하고 선택 전·결과 후 각각 2초 잠근다.
- 카드 펼치기 30초 무입력은 플레이어 패배, AI 승수 +1과 보상 카드 선택으로 처리한다.
- 직전 할리갈리 라운드 승자가 다음 4장 배분을 플레이어 입력 대기 또는 AI 자동 진행으로 시작한다.
- 할리갈리 승리 목표와 승자 직접 선택 수를 `3→2→2`로 변경한다.
- 승패 예측 제한 시간은 2분이며 실패와 무반응은 성공 횟수를 올리지 않고 기존 누적을 유지한다.
- 포커 계산 완료 후 1초 안에 결과를 발표한다.

## 0.1.2.2 확정 범위

- 스테이지 클리어 보상은 기본 재화, 예측 성공 보상은 일회성 재화로 분리한다.
- 기본 재화와 보유 아이템은 현재 런 동안 이월한다. 일회성 재화는 직후 상점에서 우선 사용하고 상점 이탈 시 소멸한다.
- 1차 아이템은 재장전 1, 밑장빼기 2, 바람잡이 2 가격으로 확정한다.
- 체력 회복 아이템 가격은 총알 1개다.
- 인벤토리와 상점은 각각 최대 4칸이며 동일 ItemId는 1개만 보유한다.
- 구매 횟수와 포커 라운드당 기본 아이템 사용 횟수는 제한하지 않는다.
- 버린 카드는 같은 아이템 추첨에 다시 등장할 수 있다.
- 상점은 스테이지 승리 후 확정 등장하고 `상점 이탈` 전까지 유지한다.
- 초기 콘텐츠 범위는 3스테이지다.
- 패배 보상은 없으며 현재 런 진행을 초기화하고 1스테이지부터 재도전한다.
- AI 반응시간은 2스테이지 5%, 3스테이지 10% 단축한다.
- 유리한 카드 선택 확률은 60% → 63% → 66%로 증가하며 AI HP는 전 스테이지 3이다.
- 상점 이탈 후 전환 연출 동안 입력을 잠그고 연출 재생 완료 시 다음 스테이지에 진입한다.
- 개발·QA 치트의 상세 기준은 GitHub Issue #35와 [[게임진행플로우_0.1.2.2_작업요청]]을 따른다.

## 0.1.2.3 확정 범위

- 최종 획득 카드 후보가 4장 이상인 참가자만 포커 라운드당 정확히 한 번 10% 조커 판정을 수행한다.
- 조커는 52장 덱에 섞지 않고 출현 시 개인 카드 후보 풀에 1장만 추가한다.
- 처리 순서는 `조커 판정 → 두 번째 공용 카드 공개 → 개인 카드 3장 선택·배분 → 아이템 → 조커 족보 선택 → 패 확정`이다.
- 조커는 실제 카드 한 장 대체로 완성 가능한 족보에만 사용할 수 있고 포커 라운드 종료 후 소멸한다.
- 플레이어와 AI에 같은 규칙을 적용하며 AI 조커 정보는 정상 패 공개 전까지 비공개다.
- 상세 구현·QA 기준은 [[게임진행플로우_0.1.2.3_작업요청]]을 따른다.
## 스테이지별 AI 기준

- 유효한 벨 기회에서 정답 60%, 오답 20%, 놓침 20%를 적용한다.
- 1스테이지 반응 시간은 네 번째 카드 공개 완료부터 최소 1초, 일반값 2초, 최대 3초다.
- 2스테이지는 반응시간 5% 단축·유리한 카드 선택 63%, 3스테이지는 반응시간 10% 단축·유리한 카드 선택 66%다.
- AI HP는 모든 스테이지에서 3이다.
- 정답 조건 발생 후 다음 펼치기를 1초 잠그며, 잠금 후 다음 카드를 펼치면 이전 AI 입력을 취소한다.
- 유효 카드와 보상 카드 평가는 60% 최선·40% 무작위 정책을 별도로 적용한다.
- 랭크 우선순위는 `A > K > Q > J > 10~2`, 문양 우선순위는 `♠ > ♦ > ♥ > ♣`다.
