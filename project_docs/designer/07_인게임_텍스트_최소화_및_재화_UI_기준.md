# 인게임 텍스트 최소화 및 재화 UI 기준

- 작성일: 2026-08-10
- 기준 명세: [[게임진행플로우_0.1.2.2]]
- 대상 역할: 기획, 프로그래밍, UI·아트, QA
- 상태: 재화 종류·소비 순서·금지 문자열 확정, 지급 수량 밸런싱 중

## 1. 목적

플레이어가 특정 보드게임이나 카드게임 명칭을 먼저 떠올리지 않고 화면의 카드, 벨, 인물과 연출만으로 행동을 이해하게 한다. 인게임 상시 UI의 문장을 제거하고 아이콘, 숫자, 위치, 움직임과 색상으로 정보를 전달한다.

`총알`, `일회성 총알`, `할리갈리`, `포커`는 내부 기획·코드·QA 용어로만 사용한다. 일반 플레이 화면의 표시 문자열에는 사용하지 않는다.

## 2. 재화 구분

| 내부 명칭 | 획득처 | 유지 범위 | 인게임 표시 |
|---|---|---|---|
| 기본 재화 | 스테이지 클리어 | 현재 런 동안 유지 | 실선 테두리의 온전한 탄환 아이콘 + 숫자 |
| 일회성 재화 | 승리 예측 성공 | 획득 직후 상점까지만 유지 | 갈라진 탄환 또는 모래시계 표식이 결합된 탄환 아이콘 + 숫자 |

- 두 재화는 별도 수량으로 저장한다.
- 상점 구매 시 일회성 재화를 먼저 차감하고 부족한 가격만 기본 재화에서 차감한다.
- 상점 이탈 시 남은 일회성 재화는 0으로 만든다.
- 캐릭터 사망 시 기본 재화와 일회성 재화를 모두 0으로 만든다.
- 색상만으로 구분하지 않는다. 아이콘 외곽선, 균열·모래시계 표식과 고정 위치를 함께 사용한다.
- 지급량은 밸런싱 데이터로 관리하며 UI와 소비 로직에 하드코딩하지 않는다.

### 소비 계산

```text
일회성 사용량 = min(가격, 보유 일회성 재화)
기본 사용량 = 가격 - 일회성 사용량
```

예를 들어 가격 2, 기본 재화 3, 일회성 재화 1이면 일회성 1과 기본 1을 사용한 뒤 기본 2만 남는다.

## 3. 재화 UI

### 전투 화면

- 재화 명칭을 표시하지 않는다.
- 기본 재화는 화면의 고정 위치에 `온전한 탄환 아이콘 + 숫자`로 표시한다.
- 일회성 재화는 전투 중 예측 보상 진행을 확인해야 할 때만 보조 위치에 표시한다.
- 숫자가 0인 일회성 재화는 전투 화면에서 숨길 수 있다.

### 상점 화면

- 기본 재화와 일회성 재화를 항상 나란히 표시한다.
- 고정 순서는 `일회성 재화 → 기본 재화`로 두어 실제 소비 순서를 따른다.
- 상품 가격은 재화 명칭 없이 `탄환 아이콘 + 숫자`만 표시한다.
- 구매 시 일회성 아이콘의 숫자와 게이지가 먼저 감소하고, 부족분이 있을 때만 기본 아이콘이 감소한다.
- 남은 일회성 재화가 있는 상태에서 상점 이탈을 처음 입력하면 일회성 아이콘을 흔들거나 점멸하고 출구 아이콘에 경고 표식을 표시한다.
- 같은 상태에서 이탈을 다시 입력하면 일회성 재화를 소멸시키고 전환 연출로 진행한다.
- 경고는 문장 없이 아이콘과 애니메이션으로 전달한다.

## 4. 단계 명칭 비노출

### 카드·벨 구간

- `할리갈리`, `할리갈리 단계`, `라운드` 명칭을 화면에 표시하지 않는다.
- 현재 행동은 카드 더미 확대, 중앙 벨, `Q/W/E` 키캡과 입력 가능 애니메이션으로 전달한다.
- `카드 펼치기`, `왼쪽`, `오른쪽` 문구 대신 카드 아이콘, 좌우 벨 아이콘과 키캡을 사용한다.
- 승수는 문장 대신 플레이어·AI 영역의 점등 마커로 표시한다.

### 5장 승부 구간

- `포커`, `포커 단계`, `포커 라운드` 명칭을 화면에 표시하지 않는다.
- 카드 5장 배치, 양측 인물 프레임과 중앙 비교 연출로 단계 전환을 전달한다.
- 예측은 `승리`·`패배` 문구 대신 플레이어 초상과 AI 초상 중 예상 승자를 선택하게 한다.
- 결과는 승자 프레임 강조, 패자 HP 감소, 카드 조합 하이라이트로 전달한다.
- 표준 족보 명칭의 상시 노출은 사용하지 않는다. 필요한 경우 결과 상세 또는 가이드에서만 선택적으로 제공한다.

## 5. 화면별 허용 정보

| 화면 | 기본 노출 | 숨기는 문자열 |
|---|---|---|
| 메인 | 시작 아이콘, 가이드 `?` 아이콘 | 장르·규칙 명칭 |
| 카드·벨 | 카드, 벨, 키캡, 타이머 숫자, 승수 마커 | 할리갈리, 카드 펼치기, 좌·우 설명문 |
| 카드 선택 | 카드, 선택 개수, 타이머 숫자 | 장문의 선택 안내 |
| 5장 승부 | 카드 5장, 양측 초상, 아이템 아이콘 | 포커, 승리·패배 문장 |
| 상점 | 두 재화 아이콘과 숫자, 상품 아이콘·가격 | 총알, 일회성 총알, 가격 문구 |
| 결과 | 승자 강조, HP 변화, 획득 아이콘·숫자 | 포커 결과 설명문, 재화 명칭 |

## 6. 텍스트 사용 예외

- 아이템 이름과 효과는 키보드 포커스·마우스 오버·상세 보기에서만 표시할 수 있다.
- 최초 가이드와 접근성 설명은 최소 문장을 사용할 수 있지만 금지된 장르·재화 명칭은 사용하지 않는다.
- 스크린리더용 접근성 이름과 개발·QA 로그에는 내부 명칭을 사용할 수 있다. 화면에는 렌더링하지 않는다.
- 오류 복구, 브라우저 접근 실패와 제출 필수 실행 안내는 명확성을 위해 텍스트를 유지한다.

## 7. 문자열 관리

- 기존 문자열 테이블의 키는 삭제하지 않고 `displayPolicy`를 `hidden`, `icon_only`, `focus_only`, `always` 중 하나로 관리한다.
- 내부 상태명과 표시 문자열을 분리한다.
- 신규 상시 노출 문자열을 추가하려면 아이콘·숫자·연출만으로 전달할 수 없는 이유를 기획 검토에 남긴다.
- 금지 문자열 검색 대상은 Unity 씬·프리팹·ScriptableObject·JSON·CSV·문자열 테이블과 WebGL 화면이다.

## 8. QA 수용 기준

- [ ] 일반 플레이 화면에서 `총알`, `일회성 총알`, `할리갈리`, `포커` 문자열이 보이지 않는다.
- [ ] 기본 재화와 일회성 재화를 색각 정보 없이 아이콘 형태와 위치만으로 구분할 수 있다.
- [ ] 구매 시 일회성 재화가 항상 먼저 차감된다.
- [ ] 일회성 재화 부족분만 기본 재화에서 차감된다.
- [ ] 상점 이탈 시 남은 일회성 재화가 소멸한다.
- [ ] 일회성 재화가 남아 있으면 텍스트 없는 1차 이탈 경고가 작동한다.
- [ ] 카드·벨 구간과 5장 승부 구간을 단계 명칭 없이 화면 구도와 조작 상태로 구분할 수 있다.
- [ ] 예측 선택을 승리·패배 문구 없이 플레이어·AI 초상 선택으로 완료할 수 있다.
- [ ] 숨긴 문자열이 개발 로그와 접근성 이름까지 제거되지는 않는다.
