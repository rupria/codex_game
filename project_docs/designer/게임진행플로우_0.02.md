## 1. 문서 목적과 범위

플레이어와 AI가 카드를 좌우에 펼쳐 해골 합계 3을 먼저 찾고, 획득한 개인 카드 3장과 공용 카드 2장으로 포커 승부를 진행하는 전체 흐름을 정의한다.

본 문서는 2026-08-06까지 사용자와 합의한 진행 규칙을 반영한다. 별도로 수행한 CSV·ML 확률 검증의 수치, 카드 순서와 임시 해골 분포 가정은 포함하지 않는다.

## 2. 0.02 주요 결정

- `펼치기` 1회에 플레이어와 AI가 카드 1장씩, 총 2장을 공개한다.
- 플레이어와 AI는 각자 바라보는 방향 기준 `왼쪽 → 오른쪽`을 반복한다.
- 좌우 더미의 해골 합계는 서로 독립적으로 계산한다.
- 합계가 정확히 3인 더미가 나오면 벨 경쟁을 진행한다.
- 벨 승자는 선택한 더미에서 합계 3을 구성한 카드를 모두 획득한다.
- 벨 승부가 끝나면 선택하지 않은 반대편을 포함해 양쪽 필드를 모두 초기화한다.
- 한쪽이 벨 3승을 달성하거나 펼치기 26회에 도달할 때까지 반복한다.
- 26회 안에 3승자가 없으면 미획득 카드 풀에서 양측 개인 카드를 3장까지 무작위 보충한다.
- 카드 획득 후 최대 15초 동안 확인 시간을 주며, `W` 입력으로 즉시 다음 펼치기를 진행할 수 있다.
- 전투가 끝날 때까지 하나의 52장 덱을 공유한다.
- 시작 HP는 플레이어와 AI 모두 3이다.

## 3. 전투 전체 흐름

```text
메인 화면
→ 게임 시작
→ 전투용 표준 52장 덱 생성 및 셔플
→ 양측 HP 3으로 초기화
→ 라운드 시작
→ 첫 번째 공용 카드 1장 공개
→ 할리갈리 단계
   ├─ 한쪽이 벨 3승: 단계 종료
   └─ 펼치기 26회 도달: 단계 종료
→ 양측 개인 카드 3장 정리
→ 마지막 공용 카드 1장 공개
→ 아이템 사용 또는 건너뛰기
→ 패 확정
→ 승패 예측
→ AI 개인 카드 공개
→ 5장 포커 족보 비교
→ 포커 패자 HP 감소
→ 포커 승자 재화 획득
→ HP 확인
   ├─ 양측 HP가 남음: 다음 라운드
   └─ 한쪽 HP가 0: 전투 종료
→ 전투 종료 보상 및 아이템 획득 처리
→ 플레이어 승리 시 다음 스테이지
```

## 4. 카드와 덱 구성

### 표준 카드

- 표준 트럼프 52장을 사용한다.
- 문양은 `스페이드, 클로버, 하트, 다이아몬드` 4종이다.
- 랭크는 `A, 2~10, J, Q, K`를 사용한다.
- 조커는 사용하지 않는다.
- 카드 상단에는 포커 문양과 랭크를 표시한다.
- 카드 중앙에는 할리갈리 판정에 사용하는 해골 수를 표시한다.

### 전투 전체 공유 덱

- 전투 시작 시 한 번 생성하고 섞은 덱을 전투 종료까지 공유한다.
- 라운드가 바뀌어도 사용한 카드를 자동으로 새 덱에 되돌리지 않는다.
- 공용 카드, 필드 카드, 개인 획득 카드와 미획득 카드는 같은 전투 덱의 상태로 관리한다.
- 전투 중 덱이 부족해지는 경우의 재구성·재셔플 규칙은 추가 확정이 필요하다.

### 카드 상태

| 상태 | 정의 |
|---|---|
| 남은 덱 | 아직 공개되지 않은 카드 |
| 필드 카드 | 현재 좌우 더미에서 해골 합계 판정에 사용되는 카드 |
| 획득 카드 풀 | 벨 승자가 가져간 개인 카드 후보 |
| 미획득 카드 풀 | 필드 초기화 시 누구도 가져가지 않은 카드 |
| 공용 카드 | 양측의 최종 포커 패에 함께 사용하는 카드 |
| 개인 카드 | 획득·보충·선택을 거쳐 최종 확정한 3장 |

## 5. 라운드 시작

1. 양측의 벨 승리 수를 0으로 초기화한다.
2. 해당 라운드의 획득 카드 풀과 미획득 카드 풀을 준비한다.
3. 전투 공유 덱에서 첫 번째 공용 카드 1장을 공개한다.
4. 좌우 필드를 비운다.
5. 펼치기 횟수를 0으로 초기화한다.
6. 플레이어와 AI의 다음 방향을 각자 기준 왼쪽으로 지정한다.

## 6. 카드 펼치기 단계

### 입력

| 행동 | 마우스 | 키보드 |
|---|---|---|
| 펼치기 시작 | 중앙 펼치기 영역 클릭 | `W` |
| 왼쪽 벨 | 왼쪽 더미 또는 벨 클릭 | `Q` |
| 오른쪽 벨 | 오른쪽 더미 또는 벨 클릭 | `E` |

### 펼치기 1회 처리

```text
플레이어가 W 또는 중앙 UI 입력
→ 플레이어 카드 1장 공개
→ AI 카드 1장 공개
→ 좌우 더미의 해골 합계 판정
→ 벨 가능 상태 또는 다음 펼치기 대기
```

홀수 번째 펼치기:

- 플레이어: 본인 기준 왼쪽, 화면 왼쪽에 카드 1장
- AI: 본인 기준 왼쪽, 플레이어 화면 기준 오른쪽에 카드 1장

짝수 번째 펼치기:

- 플레이어: 본인 기준 오른쪽, 화면 오른쪽에 카드 1장
- AI: 본인 기준 오른쪽, 플레이어 화면 기준 왼쪽에 카드 1장

따라서 펼치기 1회마다 화면 왼쪽과 오른쪽에 카드가 각각 1장씩 추가된다. 플레이어가 누르는 펼치기 입력은 한 라운드에서 최대 26회다.

## 7. 해골 합계와 벨 경쟁

- 화면 왼쪽과 오른쪽 더미는 각자 다른 합계를 가진다.
- 화면에는 계산된 합계 숫자와 정답 더미를 표시하지 않는다.
- 플레이어는 카드에 표시된 해골을 직접 보고 합계를 판단한다.
- 어느 한쪽 또는 양쪽의 합계가 정확히 3이면 벨을 선택할 수 있다.
- 조건에 맞지 않는 더미에도 벨 입력은 가능하며 오답으로 판정한다.
- 플레이어와 AI의 유효 입력이 같은 시각이면 플레이어 입력을 우선한다.

### 한쪽만 합계 3

```text
한쪽 더미 합계 = 3
→ 플레이어와 AI 벨 경쟁
→ 먼저 올바르게 선택한 참가자 승리
```

### 양쪽 모두 합계 3

```text
왼쪽 합계 = 3 그리고 오른쪽 합계 = 3
→ 플레이어와 AI 벨 경쟁
→ 벨 승자가 원하는 더미 하나 선택
```

### 카드 획득

- 벨 승자는 선택한 더미에서 합계 3을 구성한 카드 전체를 획득한다.
- 예: 해골 `1 + 2`로 합계 3을 만들었다면 두 카드를 모두 획득한다.
- 해골 `3` 한 장으로 합계 3을 만들었다면 해당 카드 한 장을 획득한다.
- 선택하지 않은 반대편 필드 카드는 미획득 카드 풀로 이동한다.
- 카드 획득 처리가 끝나면 양쪽 필드를 모두 초기화한다.
- 다음 세트는 빈 필드에서 다시 각자 기준 왼쪽부터 시작한다.

### AI 획득 카드 노출

- AI가 벨 승부에서 이기면 AI가 실제 획득하는 카드만 이동 연출 중 일시적으로 보여준다.
- AI가 선택해야 하는 더미가 둘이면 획득할 더미를 무작위로 선택한다.
- 획득 연출이 끝난 AI 카드는 다시 숨긴다.
- AI가 해당 벨 판정에서 패배하면 별도의 AI 카드 획득 정보는 보여주지 않는다.

## 8. 카드 획득 후 확인 유예

```text
벨 승부 및 카드 이동 연출 완료
→ 최대 15초 확인 유예 시작
   ├─ W 또는 중앙 UI 입력: 즉시 다음 펼치기
   └─ 15초 만료: 자동으로 다음 펼치기
```

- 플레이어는 최대 15초 동안 첫 공용 카드, 자신의 획득 카드와 AI가 방금 획득한 카드 연출을 확인할 수 있다.
- 확인을 마쳤다면 15초가 끝나기 전에도 `W` 또는 중앙 UI 클릭으로 진행할 수 있다.
- 기존 0.01의 30초 할리갈리 전체 제한 시간은 사용하지 않는다.

## 9. 할리갈리 단계 종료

### 벨 3승 종료

```text
한쪽이 벨 승리 3회 달성
→ 남은 펼치기 횟수와 관계없이 할리갈리 단계 종료
```

### 펼치기 26회 종료

```text
26회 펼치기 완료
→ 양쪽 모두 벨 3승 미달
→ 할리갈리 단계 종료
→ 개인 카드 수 확인
```

- 26회 제한 종료에서는 기존의 카드 1장 버리기 공통 페널티를 사용하지 않는다.
- 양측은 자신의 획득 카드가 3장이 될 때까지 미획득 카드 풀에서 무작위로 보충한다.
- 보충된 카드는 미획득 카드 풀에서 제거해 중복 획득을 방지한다.

## 10. 개인 카드 3장 정리

| 획득 카드 수 | 처리 |
|---:|---|
| 3장 미만 | 미획득 카드 풀에서 3장이 될 때까지 무작위 보충 |
| 정확히 3장 | 그대로 개인 카드로 확정 |
| 3장 초과 | 원하는 카드 3장을 선택하고 나머지는 미획득 카드 풀로 이동 |

### 플레이어 선택 조작

- 마우스를 카드 위에 올리면 해당 카드를 하이라이트한다.
- 키보드 왼쪽·오른쪽 방향키로 카드 하이라이트를 이동한다.
- 카드 3장을 선택한 뒤 확정한다.
- 키보드 선택·해제와 최종 확정 키는 추가 확정이 필요하다.

### AI 카드 정리

- AI가 3장을 초과해 획득했다면 AI 카드 평가 기준으로 3장을 선택한다.
- AI 개인 카드 3장은 승패 예측이 끝날 때까지 숨긴다.

## 11. 마지막 공용 카드, 아이템과 승패 예측

```text
양측 개인 카드 3장 확정
→ 마지막 공용 카드 1장 공개
→ 개인 카드 3장 + 공용 카드 2장 확인
→ 아이템 사용 또는 건너뛰기
→ 아이템 결과 반영
→ 패 확정
→ 내가 이긴다 / 내가 진다 선택
→ AI 개인 카드 공개
→ 양측 5장 포커 족보 비교
```

- 아이템은 패 확정 전에만 사용할 수 있다.
- 패 확정 이후에는 카드 선택과 아이템 결과를 변경할 수 없다.
- 승패 예측은 패 확정 후, AI 개인 카드 공개 전에 진행한다.
- 실제 포커 결과와 예측 성공·실패 결과를 구분해 표시한다.
- 5장 포커 동률 처리는 후순위 기획으로 남긴다.

## 12. HP, 재화와 전투 종료

### HP

- 전투 시작 HP는 플레이어와 AI 모두 3이다.
- 포커 패자의 HP를 감소시킨다.
- 기본 피해량과 아이템에 의한 피해 변경은 추가 확정이 필요하다.
- 양측 HP가 남아 있으면 같은 전투 공유 덱을 유지한 채 다음 라운드로 진행한다.

### 포커 승리 재화

- 포커 승자는 현재 남아 있는 자신의 HP만큼 재화를 획득한다.
- 예: 승자의 남은 HP가 1이면 재화 1을 추가한다.
- 재화의 사용처와 전투 종료 시 유지 범위는 후속 기획으로 남긴다.

### 예측 성공 보상

- 승패 예측 성공은 전투 종료 후 보상 증가 또는 아이템 희귀도 증가와 연결한다.
- 두 보상 중 적용 방식, 증가량과 중복 여부는 후속 기획으로 남긴다.

### 전투 종료와 스테이지

```text
상대 HP를 0으로 만듦
→ 플레이어 전투 승리
→ 전투 종료 보상 정산
→ 아이템 획득 처리
→ 다음 스테이지 이동

플레이어 HP가 0
→ 전투 패배
→ 전투 종료 처리
```

- 아이템 획득과 보상 정산은 전투 종료 시 진행한다.
- 획득한 아이템은 이후 전투의 패 확정 전 아이템 단계에서 사용할 수 있다.

## 16. 구현 전달용 수용 기준

- [ ] 전투 시작 시 양측 HP가 3으로 설정된다.
- [ ] 전투 전체에서 하나의 52장 덱 상태가 유지된다.
- [ ] `W` 또는 중앙 UI 입력 1회에 플레이어와 AI 카드가 각각 1장씩 공개된다.
- [ ] 양측은 각자 기준 왼쪽과 오른쪽을 번갈아 사용한다.
- [ ] 화면 왼쪽과 오른쪽 더미에 매 펼치기 1장씩 추가된다.
- [ ] 합계 숫자와 정답 강조 없이 카드의 해골만 보고 합계 3을 판단할 수 있다.
- [ ] 합계 3인 더미의 벨 승자가 해당 더미의 카드 전체를 획득한다.
- [ ] 벨 승부 후 반대편을 포함한 양쪽 필드가 초기화된다.
- [ ] AI 획득 카드는 획득 연출 중에만 확인할 수 있다.
- [ ] 획득 후 최대 15초 대기하며 `W`로 즉시 진행하거나 만료 시 자동 진행한다.
- [ ] 벨 3승 또는 펼치기 26회에서 할리갈리 단계가 종료된다.
- [ ] 26회 내 3승자가 없으면 미획득 카드 풀에서 부족한 개인 카드를 보충한다.
- [ ] 3장 초과 시 마우스와 좌우 방향키로 카드를 하이라이트할 수 있다.
- [ ] 마지막 공용 카드 공개 후 아이템 사용 또는 건너뛰기와 패 확정이 가능하다.
- [ ] `패 확정 → 승패 예측 → AI 카드 공개 → 족보 비교` 순서를 유지한다.
- [ ] 포커 승자는 남은 자신의 HP만큼 재화를 획득한다.
- [ ] HP가 0이 되면 전투가 종료되고, 플레이어 승리 시 다음 스테이지로 이동한다.
- [ ] 전투 종료 시 보상과 아이템 획득 결과를 표시한다.
