# 확정사항

## D-001. 할리갈리 기본 정답 조건

- 상태: 확정
- 판정 문양은 `클로버(♣)`, `하트(♥)`, `다이아몬드(♦)`, `스페이드(♠)` 4종이다.
- 기본 정답은 **같은 문양이면서 해골 수 합계가 3인 카드 조합**이다.
- 해골 `1 + 2` 또는 `2 + 1` 조합은 두 카드의 문양이 같을 때 정답이다.
- 해골 3 카드의 단독 획득 규칙은 D-003을 따른다.
- 각 벨은 자신에게 대응하는 왼쪽 또는 오른쪽 카드 더미 한쪽만 판정한다.
- 한쪽 카드 더미에서 동시에 판정하는 카드는 최대 2장이며, 반대편 카드와 합산하지 않는다.
- 따라서 `1 + 1 + 1`은 정답으로 인정하지 않는다.

## D-002. 해골 1·2 정답 카드 획득

- 상태: 확정
- 같은 문양의 해골 1 카드와 해골 2 카드로 정답이 성립하면 두 장을 모두 획득한다.
- 두 카드는 정답을 맞힌 참가자의 개인 획득 카드 저장소로 이동한다.
- 획득된 두 카드는 미획득 카드풀과 이후 재셔플 대상에서 제외한다.

```text
같은 문양 해골 1 + 해골 2
→ 유효 벨 판정
→ 먼저 정답 입력한 참가자 결정
→ 해골 1 카드와 해골 2 카드 모두 획득
→ 개인 획득 카드 저장소로 이동
```

## D-003. 해골 3 정답 카드 획득

- 상태: 확정
- 해골 3 조건으로 성공하면 펼치기 단계에 노출된 해골 3 카드 한 장만 획득한다.
- 같은 카드 더미에 다른 해골 카드가 함께 있어도 해골 3 카드만 개인 획득 카드 저장소로 이동한다.
- 함께 있던 비선택 카드는 획득 카드로 처리하지 않는다.
- 해골 3 카드가 여러 장 노출됐을 때 어느 한 장을 선택하는지는 기존 최신 명세의 `가장 최근에 펼쳐진 해골 3 카드` 규칙을 유지한다.

## D-004. 양쪽 조건 동시 성립과 입력 우선순위

- 상태: 확정
- 왼쪽과 오른쪽이 모두 정답 조건을 만족하면 먼저 누른 쪽의 벨만 정답으로 처리한다.
- 먼저 선택된 유효 카드 더미만 획득 처리한다.
- 왼쪽 벨과 오른쪽 벨은 각각 대응하는 카드 더미만 판정하며, 화면 전체의 같은 문양 카드를 합산하지 않는다.
- 입력 시각이 최신 명세의 동시 판정 범위에 들어오면 플레이어를 우선한다.
- 최초 판정이 확정된 뒤 들어온 같은 프레임의 추가 입력과 연타는 무시한다.

## D-005. 카드 공개 중 벨 입력과 카드 상태

- 상태: 확정
- 직전 승패가 확정된 직후 다음 진행에 **2초 펼치기 잠금**을 1회 적용한다.
- 2초 잠금 중에는 벨 입력을 받지 않으며, 잠금이 끝난 뒤에는 카드가 순차 공개되는 도중에도 벨 입력을 받을 수 있다.
- 벨을 누른 순간의 카드 상태를 기준으로 선택한 카드 더미의 정답 여부를 판정한다.
- 카드는 앞면 전환이 완료된 시점부터 벨 판정 대상이 된다.
- 선택 카드가 앞면 전환을 완료했다면 획득 가능 카드에 포함한다.
- 선택하지 않은 카드 더미의 최상단 카드는 획득하지 않고 해당 더미 맨 아래로 이동한다.

> 이 결정은 `게임진행플로우_0.1.0.md`의 `4장 배분 중 벨 입력 잠금`, `네 번째 CardRevealComplete 이후 판정 시작` 규칙을 변경한다.

## D-006. 카드 펼치기 순서

- 상태: 확정
- 배분 시작 참가자와 관계없이 다음 순서를 유지한다.

```text
1. 플레이어 본인 기준 왼쪽 카드 공개
2. AI 본인 기준 왼쪽 카드 공개
3. 플레이어 본인 기준 오른쪽 카드 공개
4. AI 본인 기준 오른쪽 카드 공개
```

- AI의 네 번째 카드는 `AI 본인 기준 오른쪽`으로 확정한다.
- 공개 중 벨로 라운드 결과가 확정되면 남은 카드 공개를 즉시 중단하고 다음 할리갈리 라운드로 이동한다.
- 카드의 제출 주체가 보이도록 플레이어 카드 펼치기 저장소는 화면 하단 중앙, AI 카드 펼치기 저장소는 화면 상단 중앙에 둔다.
- 플레이어 카드는 하단 덱에서 판정 슬롯 방향으로 위쪽 이동하고, AI 카드는 상단 덱에서 판정 슬롯 방향으로 아래쪽 이동한 뒤 앞면을 공개한다.
- 위·아래 출발점과 이동 방향은 대면 연출을 위한 표시 규칙이며, 왼쪽·오른쪽 벨의 논리 슬롯과 판정 범위는 변경하지 않는다.
- 실제 게임 화면에서는 검토 이미지의 흰색 여백 대신 살룬·원형 테이블 배경이 이어져야 한다.
- 세부 이동·회전·도착 수용 기준은 [[03_가이드_및_카드_UI_개선_기준]]의 `대면형 덱 배치와 카드 제출 연출`을 따른다.

## D-007. 획득 카드 저장과 포커 사용

- 상태: 확정
- 할리갈리 단계에서 획득한 카드는 참가자별 개인 획득 카드 저장소에 보관한다.
- 저장된 획득 카드는 포커 단계의 개인 카드 구성에 사용한다.
- 포커 판정에 실제 사용하는 개인 카드는 정확히 3장이다.
- 개인 획득 카드가 3장을 초과하면 플레이어와 AI 모두 포커에 사용할 3장을 직접 선택한다.
- 기존 `3 → 2 → 2` 직접 선택 규칙을 유지한다.
- 할리갈리 단계 패자도 정상적으로 획득한 카드를 유지하며, 3장을 초과하면 동일하게 직접 선택한다.
- 오답 또는 제한 시간 초과로 해당 할리갈리 라운드에서 패배해도, 이전 라운드에서 정상 획득한 카드는 빼앗기거나 상대의 보상 카드 선택 대상으로 이동하지 않는다.
- 개인 획득 카드가 3장 미만이면 할리갈리 단계 종료 시 미획득 카드풀에서 시드 기반 무작위로 지급해 정확히 3장을 구성한다.
- 카드 펼치기에 사용하려 했으나 소진되지 않은 카드도 단계 종료 시 미획득 카드풀에 포함한다.
- 개인 획득 카드는 현재 전투의 포커 라운드까지 유지한다.
- 포커 판정과 해당 전투 라운드가 끝나면 개인 획득 카드 저장소를 초기화하며, 다음 전투 라운드는 새 52장 덱과 새 개인 카드 구성으로 시작한다.

## D-008. 카드 부족과 미획득 카드풀 처리

- 상태: 확정
- 카드 펼치기 저장소가 4장 미만이어도 남은 카드가 있으면 순차 공개를 계속한다.
- 전투 라운드의 할리갈리 단계 진행 중에는 미획득 카드풀을 재셔플해 펼치기 저장소를 다시 채우지 않는다.
- 다음 카드 공개가 필요하지만 펼치기에 사용할 카드가 없으면 할리갈리 단계를 즉시 종료한다.
- 현재 필드에 노출됐지만 획득되지 않은 카드와 펼치기에 사용하지 못한 잔여 카드는 단계 종료 시 미획득 카드풀에 포함한다.
- 이 종료 시점에 개인 카드가 3장 미만이면 D-007의 무작위 보충 규칙을 적용한다.
- 새 덱 구성과 재셔플은 포커 라운드가 끝난 뒤 다음 전투 라운드를 시작할 때 새 시드로 수행한다.

> `게임진행플로우_0.1.0.md`의 `전투 라운드 진행 중 재셔플하지 않는다` 규칙을 유지한다.

## D-009. 제한 시간·오조작·동시 입력

- 상태: 확정
- 기본 제한 시간은 30초다.
- 제한 시간 초과는 해당 할리갈리 라운드의 패배 1회로 판정한다.
- 오조작 또는 오답 벨은 해당 할리갈리 라운드의 패배 1회로 판정한다.
- 제한 시간 초과·오조작·오답으로 승리한 상대에게는 승리 1회만 기록한다.
- 위 사유로 패배한 참가자의 기존 획득 카드를 빼앗지 않으며, 상대에게 별도의 보상 카드 선택 단계도 제공하지 않는다.
- 플레이어와 AI 입력이 동시로 판정되면 플레이어를 우선한다.
- 직전 승패 확정 직후 2초 펼치기 잠금을 1회 적용하고, 잠금이 끝나면 30초 벨 입력 제한 타이머를 시작한다.
- 2초 잠금이 끝난 뒤에는 카드 공개 도중에도 벨 입력할 수 있으며, 앞면 전환이 완료된 카드만 판정에 포함한다.

## D-010. AI 대전

- 상태: 확정
- 기본 게임 모드는 플레이어 대 AI 대전이다.
- AI도 플레이어와 같은 카드 판정, 획득, 개인 카드 3장과 포커 비교 규칙을 사용한다.
- AI의 반응 시간과 정답·오답·놓침 확률은 별도 밸런싱 값으로 관리한다.

## D-011. 포커 사용 카드

- 상태: 확정
- 플레이어와 AI는 각각 개인 카드 3장을 사용한다.
- 양측은 커뮤니티 카드 2장을 공유한다.
- 포커 족보 판정에는 개인 카드 3장과 커뮤니티 카드 2장, 정확히 5장을 모두 사용한다.
- 일부 카드만 골라 사용하는 베스트 핸드 방식은 사용하지 않는다.

## D-012. 포커 동률 처리

- 상태: 확정
- 동률 처리는 최신 명세의 포커 비교 규칙을 사용한다.
- 랭크 비교가 모두 같으면 같은 비교 위치의 카드 문양을 비교한다.
- 문양 우선순위는 `♠ 스페이드 > ♦ 다이아몬드 > ♥ 하트 > ♣ 클로버`다.
- 랭크와 문양 비교를 끝까지 적용하므로 최종 동률은 발생하지 않는다.

## D-013. 승패 예측 시점

- 상태: 확정
- 모든 아이템 사용과 카드 변경을 마친 뒤, 실제 승패를 공개·확인하기 직전에 승패 예측을 진행한다.
- 예측 입력을 확정한 뒤 AI 개인 카드 공개와 포커 결과 판정을 진행한다.
- 예측 결과는 포커 승패 자체를 변경하지 않고 별도 보상 판정에만 사용한다.
- 승패 예측 제한 시간은 2분이다.

## D-014. 아이템 사용과 승패 예측

- 상태: 확정
- 아이템은 승패 예측 단계에 진입하기 전에만 사용할 수 있다.
- 기본 5장 승부에는 아이템 사용 개수 제한을 두지 않으며 보유한 사용 가능 아이템을 연속으로 사용할 수 있다.
- 아이템 사용 개수 제한은 향후 특정 스테이지의 패널티 규칙으로만 적용할 수 있으며 기본 규칙에는 적용하지 않는다.
- 예측 성공 횟수는 현재 스테이지에서 집계하며 최대 5회다.
- 예측 실패·2분 무반응은 성공 횟수를 늘리지 않고 일회성 재화를 지급하지 않는다.
- 스테이지 승리 시 예측 성공 결과에 따른 일회성 재화를 별도 지급한다.
- 아이템으로 카드가 변경되면 변경된 최종 카드 상태를 확인한 뒤 승패 예측을 한 번 진행한다.
- 카드 변경 시 재예측하지 않으며 예측 제한 시간도 초기화하지 않는다.
- 정확한 일회성 재화 지급량은 밸런싱 데이터에서 조정한다.

## D-015. 할리갈리 최대 진행 횟수와 조기 종료

- 상태: 확정
- 할리갈리 단계는 최대 12회까지 진행하며, 1회당 최대 4장을 순차 배분한다.
- 12회 한도에 도달하면 할리갈리 단계를 종료한다.
- 한도에 도달하기 전이라도 펼치기에 사용할 카드가 없으면 즉시 종료한다.
- 종료 시 플레이어 또는 AI의 개인 카드가 3장 미만이면 미획득 카드풀에서 시드 기반 무작위 카드를 지급해 정확히 3장을 구성한다.

## D-016. 스테이지 승리 보상과 재화

- 상태: 확정
- AI의 HP가 0이 되는 순간 플레이어의 스테이지 승리를 확정한다.
- 스테이지 클리어 보상은 기본 재화, 예측 성공 보상은 일회성 재화로 분리한다.
- 두 재화의 정확한 지급량은 보상 밸런싱 데이터에서 조정한다.
- 기본 재화는 현재 런 동안 다음 스테이지로 이월한다.
- 일회성 재화는 승리 직후 상점에서 먼저 사용하고 상점 이탈 시 남은 수량을 소멸한다.
- 캐릭터 사망 시 기본·일회성 재화와 현재 런 진행을 초기화한다.
- 일반 플레이 화면에는 재화 명칭을 표시하지 않고 서로 다른 아이콘과 숫자만 표시한다.
- 1차 아이템 3종, 가격, 인벤토리·구매 제한과 체력 회복 가격은 `게임진행플로우_0.1.2.2`를 따른다.
- 공개 화면에 `미확정`, `개발 중` 같은 내부 문구를 노출하지 않는다.

## D-017. 게임 시작과 다음 스테이지 전환

- 상태: 확정
- 게임 최초 시작 시 `가게로 걸어감 → 살룬 스윙도어를 열고 입장 → 실내 중앙 원형 테이블로 접근 → 착석 → 상대 소개 및 전투 시작` 순서로 진행한다.
- 스테이지 승리 뒤에는 `기본·일회성 재화 분리 정산 → 현재 가게의 바 → 상점 이탈 → 전환 연출 → 새 가게 입장 → 새 상대 소개 → 중앙 원형 테이블 착석 → 다음 전투 시작` 순서로 진행한다.
- 상점 이탈 후 전환 연출 재생 중에는 모든 게임 입력을 잠그고, 실제 연출 재생 완료 이벤트에서 다음 스테이지를 한 번 시작한다.
- 전환 시간은 별도 고정 초 수가 아니라 실제 연출 재생시간을 기준으로 한다. 건너뛰기와 최종 아트·사운드는 후순위다.
