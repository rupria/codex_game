# 스테이지 보상·바 상점 및 전환 기준

> 최신 재화 종류·소비 순서·표시 기준은 [[게임진행플로우_0.1.2.2]]과 [[07_인게임_텍스트_최소화_및_재화_UI_기준]]을 우선한다.

## 1. 목적

이 문서는 전투 승리 뒤 보상 정산, 현재 가게의 바 이용, 다음 가게로 이동하는 스테이지 메타 진행을 관리한다. 확정된 진행 순서와 아직 수치가 정해지지 않은 상점 항목을 분리한다.

참고 연출:

- https://youtu.be/TIn5M86ogvQ?si=h5f28CRs3OOekmU7
- 살룬 스윙도어 참고 이미지: 사용자 제공 이미지
- 참고 자료는 분위기와 카메라 동선의 기준이며 원본 영상·이미지를 그대로 복제하거나 에셋으로 사용하지 않는다.

## 2. 확정 규칙

### 2.1 스테이지 승리와 보상 정산

- AI의 HP가 0이 되는 순간 플레이어의 스테이지 승리를 확정한다.
- 내부 기획에서는 스테이지 클리어 보상을 `기본 재화`, 예측 성공 보상을 `일회성 재화`로 구분한다. 일반 플레이 화면에는 재화 명칭을 표시하지 않는다.
- 기본 재화 지급량은 현재 보상 밸런싱 데이터에서 조정한다.
- 일회성 재화 지급량은 현재 스테이지의 예측 성공 결과를 기준으로 별도 데이터에서 조정한다.
- 보상은 포커 한 판이나 HP 감소마다 지급하지 않고, AI HP가 0이 된 뒤 스테이지당 한 번만 정산한다.
- 사용하지 않은 총알은 스테이지 전환과 바 방문 이후에도 누적해서 유지한다.
- 총알은 현재 캐릭터의 런에 귀속되며 캐릭터가 사망하면 0으로 초기화한다.
- 상점에서 총알을 사용하면 구매 가격만큼 현재 보유량에서 차감한다.
- 예: 플레이어 잔여 HP가 2일 때 AI HP가 0이 되면 총알 2개를 획득한다.

### 2.2 바 상점

- 보상 정산 뒤 플레이어는 방금 게임을 진행한 가게의 `바`로 이동한다.
- 바에서는 총알을 소비해 아이템 구매와 체력 회복을 할 수 있다.
- 보상 정산 결과와 현재 총알 보유량은 바 진입 전에 반영한다.
- 1차 아이템 3종과 가격, 인벤토리 4칸, 동일 ID 1개, 구매 횟수 무제한, 체력 회복 가격 1은 확정한다. 후순위 아이템과 정확한 보상 지급량은 밸런싱 중이다.

#### 2.2.1 더미 상점과 리롤 적용 범위

- 더미 상점은 AI의 HP가 0이 되어 스테이지 클리어가 확정된 뒤에만 진입한다.
- 전투 라운드 중간이나 플레이어 패배 시에는 더미 상점을 열지 않는다.
- 상점은 `총알 보상 정산` 이후이면서 `다음 스테이지 전환` 이전에 위치한다.
- 상점 진입 시 기본 재화와 일회성 재화를 서로 다른 아이콘과 숫자로 표시하고 현재 HP를 함께 표시한다.
- 더미 상품 풀은 6종이며, 한 번의 상점 방문에 상품 슬롯 3개를 표시한다.
- 상품은 이름·아이콘·가격·효과를 교체 가능한 데이터 필드로 가지되 현재 더미 단계에서는 실제 구매, 총알 차감, 인벤토리 반영과 아이템 효과를 실행하지 않는다.
- 상점 방문당 무료 리롤을 1회 제공하며, 리롤 시 세 상품 슬롯을 모두 다시 구성한다.
- 리롤 결과는 시드 기반으로 재현 가능해야 하고, 같은 방문에서 리롤을 사용한 뒤에는 리롤 입력을 비활성화한다.
- 다음 스테이지의 새 상점 방문에서는 리롤 사용 상태를 초기화한다.
- 현재 더미 리롤 비용은 0이며, 이후 비용·횟수 규칙을 데이터로 교체할 수 있게 분리한다.
- `다음 가게로` 입력을 통해 상점을 종료하고 이후 다음 스테이지 전환을 시작한다.
- 공개 화면에는 `미확정`, `개발 중` 같은 내부 관리 문구를 노출하지 않는다.

> 더미 상점은 상점 진입·상품 표시·리롤·퇴장 상태를 검증하기 위한 임시 구현 범위다. 실제 아이템 효과·가격·구매·체력 회복 규칙이 확정된 것으로 해석하지 않는다.

### 2.3 게임 최초 시작 연출

`시작`을 누르면 전투 화면을 즉시 표시하지 않고 다음 순서로 진행한다.

```text
가게로 걸어가는 장면
→ 살룬 스윙도어 앞 도착
→ 플레이어 시점으로 문을 밀어 열고 입장
→ 실내 한가운데의 원형 테이블로 접근
→ 테이블에 앉음
→ 상대 소개 및 전투 시작
```

- 카메라는 플레이어가 직접 가게에 들어가는 1인칭에 가까운 이동감을 전달한다.
- 문은 서부극 살룬의 양쪽 스윙도어 형태로 열리며, 문을 통과하면 실내 중앙의 원형 테이블이 시선의 중심이 된다.
- 착석 동작이 끝난 뒤 기존 게임 테이블 화면으로 자연스럽게 연결한다.

### 2.4 다음 스테이지 전환 연출

바 이용을 마치고 다음 스테이지로 이동하면 다음 순서를 사용한다.

```text
현재 가게의 바 종료
→ 가게를 나섬
→ 다음 가게로 걸어가는 이미지가 있는 로딩 화면
→ 다른 가게의 살룬 스윙도어를 열고 입장
→ 새 상대를 보여주는 연출
→ 실내 한가운데 원형 테이블로 접근
→ 테이블에 앉음
→ 다음 스테이지 게임 시작
```

- 최초 시작과 다음 스테이지는 `가게 진입 → 중앙 원형 테이블 착석`이라는 같은 핵심 문법을 공유한다.
- 다음 스테이지에서는 가게 이동 로딩과 새 상대 소개를 앞에 추가한다.
- 로딩이 실제 데이터 로드를 동반하더라도 장면 전환이 끝나기 전에는 게임 입력과 전투 타이머를 시작하지 않는다.

## 4. 연출·UI 수용 기준

- [ ] AI HP가 0이 되기 전에는 총알 보상 정산이 발생하지 않는다.
- [ ] 스테이지 승리 정산에서 기본 재화와 일회성 재화가 서로 다른 아이콘과 숫자로 표시된다.
- [ ] 같은 스테이지에서 보상 정산이 두 번 호출되지 않는다.
- [ ] 바 진입 시 정산된 총알 보유량과 현재 HP를 확인할 수 있다.
- [ ] 사용하지 않은 총알이 다음 스테이지와 다음 바 방문에서도 유지된다.
- [ ] 캐릭터 사망 시 보유 총알이 0으로 초기화된다.
- [ ] AI HP가 0이 되기 전과 플레이어 패배 시에는 더미 상점이 열리지 않는다.
- [ ] 상점에 더미 상품 3개가 표시되고 방문당 무료 리롤 1회로 세 슬롯이 갱신된다.
- [ ] 같은 방문에서 두 번째 리롤은 실행되지 않고 다음 상점 방문에서 리롤 상태가 초기화된다.
- [ ] 상점 중 카드 펼치기, 벨, 예측 입력과 전투 타이머가 진행되지 않는다.
- [ ] `다음 가게로` 입력을 한 번 처리한 뒤에만 다음 스테이지 전환을 시작한다.
- [ ] 아이템과 체력 회복은 가격과 효과가 확정되기 전 임의 수치로 활성화하지 않는다.
- [ ] 최초 시작과 다음 스테이지 모두 살룬 스윙도어 통과와 중앙 원형 테이블 착석 장면을 포함한다.
- [ ] 다음 스테이지 전환은 `가게 퇴장 → 이동 로딩 → 새 가게 입장 → 상대 소개 → 착석` 순서를 지킨다.
- [ ] 이동·입장·착석 연출 중 카드 펼치기, 벨, 예측과 전투 타이머 입력을 받지 않는다.
- [ ] 착석 연출의 마지막 프레임과 실제 게임 테이블의 카메라 방향·테이블 위치가 시각적으로 이어진다.
- [ ] WebGL 로딩 지연이 발생해도 검은 화면 대신 이동 이미지 또는 로딩 상태가 유지된다.

## 5. 미확정 사항

아래 항목은 구현자가 임의로 정하지 않는다.

1. 플레이어 패배 시 총알 또는 다른 보상을 지급하는지 여부
2. 후순위 아이템의 효과와 가격
3. 체력 회복 아이템의 정확한 회복량과 최대 HP
4. 바에서 구매 없이 나갈 수 있는지, 바 종료가 수동인지 자동인지
5. 스테이지 수, 가게와 상대의 배치 데이터
6. 최초 시작·가게 이동·입장·착석 연출의 정확한 길이와 건너뛰기 허용 여부
7. 이동 로딩 이미지, 살룬 스윙도어, 실내와 상대 소개에 사용할 최종 아트·사운드

더미 상점에 한해 상품 3칸, 더미 풀 6종, 방문당 무료 리롤 1회와 `다음 가게로` 수동 종료는 2026-08-09 구현 검증 기준으로 확정한다. 이는 위 2~4번의 최종 상점 규칙을 확정하지 않는다.
