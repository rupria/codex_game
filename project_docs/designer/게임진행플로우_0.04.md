### 용어 사용 원칙

- `할리갈리`는 단독 라운드 명칭이 아니라 `할리갈리 단계`로 표기한다.
- 합계 3 판정과 벨 승부로 발생하는 승패 단위를 `할리갈리 라운드`로 표기한다.
- 모든 전투 라운드에서 할리갈리 단계를 진행한다.
- 승리 목표는 첫 번째 전투 라운드 3승, 두 번째 전투 라운드 2승, 세 번째 이후 전투 라운드 1승이다.

### 전투 라운드별 할리갈리 승리 목표

| 전투 라운드 | 할리갈리 단계 종료 승수 |
|---:|---:|
| 1번째 | 3승 |
| 2번째 | 2승 |
| 3번째 이후 | 1승 |

라운드가 진행될수록 할리갈리 구간을 단축하되, 개인 카드를 할리갈리로 획득하는 핵심 행동은 모든 전투 라운드에서 유지한다.

### 전투 라운드별 개인 카드 구성

| 전투 라운드 | 할리갈리 승리 목표 | 단계 승자 | 단계 패자 |
|---:|---:|---|---|
| 1번째 | 3승 | 획득 후보 중 3장 선택 | 미획득 후보군에서 무작위 3장 |
| 2번째 | 2승 | 획득 후보 중 2장 선택 + 무작위 1장 | 미획득 후보군에서 무작위 3장 |
| 3번째 이후 | 1승 | 획득 후보 중 1장 선택 + 무작위 2장 | 미획득 후보군에서 무작위 3장 |

단계 패자가 할리갈리 중 획득한 카드는 개인 카드 선택권에 사용하지 않고 미획득 후보군으로 이동한다.

## 3. 0.04 주요 결정

- 좌우 카드 더미에는 각각 최대 2장의 카드만 노출한다.
- 카드 더미에서 밀려나거나 초기화된 카드는 미획득 풀로 이동한다.
- 미획득 풀은 카드 펼치기 저장소와 분리하며 카드 펼치기 순서에 영향을 주지 않는다.
- 할리갈리 라운드 종료 시 획득을 시도한 카드 더미만 초기화한다.
- 반대편 카드 더미는 유지한다.
- 카드 더미 초기화와 관계없이 다음 카드 펼치기 방향과 횟수는 기존 순서대로 진행한다.
- 오답 벨을 입력한 참가자는 해당 할리갈리 라운드에서 즉시 패배한다.
- 카드 펼치기 입력 제한 시간은 30초다.
- 현재 행동 주체가 30초 안에 카드 펼치기를 시도하지 않으면 해당 할리갈리 라운드에서 패배한다.
- 1스테이지 AI 난이도는 본 명세에 정의된 기본 AI 판정값을 그대로 사용한다.
- AI는 올바른 벨 기회가 있어도 30% 확률로 벨을 놓친다.
- 좌우 카드 더미가 모두 합계 3이면 AI는 자신의 포커 승률에 더 유리한 카드를 우선 획득한다.
- 플레이어와 AI의 벨 입력이 사실상 동시에 판정되면 플레이어 입력을 우선한다.
- 첫 번째 전투 라운드 시작 시 전투 라운드 시드를 새로 생성한다.
- 전투 라운드 종료 후 양측 HP가 남아 있으면 다음 전투 라운드 시드를 다시 생성하고 52장 덱을 새로 셔플한다.
- 모든 전투 라운드에서 할리갈리 단계를 진행하며 승리 목표는 3승 → 2승 → 1승으로 단축한다.
- 단계 승자의 직접 선택 카드는 3장 → 2장 → 1장으로 줄고, 부족분은 각각 0장 → 1장 → 2장을 무작위 보충한다.
- 단계 패자는 모든 전투 라운드에서 개인 카드 3장을 무작위 획득한다.
- 첫 번째 공용 카드 1장을 제외한 카드로 할리갈리 단계를 진행하며, 플레이어와 AI가 한 장씩 펼칠 수 없으면 단계를 종료한다.
- 각 전투 라운드의 카드 펼치기는 최대 25회이며 플레이어와 AI가 각각 최대 25장씩 펼친다.
- 할리갈리 단계 종료 시 펼치지 않은 카드도 미획득 후보군에 포함한다.
- 개인 카드 배분을 완료한 뒤 포커 단계에 진입하고, 남은 랜덤 획득 후보군에서 두 번째 공용 카드를 현재 전투 라운드 시드 기반으로 무작위 선정한다.
- 개인 카드 선택이 1분을 초과하면 현재 선택을 유지하고 부족한 장수만 랜덤 획득 후보군에서 무작위 획득한다.
- 포커 패배 시 기본 피해량은 1이다.
- 승패 예측에 성공하면 아이템 또는 스테이지 종료 시 코인 증가 중 하나를 무작위로 획득한다.
- 예측에 실패하면 해당 전투 라운드의 예측 보상을 획득하지 못하지만 이전에 누적한 코인 증가 수치는 유지한다.
- 사용할 아이템이 없으면 아이템 선택 단계에서 별도 입력 없이 자동으로 건너뛴다.

```text

→ 전투 라운드 시드 새로 생성

→ 랜덤 획득 후보군 1차 구성

   ├─ 1번째: 후보가 3장 초과이면 3장 선택
   ├─ 2번째: 후보가 2장 초과이면 2장 선택
   └─ 3번째 이후: 후보가 1장 초과이면 1장 선택

→ 승자의 부족분과 단계 패자의 개인 카드 3장을 무작위 획득
→ 양측 개인 카드 3장 확정
→ 포커 단계 진입
→ 남은 랜덤 획득 후보군에서 두 번째 공용 카드 1장 무작위 선정 및 공개
→ 개인 카드 3장과 공용 카드 2장 확인

→ 패 확정
→ 승패 예측
→ AI 개인 카드 공개
→ 5장 포커 족보 비교
→ 포커 패자 HP 1 감소
→ 승패 예측 결과 처리
   ├─ 성공: 아이템 또는 스테이지 종료 코인 증가 중 하나를 무작위로 누적
```

## 5. 카드 구성과 저장소

### 표준 카드

- 표준 트럼프 카드의 문양과 랭크를 사용한다.
- 문양은 `스페이드, 클로버, 하트, 다이아몬드` 4종이다.
- 랭크는 `A, 2~10, J, Q, K`를 사용한다.
- 조커는 사용하지 않는다.
- 카드 상단에는 포커 문양과 랭크를 표시한다.
- 카드 중앙에는 할리갈리 판정에 사용하는 해골 수를 표시한다.

### 카드 저장소 분리

| 저장소 | 포함 카드 | 카드 펼치기 순서 영향 |
|---|---|---|
| 카드 펼치기 저장소 | 아직 펼치지 않은 카드 | 있음 |
| 왼쪽 카드 더미 | 화면 왼쪽에 현재 노출된 최대 2장 | 없음 |
| 오른쪽 카드 더미 | 화면 오른쪽에 현재 노출된 최대 2장 | 없음 |
| 미획득 풀 | 펼쳤지만 획득되지 않은 카드 | 없음 |
| 플레이어 획득 카드 풀 | 플레이어가 획득한 개인 카드 후보 | 없음 |
| AI 획득 카드 풀 | AI가 획득한 개인 카드 후보 | 없음 |
| 공용 카드 | 양측 포커 패에 함께 사용하는 카드 | 없음 |

### 저장소 운용 원칙

- 첫 번째 전투 라운드 시작 시 전투 라운드 시드를 새로 생성한다.
- 전투 라운드 종료 후 양측 HP가 남아 있으면 다음 전투 라운드 시드를 새로 생성한다.
- 각 전투 라운드는 새 시드로 별도 52장 덱을 생성해 한 번 셔플한다.
- 같은 전투 라운드 안에서는 카드가 중복되지 않으며, 서로 다른 전투 라운드에서는 같은 카드가 다시 등장할 수 있다.
- 첫 번째 공용 카드는 전투 라운드 시작 시 해당 라운드 덱에서 1장 공개한다.
- 카드 셔플, 개인 카드 무작위 획득과 두 번째 공용 카드 선정은 현재 전투 라운드 시드와 순차 난수 소비 규칙을 사용한다.
- 전투 라운드 진행 중에는 해당 라운드 덱을 재셔플하지 않는다.
- 미획득 풀은 카드 펼치기 저장소와 별도로 관리한다.
- 미획득 풀로 이동한 카드는 카드 펼치기 저장소에 다시 삽입하지 않는다.
- 카드 더미 초기화는 카드 펼치기 저장소의 다음 카드와 펼치기 방향을 변경하지 않는다.
- 획득 카드와 랜덤 보충 카드는 기존 저장소에서 제거해 중복 획득을 방지한다.
- 개인 카드 3장을 양측에 모두 배분한 뒤 남은 랜덤 획득 후보군에서 두 번째 공용 카드 1장을 선정한다.

## 6. 할리갈리 단계 시작

1. 플레이어와 AI의 할리갈리 라운드 승수를 0으로 초기화한다.
2. 플레이어와 AI의 획득 카드 풀을 비운다.
3. 미획득 풀을 준비한다.
4. 왼쪽과 오른쪽 카드 더미를 비운다.
5. 카드 펼치기 횟수를 0으로 초기화한다.
6. 플레이어와 AI의 첫 펼치기 방향을 각자 기준 왼쪽으로 지정한다.
7. 30초 카드 펼치기 제한 시간을 시작한다.
8. 양측이 각각 1장씩 펼칠 수 있도록 카드 펼치기 저장소에 2장 이상 남았는지 확인한다.

## 7. 카드 펼치기

### 입력

| 행동     | 마우스            | 키보드     |
| ------ | -------------- | ------- |
| 카드 펼치기 | 중앙 펼치기 영역 클릭   | `방향키 ↑` |
| 왼쪽 벨   | 왼쪽 더미 또는 벨 클릭  | `방향키 ←` |
| 오른쪽 벨  | 오른쪽 더미 또는 벨 클릭 | `방향키 →` |

### 카드 펼치기 1회 처리

```text
30초 제한 시간 시작
→ 플레이어가 W 또는 중앙 UI 입력
→ 플레이어 카드 1장 공개
→ AI 카드 1장 공개
→ 화면 좌우 카드 더미에 각각 카드 1장 적용
→ 각 더미의 최대 2장 노출 규칙 적용
→ 좌우 더미의 해골 합계 판정
→ 벨 가능 상태 또는 다음 카드 펼치기 대기
```

- 카드 펼치기 1회에는 반드시 플레이어 카드 1장과 AI 카드 1장, 총 2장이 필요하다.
- 저장소에 2장 미만이 남으면 한쪽만 카드를 펼치지 않고 할리갈리 단계를 종료한다.
- 각 전투 라운드는 첫 공용 카드 1장을 제외한 51장 중 최대 50장을 사용하므로 카드 펼치기 최대 횟수는 25회다.

### 방향 순서

홀수 번째 카드 펼치기:

- 플레이어: 본인 기준 왼쪽, 화면 왼쪽에 카드 1장
- AI: 본인 기준 왼쪽, 플레이어 화면 기준 오른쪽에 카드 1장

짝수 번째 카드 펼치기:

- 플레이어: 본인 기준 오른쪽, 화면 오른쪽에 카드 1장
- AI: 본인 기준 오른쪽, 플레이어 화면 기준 왼쪽에 카드 1장

카드 더미가 초기화되어도 홀수·짝수 횟수와 다음 방향은 변경하지 않는다.

### 카드 펼치기 제한 시간

- 카드 펼치기 시도 제한 시간은 30초다.
- 30초 안에 `방향키 ↑` 또는 중앙 UI 입력이 발생해야 한다.
- 현재 행동 주체가 30초 이상 카드 펼치기 상태에 머무르면 해당 할리갈리 라운드에서 패배한다.
- 시간 초과 승패 처리 후 다음 할리갈리 라운드를 기존 카드 펼치기 순서에서 계속한다.

## 8. 좌우 카드 더미 노출 규칙

- 왼쪽과 오른쪽 카드 더미는 서로 독립적으로 관리한다.
- 각 카드 더미에는 최대 2장만 노출한다.
- 세 번째 카드가 들어오면 가장 오래된 카드가 미획득 풀로 이동한다.
- 남은 카드와 새 카드가 해당 더미의 새로운 노출 카드 2장이 된다.

### 예시: `1 + 1` 이후 `2`

```text
노출 카드: 1 + 1
→ 합계 2이므로 획득 불가
→ 다음 카드 2가 같은 더미에 적용
→ 가장 오래된 1은 미획득 풀로 이동
→ 최근 1과 새 2가 노출
→ 1 + 2로 합계 3 충족
```

## 9. 합계 3과 벨 승부

- 화면에는 합계 숫자와 정답 카드 더미를 표시하지 않는다.
- 플레이어는 노출된 카드의 해골 수를 직접 보고 합계 3을 판단한다.
- 좌우 중 한쪽 또는 양쪽의 합계가 정확히 3이면 벨 승부가 가능하다.
- 조건에 맞지 않는 카드 더미에도 벨 입력은 가능하지만 오답으로 판정한다.

### 한쪽만 합계 3

```text
한쪽 카드 더미 합계 = 3
→ 플레이어와 AI 벨 판정
→ 먼저 올바른 카드 더미를 선택한 참가자가 할리갈리 라운드 승리
```

### 양쪽 모두 합계 3

```text
왼쪽 합계 = 3 그리고 오른쪽 합계 = 3
→ 플레이어와 AI 벨 판정
→ 플레이어 승리: 원하는 카드 더미 하나 선택
→ AI 승리: 현재 포커 승률에 더 유리한 카드를 포함한 더미 우선 선택
```

### 동시 입력

- 플레이어와 AI의 유효 벨 입력이 사실상 동시에 접수되면 플레이어를 승자로 판정한다.

### 오답 벨

- 합계 3이 아닌 카드 더미에 벨을 입력하면 오답이다.
- 오답 입력자는 해당 할리갈리 라운드에서 즉시 패배한다.
- 상대는 해당 할리갈리 라운드 승리 1회를 획득한다.
- 오답이 발생한 시점에 획득 가능한 합계 3 카드 더미가 있다면 승자가 해당 더미의 카드를 획득한다.
- 획득 가능한 카드 더미가 없다면 라운드 승수만 반영하고 카드 획득은 발생하지 않는다.

### AI 벨 놓침

- AI가 올바른 벨을 입력할 수 있는 상황에서도 30% 확률로 벨을 놓친다.
- AI가 벨을 놓치면 플레이어의 유효 입력 기회는 유지한다.
- 플레이어도 벨을 입력하지 않으면 다음 카드 펼치기 입력을 기다린다.

### 1스테이지 AI 난이도 기준

- 1스테이지에서는 별도의 난이도 가감 없이 본 문서의 AI 규칙을 그대로 적용한다.
- 올바른 벨 기회를 놓칠 확률은 30%다.
- 플레이어와 유효 벨 입력이 동시에 판정되면 플레이어를 우선한다.
- 좌우 카드 더미가 모두 획득 가능하면 현재 포커 패에 더 유리한 카드 더미를 선택한다.
- AI가 단계 승자이고 직접 선택 후보가 기준 수량을 초과하면 첫 번째 공용 카드와 획득 후보를 기준으로 유리한 카드를 선택한다.
- 별도의 AI 반응 시간 단축, 벨 정확도 증가 또는 카드 평가 보정은 1스테이지에 적용하지 않는다.

## 10. 카드 획득과 더미 초기화

### 기본 획득

| 노출 해골 | 획득 처리 |
|---|---|
| `1 + 2` | 두 카드 모두 획득 |
| `2 + 1` | 두 카드 모두 획득 |
| `3` | 해골 3 카드 한 장 획득 |
| `1 + 1` | 합계 2이므로 획득 불가 |

### 해골 3 예외

| 노출 해골 | 획득 처리 |
|---|---|
| `1 + 3` | 해골 3 카드만 획득, 해골 1 카드는 미획득 풀로 이동 |
| `3 + 1` | 해골 3 카드만 획득, 해골 1 카드는 미획득 풀로 이동 |
| `2 + 3` | 해골 3 카드만 획득, 해골 2 카드는 미획득 풀로 이동 |
| `3 + 2` | 해골 3 카드만 획득, 해골 2 카드는 미획득 풀로 이동 |

해골 3이 포함된 더미는 전체 합계가 3을 초과하더라도 해골 3 카드 한 장을 획득 가능한 카드로 판정한다.

### 초기화 범위

```text
왼쪽 카드 더미에서 획득
→ 왼쪽 카드 더미만 초기화
→ 왼쪽의 미획득 잔여 카드는 미획득 풀로 이동
→ 오른쪽 카드 더미는 현재 상태 유지
→ 다음 카드 펼치기 방향과 횟수는 기존 순서대로 진행
```

- 획득을 시도한 카드 더미만 초기화한다.
- 선택하지 않은 반대편 카드 더미는 초기화하지 않는다.
- 양쪽 모두 합계 3이더라도 승자가 선택한 한쪽만 초기화한다.

### AI 획득 카드 노출

- AI가 할리갈리 라운드에서 이기면 실제 획득한 카드만 이동 연출 중 일시적으로 공개한다.
- 획득 연출이 끝난 AI 카드는 다시 숨긴다.
- AI가 할리갈리 라운드에서 패배하면 AI 카드 획득 정보는 별도로 공개하지 않는다.

## 11. 획득 후 확인 유예

```text
할리갈리 라운드 승패와 카드 이동 처리 완료
→ 최대 15초 확인 유예
   ├─ W 또는 중앙 UI 입력: 즉시 다음 카드 펼치기
   └─ 15초 만료: 자동으로 다음 카드 펼치기 대기 상태
```

- 확인 유예 동안 첫 공용 카드, 자신의 획득 카드와 AI가 방금 획득한 카드 연출을 확인할 수 있다.
- 확인 유예는 카드 펼치기 30초 제한 시간과 별도로 처리한다.

## 12. 할리갈리 단계 종료

다음 중 하나를 만족하면 할리갈리 단계를 종료한다.

1. 현재 전투 라운드의 승리 목표 달성: 1번째 3승, 2번째 2승, 3번째 이후 1승
2. 카드 펼치기 25회 완료
3. 카드 펼치기 저장소에 2장 미만이 남아 양측이 한 장씩 펼칠 수 없는 상태
4. 그 밖에 정상적인 카드 펼치기를 진행할 수 없는 상태

단계 종료 시 왼쪽과 오른쪽 카드 더미에 남은 카드는 랜덤 획득 후보군에 포함한다.

## 13. 남은 카드 소진 및 랜덤 획득

### 랜덤 획득 후보군 1차 구성

할리갈리 단계가 종료되면 다음 저장소의 카드로 랜덤 획득 후보군을 구성한다.

1. 단계 패자가 할리갈리 중 획득한 카드
2. 미획득 풀
3. 왼쪽과 오른쪽 카드 더미에 남은 카드
4. 카드 펼치기 저장소에 남은 카드
5. 그 밖에 플레이어와 AI 어느 쪽도 최종 획득하지 않은 카드

- 단계 패자의 획득 카드는 개인 카드 선택권에 사용하지 않고 후보군으로 이동한다.
- 단계 승자의 획득 카드 풀은 1차 후보군과 분리한다.
- 단계 승자의 선택이 끝난 뒤 미선택 카드만 랜덤 획득 후보군에 추가한다.
- 두 번째 공용 카드는 이 시점에 공개하지 않는다.

### 전투 라운드별 개인 카드 배분

| 전투 라운드 | 단계 승자 직접 선택 | 단계 승자 무작위 획득 | 단계 패자 무작위 획득 |
|---:|---:|---:|---:|
| 1번째 | 3장 | 0장 | 3장 |
| 2번째 | 2장 | 1장 | 3장 |
| 3번째 이후 | 1장 | 2장 | 3장 |

- 단계 승자는 해당 전투 라운드에 정해진 수량만 자신의 획득 카드 풀에서 확정한다.
- 단계 승자의 개인 카드가 3장이 되도록 부족한 수량을 랜덤 획득 후보군에서 보충한다.
- 단계 패자는 할리갈리 중 획득한 카드와 관계없이 랜덤 획득 후보군에서 개인 카드 3장을 획득한다.
- 카드 펼치기 한도 또는 카드 부족으로 어느 쪽도 승리 목표를 달성하지 못하면 단계 승자 없이 종료하며 양측 모두 랜덤 획득 후보군에서 3장씩 획득한다.
- 랜덤으로 선택된 카드는 원래 저장소와 후보군에서 제거한다.
- 같은 카드를 양측이 중복 획득할 수 없다.
- 양측 개인 카드 3장을 모두 확정한 뒤 남은 후보군을 두 번째 공용 카드 선정에 사용한다.

## 14. 개인 카드 선택 및 무작위 보충

### 선택 단계 진입 조건

| 전투 라운드 | 승자의 직접 선택 수 | 선택 UI 진입 조건 | 선택 후 무작위 보충 수 |
|---:|---:|---|---:|
| 1번째 | 3장 | 획득 후보가 3장 초과 | 0장 |
| 2번째 | 2장 | 획득 후보가 2장 초과 | 1장 |
| 3번째 이후 | 1장 | 획득 후보가 1장 초과 | 2장 |

- 단계 승자의 획득 후보가 직접 선택 수를 초과할 때만 선택 UI에 진입한다.
- 획득 후보 수가 직접 선택 수와 같으면 해당 카드를 자동 확정하고 선택 UI를 건너뛴다.
- 단계 승자 없이 할리갈리 단계가 강제 종료되면 카드 선택 UI를 건너뛰고 양측 개인 카드 3장을 무작위 구성한다.
- 단계 패자는 카드 선택 UI를 건너뛴다.

### 입력

| 행동 | 키보드 | 마우스 |
|---|---|---|
| 이전 카드로 이동 | `Q` | 카드 위로 마우스 이동 |
| 다음 카드로 이동 | `E` | 카드 위로 마우스 이동 |
| 카드 선택·해제 | `W` | 카드 클릭 |
| 선택 확정 | 선택 버튼 | 선택 버튼 클릭 |

### 선택 규칙

- 카드 위에 마우스를 올리거나 `Q`, `E`로 이동하면 해당 카드를 하이라이트한다.
- `W` 또는 마우스 클릭으로 카드를 선택한다.
- 이미 선택한 카드를 다시 선택하면 선택을 해제한다.
- 선택 카드가 해당 전투 라운드의 직접 선택 수보다 적으면 선택 버튼을 비활성화한다.
- 선택 카드가 직접 선택 수와 같으면 선택 버튼을 활성화한다.
- 선택 가능한 최대 카드 수는 해당 전투 라운드의 직접 선택 수와 같다.
- 선택 단계 제한 시간은 최대 1분이다.
- AI가 단계 승자이면 첫 번째 공용 카드와 자신의 획득 카드 후보를 기준으로 가장 유리한 필수 수량을 선택한다.
- 선택 확정 후 미선택 획득 후보 카드는 랜덤 획득 후보군으로 이동한다.
- 승자의 개인 카드가 3장이 되도록 해당 전투 라운드의 무작위 보충 수만큼 후보군에서 획득한다.
- 패자는 랜덤 획득 후보군에서 3장을 획득한다.

### 선택 시간 초과

- 1분 안에 선택을 확정하지 못하면 현재 선택한 카드는 유지한다.
- 선택하지 않은 획득 카드 후보는 랜덤 획득 후보군으로 이동한다.
- 현재 선택 수와 관계없이 개인 카드가 3장이 될 때까지 랜덤 획득 후보군에서 무작위 획득한다.
- 무작위 획득은 현재 전투 라운드 시드와 난수 소비 순번을 사용한다.

## 15. 포커 단계 진입, 두 번째 공용 카드와 아이템

### 두 번째 공용 카드 공개

- 양측 개인 카드 3장 배분을 완료한 뒤 포커 단계에 진입한다.
- 포커 단계 진입 직후 남은 랜덤 획득 후보군에서 두 번째 공용 카드 1장을 무작위 선정한다.
- 특정 마지막 카드나 덱 위치를 공용 카드로 미리 예약하지 않는다.
- 선정에는 현재 전투 라운드 시드와 난수 소비 순번을 사용한다.
- 선정된 카드는 후보군에서 제거한 뒤 공개하며 다시 획득할 수 없다.

```text
양측 개인 카드 3장 확정
→ 포커 단계 진입
→ 남은 랜덤 획득 후보군에서 두 번째 공용 카드 공개
→ 개인 카드 3장 + 공용 카드 2장 확인
→ 아이템 보유 여부 확인
   ├─ 사용 가능한 아이템 있음: 아이템 사용 또는 건너뛰기
   └─ 사용 가능한 아이템 없음: 별도 입력 없이 아이템 단계 자동 건너뛰기
→ 패 확정
```

- 아이템은 패 확정 전에만 사용할 수 있다.
- 패 확정 이후에는 카드 선택과 아이템 결과를 변경할 수 없다.
- 아이템이 없을 때는 사용할 수 없는 선택 UI를 요구하지 않고 자동으로 다음 단계로 이동한다.

## 16. 승패 예측, 포커 비교와 예측 보상

```text
패 확정
→ 내가 이긴다 / 내가 진다 선택
→ AI 개인 카드 공개
→ 양측 5장 포커 족보 비교
→ 실제 포커 결과 판정
→ 예측 성공·실패 판정
```

- 승패 예측은 현재 전투 라운드의 포커 승패 결과를 대상으로 한다.
- 포커 패자는 HP 1을 잃는다.
- 예측 성공 시 `아이템` 또는 `스테이지 종료 시 코인 증가` 중 하나를 무작위로 보상 후보에 누적한다.
- 코인 증가가 여러 번 선정되면 증가 수치를 합산한다.
- 예측 실패 시 해당 전투 라운드의 예측 보상을 새로 획득하지 못한다.
- 예측 실패가 발생해도 이전 전투 라운드에서 누적한 코인 증가 수치와 보상 후보는 유지한다.
- 승패 예측 결과는 현재 전투 라운드의 HP와 피해량을 변경하지 않는다.
- 동일 족보는 포커 랭크 비교 후 문양 우선순위를 적용한다.
- 완전 동률은 문양 우선순위까지 적용하면 발생하지 않는 것으로 가정한다.
- 문양의 정확한 우선순위와 A 스트레이트 인정 범위는 추가 확정이 필요하다.

## 17. HP, 코인과 전투 종료

### HP

- 전투 시작 시 플레이어와 AI HP는 모두 3이다.
- 포커 패배 시 기본 피해량은 1이다.
- 양측 HP가 남아 있으면 현재 전투 라운드를 종료하고 새 시드를 생성한 뒤 다음 전투 라운드의 할리갈리 단계로 진행한다.
- 어느 한쪽의 HP가 0이 되면 스테이지를 종료한다.

### 플레이어 승리와 코인

- AI HP가 0이 되면 플레이어 승리로 처리한다.
- 코인은 가칭이며 포커 승리마다 지급하지 않고 스테이지 승리 시 한 번 정산한다.
- 기본 코인 획득량은 스테이지 승리 시 플레이어의 잔여 HP와 같다.
- 예측 성공으로 누적한 코인 증가 수치를 기본 코인에 합산한다.
- `최종 코인 = 플레이어 잔여 HP + 누적 코인 증가 수치`로 계산한다.
- 예측 성공으로 누적한 아이템 보상도 스테이지 승리 정산에 반영한다.
- 코인 증가 1회당 정확한 증가 수치와 아이템 보상 목록은 후속 확정한다.

### 전투 종료

```text
AI HP가 0
→ 플레이어 승리
→ 플레이어 잔여 HP만큼 기본 코인 계산
→ 누적 코인 증가 수치 합산
→ 예측 성공 아이템 보상 반영
→ 다음 스테이지 이동

플레이어 HP가 0
→ 플레이어 패배
→ 스테이지 종료
→ 게임 초기화 및 메인 화면 이동
```
