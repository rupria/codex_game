# 아이템 기획 및 밸런스 초안

## 1. 문서 목적

포커 라운드의 최종 패 확정 전에 사용할 아이템의 방향을 정리한다.

`재장전`, `밑장빼기`, `바람잡이` 3종과 가격 1·2·2, 인벤토리 4칸, 동일 ID 1개, 구매 횟수 무제한은 `게임진행플로우_0.1.2.2`에서 확정한다. 이 문서의 나머지 후순위 아이템과 수치는 논의용이며 최신 명세와 충돌하면 적용하지 않는다.

## 2. 기존 확정 기준

- 아이템은 두 번째 공용 카드 공개 이후, 승패 예측과 패 확정 전에 사용할 수 있다.
- 모든 아이템 및 카드 변경 처리가 끝난 뒤 승패를 한 번만 예측한다.
- 아이템 사용으로 카드가 변경되어도 재예측하지 않으며 예측 제한 시간 2분은 초기화하지 않는다.
- 사용할 수 있는 아이템이 없으면 아이템 선택 단계를 자동으로 건너뛴다.
- 승패 예측은 전투 피해가 아닌 보상에 영향을 준다.
- 스테이지 승리 보상은 총알이며, 바 상점에서 아이템 및 회복 구매 수단으로 사용하는 방향이다.
- 사용하지 않은 총알은 스테이지가 바뀌어도 유지되며 캐릭터가 사망할 때 0으로 초기화된다.
- 현재 바 상점의 6종 상품 풀, 3개 진열, 무료 새로고침 1회는 임시 UI 기준이다. 실제 구매·소모·효과 규칙은 확정되지 않았다.

## 3. 설계 목표

1. 할리갈리 단계에서 획득한 카드의 가치를 완전히 무효화하지 않는다.
2. 포커 패를 확정하기 전 짧고 명확한 선택을 제공한다.
3. 효과 한 번에 결과 하나가 보이도록 하여 학습 부담을 줄인다.
4. 단순한 피해 증가보다 카드 조정과 정보 획득을 우선한다.
5. 아이템 하나만으로 승패가 확정되는 효과는 피한다.
6. 무작위 효과에는 사용 전 위험과 가능한 결과를 안내한다.

### 4.1 1차 프로토타입 권장 범위

- `재장전`, `속임수 드로우`, `엿보기` 3종만 우선 검증한다.
- 피해, HP, 보상 수치를 직접 변경하는 아이템은 기본 플레이 템포가 안정된 뒤 검토한다.
- 카드 생성보다 52장 공유 덱 안에서의 이동과 정보 공개를 우선한다.

## 5. 아이템 사용 흐름 제안

1. 개인 카드 보충을 완료한다.
2. 포커 단계에 진입한다.
3. 두 번째 공용 카드를 공개한다.
4. 보유 아이템 목록을 표시한다.
5. 사용할 아이템과 대상을 선택한다.
6. 효과와 소모 여부를 확인한다.
7. 아이템 효과를 적용한다.
8. 패를 확정한다.
9. 제한 시간 안에 승패를 예측한다.
10. AI 카드를 공개하고 족보를 비교한다.

취소한 아이템은 소모하지 않는다. 패를 확정하거나 승패 예측 단계에 진입한 뒤에는 아이템을 사용할 수 없다.

## 6. 카드 교환 공통 처리 제안

- 교환으로 버린 개인 카드는 미획득 카드 풀로 이동한다.
- 새 카드는 미획득 카드 풀에서 제거하여 플레이어 개인 카드로 이동한다.
- 미획득 카드 풀이 비어 있으면 카드 교환 아이템을 비활성화한다.
- 무작위 추첨은 해당 포커 라운드의 시드를 사용하여 재현 가능하게 처리한다.
- 후보 2장 중 선택하지 않은 카드는 미획득 카드 풀에 유지한다.
- 아이템 사용 전후에도 전체 카드의 고유성과 총 52장 상태를 유지한다.

## 7. 임시 보유·사용 제한 제안

다음 값은 플레이테스트를 시작하기 위한 제안이며 확정값이 아니다.

- 인벤토리 최대 3칸
- 기본 포커 라운드에는 아이템 사용 개수 제한 없음
- 보유한 사용 가능 아이템은 승패 예측 전까지 연속 사용 가능
- 모든 아이템은 1회용
- AI는 모든 스테이지에서 아이템을 사용하지 않음
- 사용하지 않은 아이템은 인벤토리 4칸과 동일 ID 1개 제한 안에서 현재 런의 다음 스테이지로 이월
- 기본 재화는 캐릭터 사망 전까지 누적되고 일회성 재화는 직후 상점에서 우선 사용한 뒤 이탈 시 소멸
- 1차 아이템 가격 1·2·2와 체력 회복 가격 1을 유지한다. 회복은 HP 1, 최대 HP는 3이다.

아이템 사용 제한 패널티가 발동하지 않은 스테이지에는 기본 사용 개수 제한을 두지 않는다. 패널티가 발동한 스테이지만 0.1.2.4의 스테이지 전체 총사용 한도를 적용한다. 모든 아이템 처리가 끝난 최종 카드 상태에서 승패 예측을 한 번 진행한다.

### 7.1 승리 예측 성공 보상

- 예측 성공 횟수는 현재 스테이지에서 최대 5회까지 집계한다.
- 예측 실패·2분 무반응은 성공 횟수를 늘리지 않고 일회성 재화를 지급하지 않는다.
- 스테이지 승리 시 예측 성공 결과에 따른 일회성 재화를 지급한다.
- 일회성 재화는 직후 상점에서 기본 재화보다 먼저 사용하고 상점 이탈 시 소멸한다.
- 예측 성공 0~5회별 일회성 재화는 0·1·1·2·2·3개를 지급한다.
- 기본·일회성 재화는 서로 다른 아이콘과 숫자로 표시하고 인게임에 재화 명칭을 노출하지 않는다.

### 7.2 스테이지 아이템 사용 제한 패널티

- 1스테이지에는 적용하지 않는다.
- 2·3스테이지 입장 시 같은 진행에서 패널티가 아직 발동하지 않았다면 스테이지마다 한 번 20% 확률로 발동 여부를 결정한다.
- 발동 시 해당 스테이지 전체 아이템 총사용 한도를 1개 또는 2개 중 무작위로 선정해 공개한다.
- 사용 횟수는 모든 Showdown에서 누적하며 한도 소진 후 스테이지 종료까지 추가 사용을 막는다.
- 한 진행에서 한 번 발동하면 이후 스테이지에서는 다시 등장하지 않는다. 2스테이지 미발동 시에만 3스테이지에서 다시 추첨한다.

## 8. UI 정보 기준

아이템마다 다음 정보를 표시한다.

- 아이템 이름과 아이콘
- 한 문장 효과 설명
- 대상 선택 필요 여부
- 무작위 효과 여부
- 사용 가능 또는 비활성 상태
- 비활성 상태일 경우 간단한 사유
- 사용 확인 및 취소 버튼

공개 화면에는 `미확정`, `개발 중` 같은 내부 문구를 표시하지 않는다. 아직 구현하지 않은 상품은 실제 상품처럼 노출하지 않거나 테스트용 데이터임을 개발 환경에서만 구분한다.

## 9. 플레이테스트 확인 항목

- 아이템 선택부터 효과 이해까지 걸리는 시간
- 카드 획득 선택의 가치가 아이템 때문에 약해지는지
- `엿보기` 사용 후 승패 예측 성공률 변화
- `재장전`과 `속임수 드로우`의 사용률 및 패 개선율
- 아이템 사용으로 포커 단계가 지나치게 길어지는지
- 상점에서 아이템과 HP 회복 중 무엇을 우선 구매하는지
- 사용하지 않고 보유만 하는 플레이가 과도하게 유리한지
- 패널티 총사용 한도 1개와 2개의 난이도·아이템 보존 체감 차이
- 여러 Showdown에서 사용 횟수 누적과 한도 소진 상태가 명확히 전달되는지

## 11. 우선 논의 권장안

다음 세 가지를 먼저 결정하면 아이템 프로토타입 범위를 빠르게 고정할 수 있다.

1. 최초 아이템을 `재장전`, `속임수 드로우`, `엿보기` 3종으로 제한할지
2. 인벤토리를 최대 3칸으로 둘지
3. 사용하지 않은 아이템을 다음 스테이지로 가져갈 수 있게 할지
