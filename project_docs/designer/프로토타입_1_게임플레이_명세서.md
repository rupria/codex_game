## 1. 한 문장 피치

플레이어가 좌우 카드 더미를 직접 펼치며 해골 합계 3을 먼저 찾아 원하는 포커 카드를 확보하고, 개인 카드 3장과 공용 카드 2장으로 완성한 족보에 아이템을 사용해 AI의 HP를 먼저 소진시키는 카드 대전 게임이다.

## 2. 기획 목표

- `Q-W-E` 또는 마우스만으로 카드 펼치기와 좌우 벨 선택을 수행한다.
- 할리갈리 단계의 관찰·반응 행동이 포커 단계의 카드 구성으로 직접 연결된다.
- 합계를 자동 표시하지 않고 플레이어가 카드 더미를 직접 판독한다.
- 할리갈리 승자는 획득 카드 선택권을, 패자는 무작위 보충의 위험을 가진다.
- 마지막 공용 카드와 아이템 사용이 포커 패 확정 직전의 반전을 만든다.
- 처음 보는 플레이어가 외부 설명 없이 첫 라운드를 완주할 수 있다.

## 3. 핵심 용어

| 용어 | 정의 |
|---|---|
| 공용 카드 | 플레이어와 AI가 함께 사용하는 카드. 처음과 마지막에 1장씩 공개한다. |
| 판정 카드 | 좌우 더미에서 현재 해골 합계 판정에 포함되는 공개 카드다. |
| 획득 카드 | 벨 경쟁 결과로 가져와 개인 카드 후보가 된 포커 카드다. |
| 개인 카드 | 획득 후보 중 최종 확정한 3장이다. 부족하면 무작위 보충한다. |
| 벨 승리 | 조건을 충족한 더미를 AI보다 먼저 올바르게 선택한 결과다. |
| 패 확정 | 아이템 사용을 끝내고 현재 카드 구성을 변경 불가 상태로 만드는 입력이다. |

## 4. 라운드 전체 흐름

```text
첫 번째 공용 카드 1장 공개
→ 할리갈리 단계 시작
→ 플레이어가 좌우에 카드를 번갈아 펼침
→ 해골 합계 3 판독 및 AI와 벨 경쟁
→ 먼저 3승한 쪽이 할리갈리 단계 승리
→ 양측 개인 카드 3장 정리
→ 패자의 부족한 개인 카드 무작위 보충
→ 마지막 공용 카드 1장 공개
→ 최종 카드 5장 확인
→ 아이템 사용 또는 건너뛰기
→ 포커 패 최종 확정
→ 승패 예측
→ AI 카드 공개 및 족보 비교
→ 패자 HP 감소
→ 다음 라운드 또는 전투 종료
```

## 5. 최종 카드 구성

| 카드 구분 | 플레이어 | AI | 공개 시점 |
|---|---:|---:|---|
| 첫 번째 공용 카드 | 1장 | 1장 | 라운드 시작 |
| 개인 카드 | 3장 | 3장 | 플레이어 카드는 항상 공개, AI 카드는 쇼다운 때 공개 |
| 마지막 공용 카드 | 1장 | 1장 | 할리갈리 단계 종료 후 |
| 최종 족보 | 총 5장 | 총 5장 | 패 확정 이후 |

개인 카드 3장과 공용 카드 2장을 모두 사용한다. 7장 중 최적의 5장을 다시 고르는 규칙은 사용하지 않는다.

## 6. 할리갈리 단계

### 6.1 시작

1. 첫 번째 공용 카드 1장을 공개한다.
2. 플레이어와 AI의 벨 승리 수를 0으로 초기화한다.
3. 중앙 카드 펼치기 UI와 좌우 카드 더미를 활성화한다.
4. 다음 카드가 놓일 방향은 왼쪽부터 시작한다.

### 6.2 카드 펼치기

- 플레이어가 중앙 UI를 클릭하거나 `W`를 누르면 카드 1장을 펼친다.
- 카드는 플레이어 시점 기준 `왼쪽 → 오른쪽 → 왼쪽 → 오른쪽` 순서로 자동 배치한다.
- 카드 공개 애니메이션이 끝나기 전에는 다음 펼치기와 벨 입력을 받지 않는다.
- 다음 카드를 펼칠 방향은 화살표나 약한 빛으로 안내할 수 있다.
- 플레이어가 다음 펼치기 입력을 하기 전까지 게임은 자동 진행하지 않는다.

### 6.3 해골 합계 판정

- 각 더미에서 현재 판정 대상으로 공개된 카드의 해골 수 합을 계산한다.
- 합계가 정확히 3인 더미만 정답이다.
- 합계는 시스템 내부에서 계산하고 화면에 숫자로 노출하지 않는다.
- 정답 더미 강조, 선택 가능 표시와 벨 선활성화도 사용하지 않는다.
- 판정에 포함되는 카드는 시각적으로 가리지 않으며, 가려져 판정에서 제외된 카드는 합산하거나 획득하지 않는다.

### 6.4 좌우 선택과 벨 경쟁

| 상황 | 처리 |
|---|---|
| 왼쪽만 합계 3 | 플레이어와 AI가 왼쪽 더미를 두고 경쟁한다. |
| 오른쪽만 합계 3 | 플레이어와 AI가 오른쪽 더미를 두고 경쟁한다. |
| 양쪽 모두 합계 3 | 먼저 올바른 입력을 한 쪽이 원하는 더미 하나를 선택한다. |
| 양쪽 모두 정답 아님 | 벨 승리 없이 다음 카드 펼치기 상태로 돌아간다. |

- 벨 승자는 선택한 더미에서 합계 3을 구성한 판정 카드를 모두 획득한다.
- 양쪽 모두 정답이어도 한쪽 더미만 획득하며 선택하지 않은 더미는 버린다.
- 획득한 카드는 해당 참가자의 개인 카드 후보 영역으로 이동한다.
- AI의 획득 카드는 이동 연출 동안 앞면으로 보여주고 다음 카드 펼치기 전까지 확인 시간을 준다.

### 6.5 AI 반응 원칙

- AI 반응 시간은 카드 공개 애니메이션이 완전히 끝난 뒤부터 계산한다.
- AI는 고정된 즉시 입력이 아니라 난이도별 기본 시간, 무작위 편차와 선택 판단 시간을 사용한다.
- 양쪽 모두 정답이면 AI는 자신의 포커 조합에 더 유리한 더미를 우선하되 항상 최적 선택만 하지는 않는다.
- 난이도별 반응 시간, 오답률과 카드 평가 가중치는 플레이테스트 후 확정한다.

### 6.6 할리갈리 단계 종료

- 먼저 벨 승리 3회를 달성한 쪽이 할리갈리 단계 승자다.
- 한 번의 벨 승리로 최소 1장을 획득하므로 승자는 최소 3장의 카드 후보를 가진다.
- 3승을 달성한 즉시 할리갈리 단계를 종료하며 추가 라운드는 진행하지 않는다.

## 7. 개인 카드 정리

할리갈리 단계가 끝난 뒤 각 참가자의 개인 카드를 정확히 3장으로 맞춘다.

| 획득 후보 수 | 처리 |
|---:|---|
| 4장 이상 | 원하는 카드 3장을 선택하고 나머지를 버린다. |
| 3장 | 그대로 개인 카드로 확정한다. |
| 2장 | 무작위 카드 1장을 보충한다. |
| 1장 | 무작위 카드 2장을 보충한다. |
| 0장 | 무작위 카드 3장을 보충한다. |

- 할리갈리 단계의 승패와 관계없이 4장 이상 가진 참가자는 원하는 3장을 선택할 수 있다.
- 무작위 보충 카드는 아직 사용하지 않은 포커 덱에서 뽑는다.
- AI의 개인 카드 3장은 정리가 끝나면 뒷면으로 표시한다.

## 8. 포커 및 아이템 단계

### 8.1 마지막 공용 카드 공개

- 양측 개인 카드가 3장으로 확정되면 마지막 공용 카드 1장을 공개한다.
- 플레이어는 개인 카드 3장과 공용 카드 2장, 총 5장을 확인한다.
- 이 시점의 패는 임시 상태이며 아직 최종 확정되지 않았다.

### 8.2 아이템 사용

- 아이템은 마지막 공용 카드 공개 후, `패 확정` 입력 전에만 사용할 수 있다.
- 플레이어는 아이템을 사용하거나 사용하지 않고 현재 패를 확정할 수 있다.
- 아이템 효과 처리가 끝나면 변경된 카드 상태를 다시 확인한다.
- `패 확정` 이후에는 아이템 사용, 카드 교체와 선택 변경이 불가능하다.
- 초기 프로토타입의 아이템 종류, 보유 수량, 라운드당 사용 한도와 AI 사용 규칙은 미확정이다.

### 8.3 족보 정보

- 아이템 사용 단계에는 카드 5장을 표시한다.
- 족보 이름의 사전 노출 여부는 플레이테스트로 확정한다.
- 패 확정 후에는 양측 족보 이름과 비교 결과를 명확하게 표시한다.
- 초기 카드 덱은 표준 52장 `A, 2~10, J, Q, K`와 네 무늬를 기준으로 하며 조커는 제외한다.

### 8.4 승패 예측과 쇼다운

1. 플레이어가 `내가 이긴다` 또는 `내가 진다`를 선택한다.
2. AI의 개인 카드 3장을 공개한다.
3. 양측의 5장 포커 족보를 비교한다.
4. 실제 승패와 플레이어 예측 결과를 각각 표시한다.
5. 포커 패자에게 HP 피해를 적용한다.

## 9. HP와 전투 반복

- 포커 승패 결과로 패자의 HP가 감소한다.
- HP가 남아 있으면 다음 라운드를 시작한다.
- 어느 한쪽의 HP가 0이 되면 전투를 종료한다.
- 시작 HP, 기본 피해량, 동률 처리, 예측 성공 보상과 아이템 피해 변경은 미확정이다.
- 코어 루프 검증 전에는 족보 등급별 피해 증가와 복잡한 상태 이상을 추가하지 않는다.

## 10. 조작 명세

| 행동 | 마우스 | 키보드 |
|---|---|---|
| 다음 카드 펼치기 | 중앙 카드/UI 클릭 | `W` |
| 왼쪽 더미 벨 | 왼쪽 카드 더미 또는 벨 클릭 | `Q` |
| 오른쪽 더미 벨 | 오른쪽 카드 더미 또는 벨 클릭 | `E` |
| 카드 정리 | 대상 카드 클릭 | 방향 입력 방식 미확정 |
| 아이템 사용 | 아이템 클릭 | 키보드 방식 미확정 |
| 포커 패 확정 | 확정 버튼 클릭 | 키보드 방식 미확정 |

```text
[왼쪽 더미]       [카드 펼치기]       [오른쪽 더미]
     Q                  W                    E
```

- 펼치기 상태에서는 중앙 클릭과 `W`만 유효하다.
- 판정 상태에서는 좌우 클릭과 `Q`, `E`만 유효하다.
- 카드 공개 전에 입력한 벨은 예약하지 않는다.
- `Q`와 `E` 동시 입력은 먼저 수신한 한 건만 판정한다.
- 키를 누르고 있는 상태가 아니라 새로 누른 순간만 입력으로 처리한다.

## 12. 획득 후 재개 타이밍

- 벨 판정과 카드 이동 연출 동안 입력을 잠근다.
- 획득 카드 확인을 위한 최소 연출 시간은 약 1초를 임시 기준으로 한다.
- 연출 종료 후 중앙에 `W 또는 중앙 카드를 눌러 다음 카드 펼치기`를 표시한다.
- 플레이어가 입력할 때까지 자동으로 다음 카드를 펼치지 않는다.
- 이 대기 시간에 첫 공용 카드, 자신의 카드 후보와 AI가 방금 가져간 카드를 확인할 수 있다.

## 13. 정보 노출 우선순위

### 항상 표시

- 첫 번째 공용 카드
- 플레이어 카드 후보와 획득 장수
- 플레이어와 AI의 벨 승리 수
- 현재 HP

### 할리갈리 단계에 표시

- 좌우 판정 카드 더미
- 다음 카드 펼치기 UI
- 좌우 벨과 `Q-W-E` 조작 안내

### 표시하지 않음

- 현재 해골 합계 숫자
- 정답 더미 자동 강조
- 정답 벨의 활성·비활성 차이
- AI의 남은 반응 시간

## 14. 첫 30초 경험

1. 공개 링크 진입 직후 게임 목표와 `W로 펼치기, Q/E로 벨`을 확인한다.
2. 첫 번째 공용 카드가 열린다.
3. 첫 필드는 AI가 즉시 행동하지 않고 플레이어가 카드 펼치기를 경험한다.
4. 플레이어는 카드 더미를 직접 보고 해골 합계 3인 쪽을 선택한다.
5. 정답 벨과 카드 획득 연출로 행동 결과를 이해한다.
6. 다음 펼치기는 플레이어의 입력을 기다린다는 것을 확인한다.

## 15. 3분 감정 곡선

- 초반: 카드 펼치기와 합계 3 판독을 이해하는 작은 성공
- 중반: AI보다 먼저 벨을 누르고 필요한 포커 카드를 가져가는 긴장
- 전환: 획득 후보에서 개인 카드 3장을 정리하는 계획
- 후반: 마지막 공용 카드와 아이템으로 패가 바뀌는 반전
- 결말: AI 쇼다운, 예측 결과와 HP 피해 확인

## 16. 성공·실패·종료

- 할리갈리 성공: 먼저 올바른 더미를 선택해 벨 승리 1회를 얻는다.
- 할리갈리 단계 승리: 먼저 벨 승리 3회를 달성한다.
- 포커 라운드 승리: 최종 5장 족보가 상대보다 높다.
- 예측 성공: 실제 승패와 플레이어 예측이 일치한다.
- 전투 승리: 상대 HP가 0이 된다.
- 전투 패배: 플레이어 HP가 0이 된다.
- 결과 화면에서 새 게임 또는 다음 라운드 진입이 가능해야 한다.

## 17. 초기 포함 범위

## 20. 기획 수용 기준

- [ ] 공개 HTTPS 링크에서 설치·로그인·초대·별도 승인 없이 첫 화면에 진입한다.
- [ ] 첫 화면 또는 즉시 확인 가능한 위치에서 목표, 실행 방법과 `Q-W-E` 조작을 확인한다.
- [ ] 플레이어가 중앙 클릭 또는 `W`로 좌우에 카드를 번갈아 펼칠 수 있다.
- [ ] 합계 숫자와 정답 강조 없이 카드만 보고 합계 3을 판정할 수 있다.
- [ ] 마우스 클릭과 `Q`, `E` 입력이 동일한 좌우 벨 결과를 만든다.
- [ ] AI 반응은 카드 공개가 끝난 후 시작한다.
- [ ] 먼저 벨 3승한 쪽이 할리갈리 단계를 승리한다.
- [ ] 양측이 선택 또는 무작위 보충으로 개인 카드 3장을 완성한다.
- [ ] 마지막 공용 카드 공개 후, 패 확정 전 아이템을 사용하거나 건너뛸 수 있다.
- [ ] 패 확정 후에는 카드와 아이템 상태를 변경할 수 없다.
- [ ] 개인 카드 3장과 공용 카드 2장으로 5장 족보를 일관되게 판정한다.
- [ ] 포커 패자의 HP가 감소하고 HP 0에서 전투가 종료된다.
- [ ] 외부 설명 없이 첫 라운드를 완주하고 다시 시작할 수 있다.
