# 00 Rules

> **역할:** AI와 사람이 작업할 때 항상 지켜야 하는 응답 규칙, 작업 원칙과 개인 선호를 관리한다.

상위 문서: [[../README|Rules]]

## 이곳에 넣는 것

- 모든 프로젝트에 공통으로 적용되는 작업 원칙
- 답변 형식, 언어, 상세도와 커뮤니케이션 선호
- 파일명, 폴더와 문서 작성 규칙
- 보안, 개인정보, 라이선스와 품질 기준
- 규칙의 적용 범위와 우선순위

## 넣지 않는 것

- 특정 프로젝트에만 적용되는 요구사항 → [[../../core/10_Projects/10_Projects|10 Projects]]
- 한 번의 작업에만 쓰는 임시 지시
- 검증되지 않은 팁이나 참고 지식 → [[../../core/20_Knowledge/20_Knowledge|20 Knowledge]]

## 사용 시점

- 새 프로젝트를 시작하기 전
- Codex에 반복 적용할 지침을 정할 때
- 작업 방식이 일관되지 않아 기준을 명문화할 때

## 권장 문서 형식

```markdown
# 규칙 이름
- 목적:
- 적용 범위:
- 반드시 할 것:
- 하지 않을 것:
- 예외:
- 마지막 검토일:
```
