## 1. 개선 배경

현재 화면에 대해 `이게 게임이 되고 있는 건가요?`라는 피드백이 있었다. 규칙 설명을 늘리는 것보다 현재 단계, 입력 대상, 카드 획득 결과와 다음 단계로의 전환을 화면에서 즉시 이해할 수 있게 개선한다.

## 2. 화면 방향

- 어두운 픽셀 아트 테이블과 3/4 탑다운 구도를 사용한다.
- 플레이어 영역은 청록색, AI 영역은 붉은색으로 구분한다.
- 상단 중앙에는 첫 번째 커뮤니티 카드와 잠긴 두 번째 커뮤니티 카드 슬롯을 둔다.
- 좌측 중앙에는 플레이어 필드 카드, 우측 중앙에는 AI 필드 카드를 둔다.
- 상단 좌우에는 각 진영의 HP와 현재 할리갈리 승수를 표시한다.
- 하단에는 플레이어 획득 카드·아이템과 AI 획득 상태를 구분해 표시한다.
- 색상만으로 진영을 구분하지 않고 외곽선, 위치와 아이콘도 함께 사용한다.

## 3. 중앙 벨과 마우스 조작

- 기존처럼 벨을 테이블 좌우 끝에 배치하지 않는다.
- 마우스 이동 거리를 줄이기 위해 두 벨을 테이블 중앙에 나란히 배치한다.
- 왼쪽 청록 벨은 왼쪽 필드 카드 판정, 오른쪽 붉은 벨은 오른쪽 필드 카드 판정에 대응한다.
- 두 벨은 각각 대응하는 필드 카드 아래에 정렬한다.
- 카드 펼치기 버튼 또는 카드 더미는 두 벨 아래 중앙에 분리 배치한다.
- 벨 사이와 펼치기 버튼 사이에 충분한 간격을 두어 오조작을 방지한다.
- 실제 클릭 영역은 표시된 벨보다 약간 크게 설정하되 서로 겹치지 않게 한다.
- 마우스 오버, 누름, 정답과 오답 상태를 외곽선·밝기·짧은 애니메이션으로 구분한다.
- 키보드는 `Q = 왼쪽 벨`, `W = 카드 펼치기`, `E = 오른쪽 벨`을 유지한다.

```text
       첫 커뮤니티 카드 / 잠긴 카드

 플레이어 필드 카드       AI 필드 카드
          [청록 벨] [붉은 벨]
               [카드 펼치기]
```

## 4. 획득 카드 UI

- 플레이어가 획득한 후보 카드는 좌측 하단 전용 트레이에 최대 3장까지 계속 노출한다.
- 벨 판정 후 획득 카드가 필드에서 트레이로 이동하는 애니메이션을 사용한다.
- 단순한 `카드 획득` 문구만 표시하지 않는다.
- AI 획득 카드는 판정 직후 앞면을 잠시 보여준 뒤 우측 하단에 뒷면과 장수로 정리한다.
- 플레이어는 현재 획득 결과와 포커 단계에서 사용할 카드 후보를 항상 확인할 수 있어야 한다.

## 5. 카드 한 장씩 펼치기

- 카드 2장을 동시에 보여주지 않고 한 장씩 순서대로 공개한다.
- `W` 또는 마우스 펼치기 입력 1회에 다음 순서로 실제 카드 4장을 배분한다.

```text
1. 플레이어 본인 기준 왼쪽
2. AI 본인 기준 왼쪽
3. 플레이어 본인 기준 오른쪽
4. AI 본인 기준 오른쪽
→ 네 번째 카드 공개 완료 후 벨 조건 판정
```

- 카드 1장은 `0.18~0.22초` 동안 이동·앞면 전환하고 다음 카드까지 `0.06~0.10초` 간격을 둔다.
- 4장 전체 배분은 `0.9~1.2초` 안에 완료한다.
- 순차 공개 중에는 추가 `W`와 `Q/E` 입력을 잠근다.
- AI 반응 시간은 네 번째 카드 공개 완료부터 시작한다.
- 사용자 요청의 마지막 `AI 본인 기준 왼쪽`은 좌우 교대와 대칭 구성을 위해 `AI 본인 기준 오른쪽`으로 정리한다.
- 직전 승자는 다음 4장 배분을 플레이어 입력 대기 또는 AI 자동 진행으로 시작하지만 네 카드 슬롯 공개 순서는 바뀌지 않는다.
- 첫 공용 카드 1장을 제외하면 최대 12회 배분할 수 있으며, 12회 완료 또는 카드가 4장 미만이면 기존 무승자 종료 흐름으로 진행한다.

## 6. 단계 전환 연출

1. 시작 후 딜러가 첫 번째 커뮤니티 카드 한 장을 펼친다.
2. 카드가 잠시 확대된 뒤 상단 중앙 커뮤니티 카드 슬롯에 고정된다.
3. 카메라가 필드 카드와 중앙 벨 영역으로 줌인하며 할리갈리 단계로 진입한다.
4. 할리갈리 종료 시 필드 카드와 벨 UI가 정리되며 테이블이 줌아웃된다.
5. 획득 카드가 포커 손패 위치로 재배치되고 포커 라운드 UI가 나타난다.

- 자유 카메라는 사용하지 않는다.
- `할리갈리 클로즈업`과 `포커 와이드` 두 고정 구도 사이를 전환한다.
- 첫 시작부터 할리갈리 조작 가능 상태까지의 연출은 3초 이내를 목표로 한다.

## 7. 시작 화면과 가이드

- 최초 실행 화면의 조작 버튼은 `START`와 `GUIDE`만 남긴다.
- 개발 상태, 에셋 이름과 긴 규칙 설명은 공개 시작 화면에서 제거한다.
- `GUIDE`는 다음 세 행동을 이미지 중심으로 안내한다.
  1. 카드를 펼친다.
  2. 같은 문양의 해골 합이 3이면 대응하는 벨을 누른다.
  3. 획득 카드로 포커 패를 만들고 승패를 예측한다.
- 첫 플레이 중에는 현재 필요한 조작만 짧게 안내하고, 행동 완료 후 안내를 숨긴다.

## 8. AI 영역

- AI 측에는 플레이어와 동일한 조작 버튼을 표시하지 않는다.
- AI 조작 버튼 위치는 `AI 판단 중`, 반응 상태와 획득 카드 수를 보여주는 상태 영역으로 사용한다.
- 플레이어가 조작할 수 있는 요소만 청록색 활성 상태로 명확하게 표시한다.

## 9. 아트 요청 산출물

- 플레이어 획득 카드 트레이와 AI 획득 카드 수 표시
- 첫 커뮤니티 카드 공개, 할리갈리 클로즈업과 포커 와이드 구도 시안
- `START`와 `GUIDE`만 있는 최초 실행 화면 시안
- 외부 또는 AI 생성 소스 사용 시 출처·도구·라이선스·공개 빌드 사용 가능 여부 기록

- [ ] 획득 카드가 필드에서 전용 트레이로 이동하고 이후에도 확인된다.
- [ ] AI 조작 버튼이 플레이어 입력으로 오해되지 않는다.
- [ ] 첫 커뮤니티 카드와 잠긴 두 번째 카드가 구분된다.
