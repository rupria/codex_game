## 기준 원본

- Obsidian Vault: `G:\내 드라이브\codex_game\obsidian`
- 실제 Git 저장소: `C:\sk-encoa\codex_game`
- Git 문서 공유 스냅샷: `C:\sk-encoa\codex_game\project_docs`
- 공통 규칙: [[../rules/README|Rules]]
- 프로젝트 작업: [[README|Core]]
- Git 산출물: [비공개 GitHub 저장소](https://github.com/rupria/codex_game)
- 문서는 Drive 원본을 우선하고, 공동 검토·이력 관리가 필요한 문서만 `project_docs`에 스냅샷으로 복제한다.
- Drive 원본과 Git 스냅샷을 독립적으로 편집하지 않는다.
- `G:\내 드라이브\codex_game` 최상위의 예전 Git 사본은 개발에 사용하지 않는다.
