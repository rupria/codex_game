# 2026-08-05 플랫폼 전략

- 상태: 확정
- 맥락: 공모전 접근성과 안정성을 위해 웹 플레이가 중요하며, 향후 설치형 빌드도 고려해야 한다.
- 결정: 웹 빌드를 우선 완성하되 설치형 빌드로 확장할 수 있도록 게임 로직과 플랫폼 종속 기능을 분리한다.
- 검토한 대안: 웹 전용, 설치형 우선, 웹·설치형 동시 우선 개발
- 선택 이유: 심사 접근성과 빠른 플레이테스트를 확보하면서 장기 배포 선택지를 유지할 수 있다.
- 예상 영향: 웹을 막는 설치형 전용 기능은 코어 루프에서 제외하고, 설치형 패키징은 코어 재미와 웹 안정성 검증 후 진행한다.
- 재검토 조건: 기술 스택이 설치형 확장을 지원하지 않거나 설치형 기능이 코어 플레이에 필수라는 증거가 생길 때
