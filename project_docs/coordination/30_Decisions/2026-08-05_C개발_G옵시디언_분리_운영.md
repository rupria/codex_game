# 2026-08-05 C 개발·G Obsidian 분리 운영

- 상태: 확정
- 결정일: 2026-08-05
- 결정자: 사용자
- 적용 범위: `codex_game` 로컬 개발, Git, Codex와 Obsidian 작업환경

## 결정

- 유일한 Git·개발 작업공간은 `C:\sk-encoa\codex_game`으로 한다.
- 규칙, 내부 메모, 기획 검토와 QA 증거의 기준 원본은 `G:\내 드라이브\codex_game\obsidian`에 유지한다.
- Obsidian은 G의 `obsidian` 폴더를 Vault로 연다.
- Git 명령, 코드 수정, 테스트와 빌드는 C 저장소에서 수행한다.
- 문서 작성은 Drive 기준 원본에서 진행하고, 공동 검토·이력 관리가 필요한 완료본만 C 저장소의 `project_docs`에 스냅샷으로 공유한다.

## 이유

- 로컬 NTFS 저장소에서 Git 인덱스와 빌드 성능을 안정적으로 유지한다.
- Google Drive에는 동기화 가치가 있는 규칙과 내부 문서를 남긴다.
- 문서 기준 원본과 Git 공유 스냅샷의 책임을 분리해 독립 편집을 막는다.
- 동일 Git 저장소를 C와 G에서 동시에 운영해 생기는 인덱스 충돌과 기준 원본 혼선을 제거한다.

## 안전 규칙

- `G:\내 드라이브\codex_game` 최상위의 예전 `.git`은 참고 상태로 보존하며 Git 작업에 사용하지 않는다.
- G의 `.git\index.lock`, 인덱스 또는 중복 파일을 임의로 삭제·복구하지 않는다.
- Drive의 `obsidian` 전체는 Git에 적재하지 않고, 승인된 완료본만 `project_docs`에 둔다.
- C와 G의 같은 Git 공유 문서를 독립적으로 수정하지 않는다.
- 사용자의 명시 승인 없이 `pub`을 변경하지 않는다.

## 역할별 위치

| 역할 | 내부 메모·검토 | Git 공유 산출물 |
|---|---|---|
| 기획 | `G:\내 드라이브\codex_game\obsidian\core\designer` | `C:\sk-encoa\codex_game\project_docs\designer` |
| 프로그래머 | `G:\내 드라이브\codex_game\obsidian\core\programer` | 코드 `C:\sk-encoa\codex_game\programer`, 문서 `project_docs\programer` |
| QA | `G:\내 드라이브\codex_game\obsidian\core\QA` | `C:\sk-encoa\codex_game\project_docs\QA` |
| PM·총괄 | `G:\내 드라이브\codex_game\obsidian\core\PM` | `C:\sk-encoa\codex_game\project_docs\PM` |

## 재검토 조건

- Google Drive 경로 또는 동기화 방식이 바뀌는 경우
- C와 G 연결이 Obsidian에서 안정적으로 동작하지 않는 경우
- 팀원이 다른 PC에서 동일 환경을 재현해야 하는 경우
