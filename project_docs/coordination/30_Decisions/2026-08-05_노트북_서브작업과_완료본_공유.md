# 2026-08-05 노트북 서브 작업과 완료본 공유

- 상태: 확정
- 결정일: 2026-08-05
- 결정자: 사용자

## 결정

- 완료된 코드는 GitHub `dev`와 `G:\내 드라이브\codex_game\shared`에 공유한다.
- Drive에는 활성 Git 작업트리 대신 커밋 기준 소스 ZIP, Git bundle과 매니페스트를 버전별로 둔다.
- 노트북 코딩은 GitHub 또는 bundle을 노트북 로컬 디스크에 clone한 뒤 진행한다.
- 노트북의 로컬 clone에서도 기능 브랜치 commit·push를 수행할 수 있다.
- Obsidian 내부 메모는 Google Drive 동기화가 끝난 것을 확인한 뒤 역할별 폴더에서 편집한다.

## 이유

- Google Drive 안의 활성 `.git`에서 발생하는 인덱스 잠금과 동기화 충돌을 피한다.
- GitHub 온라인 협업과 Drive 오프라인 복구를 함께 지원한다.
- 어떤 완료본을 사용했는지 커밋 SHA와 체크섬으로 확인할 수 있다.

## 완료본 기준

- 작업 트리가 깨끗하고 필요한 변경이 커밋되어 있다.
- 대상 브랜치와 커밋 SHA가 확인된다.
- 관련 검증 결과와 알려진 제한이 기록된다.
- `tools\publish-completed-to-drive.ps1`가 생성한 릴리스만 공식 Drive 완료본으로 취급한다.

## 금지 사항

- Drive의 `shared\releases` 안에서 직접 코딩하지 않는다.
- Drive에 활성 `.git` 작업트리를 만들어 여러 PC가 동시에 수정하지 않는다.
- 커밋되지 않은 작업을 완료본으로 발행하지 않는다.
- 데스크톱과 노트북에 같은 브랜치의 미푸시 변경을 동시에 남기지 않는다.
