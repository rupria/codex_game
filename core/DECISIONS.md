# 결정 기록

## 2026-08-05 — 웹 우선, 설치형 확장 가능 구조

- 상태: 확정
- 맥락: 공모전 제출물은 접근성이 높은 웹 플레이가 중요하지만, 향후 설치형 빌드 제공 가능성도 고려해야 합니다.
- 결정: 안정적인 웹 빌드를 1차 배포 대상으로 삼고, 설치형 빌드로 패키징할 수 있도록 게임 로직과 플랫폼 종속 기능을 분리합니다.
- 검토한 대안: 웹 전용 개발, 설치형 우선 개발, 웹과 설치형의 동시 개발
- 선택 이유: 심사 접근성과 초기 검증 속도를 확보하면서 향후 배포 선택지를 유지할 수 있습니다.
- 예상 영향:
  - 저장, 입력, 화면 크기와 플랫폼 API를 경계 계층으로 분리합니다.
  - 웹 배포를 막는 설치형 전용 기능은 코어 루프에 포함하지 않습니다.
  - 설치형 패키징은 코어 재미와 웹 안정성을 확인한 후 구현합니다.
- 재검토 조건: 선택한 기술 스택이 설치형 패키징을 지원하지 않거나, 설치형 기능이 코어 플레이에 필수라는 증거가 생길 때 재검토합니다.
